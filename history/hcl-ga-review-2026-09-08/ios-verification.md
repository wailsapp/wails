# iOS HCL build verification — 8 September 2026

Related acceptance work: wailsapp/wails#6021. Branch: `codex/hcl-build-system` (the branch called `hcl-ga-fixes` in the earlier handoff). Tested from base `f8f0d120eeb3792b6b3002bd88daf95257a4dcfe` plus the accompanying iOS resource fixes.

## Defect and fix

Before the fix, a native simulator build exited successfully but omitted the icon declarations from the final Info.plist, discarded the loose PNGs generated by actool, and referenced a LaunchScreen storyboard that was never compiled into the app.

The assembler now copies all compiled catalog resources, merges actool's partial plist into the app's Info.plist, and compiles the launch storyboard with the selected iOS SDK before signing. Explicit project plist values are preserved, including nested icon settings. Intermediate partial plist files stay outside the bundle. Resource compilation and metadata errors occur before replacing the previous app.

Regression tests cover simulator and device/IPA assembly, copied icon resources, launch storyboard compilation, generated metadata, preservation of custom binary/XML plist settings, invalid plist rejection, and preservation of the previous app after actool/ibtool failures.
