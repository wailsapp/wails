Validation limitations

The host contains no Go toolchain. Disposable Go 1.25 containers independently passed updater-provider, release-script, changelog, GTK state, and systray tests; the GTK tests compiled against GTK4/WebKitGTK 6.0. CodeRabbit reviewed all local changes; its substantive updater and GTK lifecycle findings were fixed and retested. Full suites, GTK3, Node/runtime/templates, Astro, native platforms, and compositor behavior have not yet been independently rerun in this candidate session.

Decision standard

“Beta ready” here means suitable for broader production-adjacent testing with a substantially stable API and an explicit support envelope. It does not mean feature-complete or bug-free. A defect blocks Beta when it threatens update integrity/security, breaks a default starter or core API on a supported platform, or makes the release/support promise materially misleading.
