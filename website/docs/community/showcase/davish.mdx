[Davish](https://github.com/2hjaito/davish) turns any Linux server into a desktop over plain SSH, with nothing to install on the server. No agent and no extra ports. It reads your local `~/.ssh/config` and keys, then opens an OS-like workspace with a menu bar, Dock, and draggable, splittable windows.

It bundles about 20 tools, including a terminal, SFTP file manager and editor, live CPU/memory/disk monitoring, Docker, logs, Nginx, Cron, services, ports and ufw firewall management, and SSH login security analysis. Built with Go, Wails and Svelte 5 for Windows, macOS and Linux. GPL-3.0.
