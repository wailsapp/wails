[Culma](https://culma.eu) is the collaborative knowledge base with end-to-end encryption, built with Wails. Several people write in the same note at the same time with live cursors, and the sync server holds only ciphertext. Notes are Markdown, the vault works offline, and search and dictation run on the device. Runs on Windows and Linux, with mobile apps for Android and iOS.
