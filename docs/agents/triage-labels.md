# Triage labels

Local Markdown tickets use the canonical label vocabulary.

| Role | Local label |
| --- | --- |
| Needs maintainer evaluation | `needs-triage` |
| Waiting for more information | `needs-info` |
| Ready for an AFK agent | `ready-for-agent` |
| Requires human implementation | `ready-for-human` |
| Will not be actioned | `wontfix` |
