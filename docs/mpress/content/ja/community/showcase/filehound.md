[FileHound エクスポートユーティリティ](https://www.filehound.co.uk/) FileHound は、ファイルの安全な保存、ビジネスプロセスの自動化、SmartCapture 機能を提供するクラウドドキュメント管理プラットフォームです。

FileHound エクスポートユーティリティを使用すると、FileHound 管理者は、代替のバックアップおよび復旧を目的として、ドキュメントとデータを安全に抽出するタスクを実行できます。このアプリケーションは、選択したフィルターに基づいて、FileHound に保存されているすべてのドキュメントおよび／またはメタデータをダウンロードします。メタデータは JSON 形式と XML 形式の両方でエクスポートされます。

バックエンドの構築に使用：

- Go 1.15
- Wails 1.11.0
- go-sqlite3 1.14.6
- go-linq 3.2

フロントエンドに使用：

- Vue 2.6.11
- Vuex 3.4.0
- TypeScript
- Tailwind 1.9.6
