[Larder](https://github.com/599yongyang/larder) は、複数の AI Agent を併用する開発者向けのローカルファーストなデスクトップアプリです。ディスク上に実際に存在する Skills、MCP サーバー、CLI ツール、指示ファイル、カスタムコマンドをスキャンし、各 Agent が実際に何を見ているかを説明します。

壊れたリンク、重複した Skill、古い設定を見つけるのに役立ちます。すべての書き込みは計画とスナップショットを経由するため、変更を元に戻せます。選択可能なデータパッケージと、任意の暗号化 WebDAV/S3 バックアップにも対応しています。

Go 1.26、Wails v3 beta.34、React 18、SQLite、Tailwind CSS で構築。MIT ライセンス。

[GitHub で見る](https://github.com/599yongyang/larder)
