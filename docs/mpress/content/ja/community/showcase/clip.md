![Clip のスクリーンショット](/assets/showcase-images/clip.png)

- **3 カラムレイアウト**：ソース/フォルダーのツリー · 記事一覧 · 閲覧ビュー
- **購読管理**：フィードの追加、フォルダーによる整理、OPML のインポート/エクスポート
- **定期取得**：RSS / Atom の解析とバックグラウンドでの自動更新
- **集中して読む**：全文閲覧ビュー + 読書を妨げる要素を省いた集中モード
- **高速検索**：タイトル、要約、メモを横断する全文検索
- **メモ**：記事にメモを付けて後から振り返ることが可能
- **デスクトップ通知**：新着記事の通知、macOS Dock / Windows タスクバーのバッジ
- **キーボード操作**：充実したショートカット
- **テーマと言語対応**：ライト / ダーク / システム設定に従う、多言語対応
- **パフォーマンスとオフライン利用**：軽量な一覧クエリ、ローカルキャッシュ、オフラインでの閲覧

[GitHub で見る](https://github.com/clip-rss/clip)
