**[MQ Studio](https://mq-studio.amigoer.com)** は **ローカルでの利用を優先するメッセージキュー用デスクトップクライアント**であり、 **Go、Wails、React**で構築されています。各ブローカーには独自のコンソールがあり、RocketMQ と Kafka ではそれぞれ異なり、RabbitMQ には管理プラグインがあります。画面も用語も異なり、それぞれをサービスとしてデプロイし、維持する必要があります。MQ Studio はこれらを単一のアプリケーションにまとめます。共通のインターフェースの背後にあるドライバーを通じて各ブローカーに接続するため、接続先にかかわらず同じ画面と操作の流れを使えます。

## 主な特徴

- **すべてのブローカーを一つの画面で** — 現在は RocketMQ、RabbitMQ、Kafka に対応し、Pulsar、NATS、MQTT、SQS も計画しています。
- **トピック、キュー、メッセージ** — トピック、キュー、エクスチェンジ、バインディングの確認、メッセージの検索と追跡、ログの監視、キーやヘッダー付きの送信、再送、配信不能メッセージの処理ができます。
- **コンシューマーと遅延** — グループ、クライアント、サブスクリプション、パーティションごとの遅延を確認し、オフセットのリセットや再試行、デッドレターキュー（DLQ）の処理ができます。
- **クラスターとアラート** — ブローカーの稼働状態、実行時メトリクス、スループット、ディスク使用量、ネイティブのデスクトップ通知に対応します。
- **接続先の機能を正確に反映** — 各ドライバーは接続先で実際に使える機能を宣言し、画面にはブローカーが対応する操作だけが表示されます。
- **プライバシーを標準で保護** — 設定は端末内に保存され、認証情報は暗号化して保存されます。

デプロイするサーバーコンポーネントも、維持するウェブコンソールもなく、テレメトリーもありません。これを可能にしているのが Wails です。ブローカーの管理クライアントは Go ライブラリなので、ドライバー層が同じプロセス内で直接呼び出し、フロントエンドは通常の React アプリのままです。運用が必要なサービスではなく、プラットフォームごとに一つのバイナリを提供します。

macOS、Windows、Linux に対応し、英語と中国語で利用できます。
