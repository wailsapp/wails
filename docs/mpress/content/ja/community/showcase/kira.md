**[Kira](https://kira.thiennguyen.dev)** は、<strong>AWS 向けのネイティブ macOS デスクトップクライアント</strong>です。そのコンセプトは、<em>「煩わしさのない AWS」</em>です。**Go、Wails、React + TypeScript** で構築され、AWS の操作をキーボードで扱える単一のアプリに集約します。AWS SSO で一度認証すれば、コンソール、CLI、多数のデータベースツールを切り替えることなく、複数のアカウントにまたがるインフラストラクチャを管理できます。

始まりは、個人的に感じていた不便さでした。変更をリリースするだけなのに、ブラウザーのタブ、`aws` コマンド、別の SQL クライアントを行き来するのは非効率でした。Kira は、こうしたワークフローを高速な単一のネイティブウィンドウに統合します。サインインしてアカウントを選択すれば、必要な機能をすべてキー操作ですぐに利用できます。

![本番、ステージング、開発の各アカウントを一元表示する Kira のマルチアカウント概要](/assets/showcase-images/kira_screenshot_1.png)

## 主な特長

- **マルチアカウント AWS SSO** - 一度サインインすれば、1 か所からアカウントとリージョンを切り替えられます
- **ECS** - クラスター、サービス、タスクの参照、サービスの再デプロイ、スケーリング、ロールバック、タスク定義の表示、サービスメトリクスの監視に加え、ECS Exec を介して対話型シェルを開けます
- **データベース** - RDS に対する SQL の実行、DynamoDB のクエリとスキャン、PostgreSQL、MySQL、Redshift への接続が可能です。安全な SSH トンネリングに対応し、認証情報は macOS Keychain に保存されます
- **S3** - バケットとプレフィックスをたどって閲覧し、オブジェクトのプレビュー、アップロード、ダウンロード、コピー、名前変更、削除、フォルダーの作成が可能です
- **Secrets Manager** - アクティブなアカウントのシークレットを一覧表示し、その値を取得できます
- **CloudWatch Logs** - ログストリームをリアルタイムに追跡および検索できます
- **スマートクエリ** - `claude` CLI を利用した、オプションの AI 支援による SQL 生成機能です
- **拡張機能** - 小さな Go スクリプトで動作するアクションボタンを追加する、カスタム `.kext` バンドルをインストールできます
- **高速なナビゲーション** - グローバル呼び出しホットキー、`Cmd+K` コマンドパレット、`kira://` ディープリンクを利用できます

## 詳しく見る

タスクの正常性、CPU とメモリ、デプロイ状態など、ECS サービスの状況をリアルタイムで確認できます。一覧から移動せずに、再デプロイ、スケーリング、ロールバックを実行できます。

![リアルタイムメトリクスを表示しながら Kira で ECS サービスを参照](/assets/showcase-images/kira_screenshot_17.png)

ファイルマネージャーのように S3 を参照できます。オブジェクトのプレビュー、メタデータとバージョンの確認、アップロード、ダウンロード、名前変更、削除をその場で実行できます。

![オブジェクトのプレビューとメタデータを表示する Kira の S3 オブジェクトブラウザー](/assets/showcase-images/kira_screenshot_5.png)

macOS 向けに署名および公証された `.dmg` として配布されています。
