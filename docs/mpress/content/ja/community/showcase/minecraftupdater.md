[Minecraft Updater](https://github.com/Gurkengewuerz/MinecraftModUpdater)は、ユーザーベース向けの Minecraft Mod を更新および同期するためのユーティリティツールです。フロントエンドフレームワークとして[antd](https://ant.design/)を使用し、Wails2 と React で構築されています。
