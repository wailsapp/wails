Burp Suite Repeater に着想を得た、デスクトップ用 HTTP リクエストリプレイヤーです。生の HTTP リクエストを編集し、書いたままの形で TCP/TLS ソケットに送信し、タブごとの履歴を保持します。プロキシも JVM も不要です。curl/fetch スニペットのインポート、タブ単位のダウンストリームプロキシ、独自の LLM エンドポイントによるリクエストやペイロードの作成に対応。Wails v2 / Go / Vue 3 / CodeMirror 6 で構築。Apache-2.0。

[GitHubで見る](https://github.com/chenshiyi007/HttpRepeater)
