MyGit は、Wails 3、Go、React で構築された、worktree を中心に据えたデスクトップ Git クライアントです。複数のリポジトリを共通のルートの下にまとめ、各 worktree をそれぞれのタブとして開き、履歴、diff と blame、Git のあらゆる操作、複数タブの PTY ターミナル、AI が生成するコミットメッセージを 1 つのネイティブウィンドウに集約します。
