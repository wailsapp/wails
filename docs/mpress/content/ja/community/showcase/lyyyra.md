Lyyyra は Wails、Go、React で作られたデスクトップ向けのソングブックアプリです。evangelickyzpevnik.cz から歌詞、メタデータ、楽譜 PDF をダウンロードし、最初のダウンロード後はオフラインでコレクションを検索・絞り込み・並べ替えできます。

主な機能：

- タイトル、作者、歌詞を対象とした全文検索
- 曲番号、タイトル、作曲者、作詞者による並べ替え
- 曲を集めて 1 つの PDF として書き出せる「準備済みシート」パネル
- 最初のダウンロード後もオフラインで動作するローカルデータベース
- Windows と Linux 向けのビルド済みバイナリ

[GitHub で見る](https://github.com/tomvladik/Lyyyra)
