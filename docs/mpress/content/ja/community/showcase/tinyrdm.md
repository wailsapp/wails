[Tiny RDM](https://redis.tinycraft.cc/) は、オープンソースのモダンで軽量な Redis GUI アプリケーションです。 美しい UI と直感的な Redis データベース管理機能を備え、Windows、Mac、Linux に対応しています。 キーと値のデータを視覚的に操作でき、さまざまなデータのデコード方法と表示方法をサポートしています。 さらに、コマンド実行用の組み込みコンソール、スローログの照会などの機能も備えています。
