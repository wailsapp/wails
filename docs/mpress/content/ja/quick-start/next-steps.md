## 機能

Wails はネイティブデスクトップ機能を提供します。

- [ウィンドウ](/features/windows/basics/) - 複数ウィンドウ、フレームレスウィンドウ、位置指定
- [メニュー](/features/menus/application/) - アプリケーションメニュー、コンテキストメニュー、システムトレイ
- [ダイアログ](/features/dialogs/file/) - ファイルを開く／保存、メッセージダイアログ
- [イベント](/features/events/system/) - コンポーネント間の通信
- [バインディング](/features/bindings/methods/) - 型安全な Go ↔ JavaScript 呼び出し
- [クリップボード](/features/clipboard/basics/) - コピー／貼り付け操作
- [ドラッグ＆ドロップ](/features/drag-and-drop/files/) - ファイルのドラッグ＆ドロップ
- [キーボード](/features/keyboard/shortcuts/) - グローバルショートカット
