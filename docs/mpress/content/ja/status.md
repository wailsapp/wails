## Wails v3.0.0 — 安定版

最新の状況については、[変更履歴](/changelog/)を確認してください。

このドキュメントでは Wails v3.0.0 を扱います。v3.0.0以降、修正と改善は週次リリースで提供され、その合間には日付付きのナイトリープレビューが提供されます。また、緊急の問題にはホットフィックスが提供されます。[リリースポリシー](/contributing/release-policy/)を参照してください。

## デスクトップ互換性

v3.0.0 の互換性保証は、デスクトップアプリケーションを対象としています。

| プラットフォーム | サポート対象 | 要件と注意事項 |
| --- | --- | --- |
| Windows | amd64 および arm64 | WebView2 ランタイム |
| macOS | Intel および Apple Silicon | インストールガイドに記載されている macOS および WebKit のバージョン |
| Linux | amd64 および arm64 | デフォルトでは GTK4 + WebKitGTK 6.0。GTK3 + WebKit2GTK 4.1 は、v3.0.x までは `-tags gtk3` レガシーオプションとして引き続き利用できますが、v3.1 で削除されます |

すべてのターゲットで、開発には Go 1.26 以降が必要です。Android と iOS のサポートは引き続き試験的なものであり、安定版デスクトップの互換性保証の対象外です。

## コントリビューション方法

- Wails v3.0.0 をテストし、再現可能なバグを報告する
- ドキュメントやサンプルに貢献する
- ディスカッションに参加し、WEP の草案にフィードバックを提供する
- バグ修正、ドキュメント、または承認済み WEP に関するプルリクエストを送信する

コミュニティからのコントリビューションを歓迎します。これらの目標にご協力いただける場合は、コミュニティのディスカッションにご参加ください。新機能の提案は、機能リクエストの Issue ではなく、WEP の PR として提出してください。

## フィードバックと更新情報

このロードマップは、コミュニティからのフィードバックやプロジェクトの優先事項に応じて変更される場合があります。進捗や方向性の変更を反映するため、定期的に更新します。再現可能な問題は Issue として報告し、新機能は [WEP（Wails Enhancement Proposal）](https://github.com/wailsapp/wails/blob/releases/v3.0.0/v3/wep/README.md) の PR を通じて提案してください。
