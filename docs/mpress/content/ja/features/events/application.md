---
title: "アプリケーションイベント"
description: "Wails v3 が発行するアプリケーションレベルのイベント"
slug: "features/events/application"
sourcePath: "features/events/application.md"
---

アプリケーションイベントは、起動、停止、ウィンドウ管理操作など、アプリケーション全体のライフサイクルが変化したときに発行されます。

アプリケーションイベントの完全なドキュメントについては、[イベントシステム](/features/events/system/#application-events)ガイドを参照してください。
