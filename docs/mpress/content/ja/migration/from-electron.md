Wails を使用すると、Go と Web 技術を使ってデスクトップアプリケーションを構築でき、Electron の Node.js ランタイムを単一の Go バイナリに置き換えられます。Wails v2 と v3 の違いについては、[v2 から v3 への移行](/migration/v2-to-v3/)を参照してください。
