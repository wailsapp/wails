[Resizem](https://github.com/barats/resizem) adalah aplikasi yang dirancang untuk memproses gambar secara massal. Aplikasi ini sangat berguna bagi pengguna yang perlu mengubah ukuran, mengonversi, dan mengelola banyak file gambar sekaligus.
