[EmailIt](https://github.com/raguay/EmailIt/) adalah program Wails 2 yang hanya berfungsi sebagai pengirim email berbasis Markdown, dengan sembilan buku catatan, skrip untuk memanipulasi teks, dan templat. Aplikasi ini juga memiliki terminal skrip untuk menjalankan skrip di EmailIt pada berkas di sistem Anda. Skrip dan templat dapat digunakan langsung dari baris perintah atau dengan ekstensi Alfred, Keyboard Maestro, Dropzone, atau PopClip. Aplikasi ini juga mendukung skrip dan tema yang diunduh dari GitHub. Dokumentasinya belum lengkap, tetapi program ini berfungsi. Aplikasi ini dibuat menggunakan Wails2 dan Svelte, dan unduhannya berupa aplikasi macOS universal.
