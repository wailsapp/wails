[Larder](https://github.com/599yongyang/larder) adalah aplikasi desktop local-first untuk developer yang menggunakan beberapa AI Agent. Aplikasi ini memindai file yang benar-benar ada di disk — Skills, server MCP, alat CLI, file instruksi, dan perintah khusus — lalu menjelaskan apa yang benar-benar dilihat setiap Agent.

Larder membantu menemukan tautan rusak, Skill duplikat, dan konfigurasi usang. Setiap perubahan melewati plan dan snapshot sehingga bisa dikembalikan. Larder juga mendukung paket data yang dapat dipilih dan cadangan WebDAV/S3 terenkripsi opsional.

Dibangun dengan Go 1.26, Wails v3 beta.34, React 18, SQLite, dan Tailwind CSS. Lisensi MIT.
