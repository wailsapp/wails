[Ytd](https://github.com/marcio199226/ytd/tree/v2-wails) adalah aplikasi untuk mengunduh lagu dari YouTube, membuat daftar putar offline, dan membagikannya kepada teman-teman Anda. Teman-teman Anda dapat memutar daftar putar tersebut atau mengunduhnya untuk didengarkan secara offline. Aplikasi ini dilengkapi pemutar bawaan.
