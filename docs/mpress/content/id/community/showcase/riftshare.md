Berbagi file dengan mudah, aman, dan gratis untuk semua orang. Pelajari selengkapnya di [Riftshare.app](https://riftshare.app)

## Fitur

- Berbagi file dengan mudah dan aman antarkomputer, baik di jaringan lokal maupun melalui internet
- Mendukung pengiriman file atau direktori secara aman melalui [protokol magic wormhole](https://magic-wormhole.readthedocs.io/en/latest/)
- Kompatibel dengan semua aplikasi lain yang menggunakan magic wormhole (CLI magic-wormhole atau wormhole-william, wormhole-gui, dan lain-lain)
- Mengompresi beberapa file yang dipilih secara otomatis ke dalam arsip ZIP agar dapat dikirim sekaligus
- Dukungan penuh untuk animasi, bilah progres, dan pembatalan saat mengirim dan menerima
- Pemilihan File Native OS
- Buka file dengan sekali klik setelah diterima
- Pembaruan Otomatis — tak perlu khawatir apakah Anda menggunakan rilis terbaru!
