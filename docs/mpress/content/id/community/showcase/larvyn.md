Larvyn adalah meja kerja desktop untuk pengembang Laravel di Linux, macOS, dan Windows. Aplikasi ini menyatukan aplikasi Laravel Anda, layanan pengembangannya (artisan serve, Vite, antrean, Reverb…), terminal sungguhan, database, Tinker, tes, log, dan agen AI coding dalam satu jendela native.

Jalankan Claude Code, Codex, OpenCode, Cursor Agent, Aider, dan lainnya secara berdampingan, masing-masing di git worktree sendiri, lalu bandingkan diff-nya dan gabungkan yang terbaik. Dibangun dengan Wails 3, Go, dan React.
