[ScriptBar](https://GitHub.com/raguay/ScriptBarApp) adalah program untuk menampilkan keluaran skrip atau server [Node-Red](https://nodered.org). Program ini menjalankan skrip yang ditentukan dalam program EmailIt dan menampilkan keluarannya. Skrip dari xBar atau TextBar dapat digunakan, tetapi saat ini hanya skrip TextBar yang berfungsi dengan baik. Program ini juga menampilkan keluaran skrip di sistem Anda. ScriptBar tidak menempatkannya di bilah menu, melainkan menyajikan semuanya dalam satu jendela praktis agar mudah dilihat. Anda dapat menggunakan beberapa tab untuk menampilkan berbagai hal. Anda juga dapat menyimpan tautan ke situs web yang paling sering Anda kunjungi.
