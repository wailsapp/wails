[Peluncur Minecraft untuk WarMine](https://warmine.ru/) adalah aplikasi Wails yang memudahkan Anda bergabung dengan server game yang telah dimodifikasi dan mengelola akun game Anda.

Peluncur ini mengunduh file game, memeriksa integritasnya, dan menjalankan game dengan beragam opsi penyesuaian argumen peluncuran dari backend.

Frontend ditulis menggunakan Svelte, seluruh peluncur hanya berukuran 9 MB dan mendukung Windows 7-11.
