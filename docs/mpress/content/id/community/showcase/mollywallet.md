[Molly Wallet](https://github.com/grvlle/constellation_wallet/) adalah dompet resmi $DAG untuk Constellation Network. Aplikasi ini akan memungkinkan pengguna berinteraksi dengan Hypergraph Network melalui berbagai cara, tidak terbatas pada pembuatan transaksi $DAG.
