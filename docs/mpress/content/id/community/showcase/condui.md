Condui adalah pengelola koneksi SSH dengan sinkronisasi multi-perangkat yang dienkripsi secara end-to-end. Condui menjaga koneksi, tunnel SSH, dan kredensial yang dilindungi brankas tetap tersinkronisasi di semua perangkat yang Anda gunakan, tanpa pernah mengekspos kredensial dalam bentuk teks biasa kepada server sinkronisasi.

Fitur Utama

- 🔐 Brankas terenkripsi secara end-to-end untuk kata sandi SSH dan frasa sandi kunci privat
- 🔄 Sinkronisasi koneksi, folder, dan tunnel SSH di beberapa perangkat
- 🌐 Tunnel penerusan port lokal yang disimpan untuk setiap koneksi
- 🖥️ Terminal, SFTP, Docker, dan alat basis data terintegrasi
- 💻 Tersedia untuk macOS, Windows, dan Linux
