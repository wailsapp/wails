Aplikasi [Tiny RDM](https://redis.tinycraft.cc/) adalah GUI Redis sumber terbuka yang modern dan ringan. Aplikasi ini memiliki antarmuka pengguna yang indah, pengelolaan basis data Redis yang intuitif, serta kompatibel dengan Windows, Mac, dan Linux. Aplikasi ini menyediakan operasi visual untuk data nilai-kunci, mendukung berbagai opsi pendekodean dan tampilan data, konsol bawaan untuk menjalankan perintah, kueri log lambat, dan banyak lagi.
