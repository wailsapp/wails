Aplikasi [BulletinBoard](https://github.com/raguay/BulletinBoard) adalah papan pesan serbaguna untuk menampilkan pesan statis atau dialog guna memperoleh informasi dari pengguna untuk sebuah skrip. Aplikasi ini memiliki TUI untuk membuat dialog baru yang nantinya dapat digunakan untuk memperoleh informasi dari pengguna. Aplikasi ini dirancang agar tetap berjalan di sistem Anda, menampilkan informasi saat diperlukan, lalu menyembunyikan diri. Saya memiliki proses yang memantau sebuah berkas di sistem saya dan mengirimkan isinya ke BulletinBoard saat berkas tersebut berubah. Aplikasi ini sangat cocok dengan alur kerja saya. Tersedia juga [alur kerja Alfred](https://github.com/raguay/MyAlfred/blob/master/Alfred%205/EmailIt.alfredworkflow) untuk mengirimkan informasi ke program tersebut. Alur kerja ini juga digunakan untuk bekerja dengan [EmailIt](https://github.com/raguay/EmailIt).
