Aplikasi wallpaper Windows yang mendukung wallpaper khusus, beberapa monitor, serta pergantian wallpaper secara acak atau berurutan.

Tayangan slide bawaan Windows tidak dapat memilih gambar dari beberapa direktori tanpa menggabungkannya terlebih dahulu. wpm memungkinkan Anda memilih beberapa direktori atau menggunakan direktori berbeda untuk setiap monitor. Aplikasi ini dapat memilih gambar acak dengan rasio aspek yang sesuai untuk setiap layar.
