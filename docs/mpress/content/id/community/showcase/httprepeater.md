Pemutar ulang permintaan HTTP desktop yang fokus, terinspirasi oleh Burp Suite Repeater. Edit permintaan HTTP mentah, kirim persis apa adanya melalui socket TCP/TLS, dan simpan riwayat per tab — tanpa proxy, tanpa JVM. Mengimpor cuplikan curl/fetch, merutekan tiap tab lewat proxy hilir opsional, dan dapat menyusun permintaan serta payload dengan endpoint LLM Anda sendiri. Dibangun dengan Wails v2, Go, Vue 3 dan CodeMirror 6; Apache-2.0.

[Lihat di GitHub](https://github.com/chenshiyi007/HttpRepeater)
