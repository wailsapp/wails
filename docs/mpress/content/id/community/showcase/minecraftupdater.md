[Minecraft Updater](https://github.com/Gurkengewuerz/MinecraftModUpdater) adalah alat bantu untuk memperbarui dan menyinkronkan mod Minecraft bagi basis pengguna Anda. Alat ini dibuat menggunakan Wails2 dan React dengan [antd](https://ant.design/) sebagai framework frontend.
