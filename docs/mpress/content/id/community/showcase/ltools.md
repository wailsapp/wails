[LTools](https://github.com/lian-yang/ltools) adalah kotak alat desktop lintas platform berbasis plugin yang dibuat dengan Wails v3 dan terinspirasi oleh uTools. Aplikasi ini menyediakan pusat terpadu untuk berbagai utilitas pengembang melalui arsitektur plugin modular.

Fitur-fiturnya mencakup bilah pencarian global bergaya Spotlight, integrasi baki sistem, serta plugin bawaan seperti pengelola papan klip, alat tangkapan layar dengan anotasi, editor JSON, kalkulator, pemantau sistem, dan lainnya. Alat baru dapat ditambahkan melalui sistem pluginnya yang dapat diperluas.
