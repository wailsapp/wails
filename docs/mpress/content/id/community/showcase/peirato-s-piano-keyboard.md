[Peirato's Piano Keyboard](https://github.com/Peiratooo/Peirato-s-Piano-Keyboard) adalah keyboard piano desktop ringan yang dibuat dengan Wails. Aplikasi ini dirancang sebagai alat permainan dan latihan ringkas yang dapat tetap terbuka di desktop saat Anda memainkan, mempelajari, merekam, menyiarkan, atau mendemonstrasikan musik.

Aplikasi ini mendukung permainan waktu nyata menggunakan keyboard komputer, keyboard piano MIDI eksternal, atau input mouse. Not langsung ditampilkan pada keyboard virtual sehingga aplikasi ini berguna baik sebagai instrumen yang dapat dimainkan maupun sebagai tampilan visual keyboard.

Selain pemutaran sederhana, Peirato's Piano Keyboard mendukung SoundFont sehingga pengguna dapat mengimpor dan beralih di antara sumber suara `.sf2` khusus. Aplikasi ini juga dapat mengimpor file MIDI untuk pemutaran, pratinjau, latihan berulang, dan latihan mengikuti panduan. Interaksi MIDI bersifat dua arah sehingga aplikasi dapat merespons input MIDI eksternal sekaligus mendukung alur kerja pemutaran dan output MIDI.

Fitur utama meliputi:

- Permainan keyboard piano desktop secara waktu nyata
- Input dari keyboard komputer, mouse, dan keyboard MIDI eksternal
- Dukungan input dan output MIDI
- Impor dan pengelolaan SoundFont `.sf2` khusus
- Impor, pemutaran, pratinjau, dan latihan file MIDI
- Mode pembelajaran MIDI dengan mengikuti panduan
- Penyorotan tuts secara visual untuk permainan dan latihan
- Pengalaman desktop ringan berbasis Wails
