MyGit adalah klien Git desktop yang berpusat pada worktree, dibangun dengan Wails 3, Go, dan React. MyGit mengelompokkan beberapa repositori di bawah root bersama, membuka setiap worktree sebagai tab tersendiri, dan menyatukan riwayat, diff dan blame, seluruh operasi Git, terminal PTY multi-tab, serta pesan commit yang dihasilkan AI ke dalam satu jendela native.
