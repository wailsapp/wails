Peristiwa jendela dipancarkan saat terjadi perubahan pada siklus hidup dan interaksi jendela, seperti membuka, menutup, memindahkan, dan mengubah ukuran.

Dokumentasi lengkap tentang peristiwa jendela tersedia dalam panduan [Sistem Peristiwa](/features/events/system/#window-events).
