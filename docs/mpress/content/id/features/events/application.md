Peristiwa aplikasi dipancarkan untuk perubahan siklus hidup yang berlaku di seluruh aplikasi, seperti operasi memulai, menghentikan, dan mengelola jendela.

Dokumentasi lengkap tentang peristiwa aplikasi tersedia dalam panduan [Sistem Peristiwa](/features/events/system/#application-events).
