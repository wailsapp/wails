Wails dibangun oleh para pengelolanya bersama komunitas kontributor. Orang-orang yang telah membantu membangunnya layak mendapat penghargaan, baik mereka masih terlibat dalam proyek ini maupun tidak.

**Pengelola**

- [Lea Anthony](https://github.com/leaanthony) — Pemilik proyek dan pengembang utama
- [Atterpac](https://github.com/atterpac) — Pengelola; perangkat pengembangan, integrasi desktop, dan dukungan komunitas

Untuk mendapatkan bantuan, gunakan [saluran dukungan komunitas](/community/links/#support-channels). Ucapan terima kasih di bawah ini merupakan penghargaan atas berbagai kontribusi sepanjang sejarah proyek.

**Terima kasih telah membangun Wails v3**

Terima kasih khusus kepada [Fabio Massaioli (fbbdev)](https://github.com/fbbdev) karena telah membuat penganalisis kode sumber statis dan generator binding yang mendukung binding JavaScript dan TypeScript yang dihasilkan oleh v3, serta atas kontribusinya pada API runtime dan layanan.

Terima kasih juga kepada:

- [Travis McLane](https://github.com/tmclane) — Kontribusi awal yang ekstensif untuk Linux dan platform native, kompilasi silang, serta pengujian macOS
- [Stffabi](https://github.com/stffabi) — Fondasi server aset serta dukungan native Windows dan macOS
- [Zach Botterman (popaprozac)](https://github.com/popaprozac) — Notifikasi, integrasi Dock, jendela modal, dan layanan desktop
- [Ian VanSchooten (IanVS)](https://github.com/IanVS) — Event bertipe serta peningkatan runtime dan menu
- [Lyimmi](https://github.com/Lyimmi) — Kontribusi untuk Linux
- [mortenolsrud](https://github.com/mortenolsrud) — Perbaikan Android dan iOS, pengemasan, serta integrasi perangkat seluler
- [Andraz Vrhovec](https://github.com/overlordtm) — Identitas aplikasi Linux dan perilaku instans tunggal
- [Julian Storer](https://github.com/julianstorer) — Fokus di macOS, akselerator papan ketik, dan perilaku desktop
- [Simon Thomas](mailto:enquiries@wails.io) — Pengembangan proyek dan komunitas

Ini hanyalah sebagian dari berbagai kontribusi, bukan daftar lengkap. Terima kasih kepada semua orang yang telah menyumbangkan kode, meninjau perubahan, menguji rilis, menerjemahkan dokumentasi, atau membantu pengguna lain.
