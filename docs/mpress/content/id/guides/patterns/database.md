Aplikasi Wails v3 adalah aplikasi Go, sehingga Anda dapat menggunakan driver basis data Go standar apa pun — termasuk [SQLite](https://github.com/mattn/go-sqlite3), [PostgreSQL](https://github.com/jackc/pgx), dan [MySQL](https://github.com/go-sql-driver/mysql) — di dalam layanan terikat Anda.

Untuk melihat contoh yang dapat dijalankan, lihat [tutorial TODO](/tutorials/02-todo-vanilla/), yang menunjukkan cara menambahkan persistensi SQLite ke aplikasi lengkap.
