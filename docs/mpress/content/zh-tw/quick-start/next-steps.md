您已建立第一個 Wails 應用程式，並瞭解基本概念。接下來可以從這裡繼續。

## 深入瞭解

透過建立完整的應用程式來練習：

- [待辦事項應用程式](/tutorials/02-todo-vanilla/) - CRUD 操作、狀態管理、現代化 UI
- [所有教學](/tutorials/overview/) - 筆記應用程式、儀表板、系統匣應用程式等

## 功能

Wails 提供原生桌面功能：

- [視窗](/features/windows/basics/) - 多視窗、無邊框視窗、視窗定位
- [選單](/features/menus/application/) - 應用程式選單、快顯選單、系統匣
- [對話方塊](/features/dialogs/file/) - 開啟／儲存檔案、訊息對話方塊
- [事件](/features/events/system/) - 元件間通訊
- [繫結](/features/bindings/methods/) - 型別安全的 Go ↔ JavaScript 呼叫
- [剪貼簿](/features/clipboard/basics/) - 複製／貼上操作
- [拖放](/features/drag-and-drop/files/) - 檔案拖放
- [鍵盤](/features/keyboard/shortcuts/) - 全域快速鍵
