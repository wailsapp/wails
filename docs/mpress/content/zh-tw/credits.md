Wails 由維護者與貢獻者社群共同打造。無論目前是否仍參與本專案，所有協助建置 Wails 的人都值得肯定。

**維護者**

- [Lea Anthony](https://github.com/leaanthony) — 專案負責人暨首席開發者
- [Atterpac](https://github.com/atterpac) — 維護者；負責開發工具、桌面整合與社群支援

如需協助，請使用[社群支援管道](/community/links/#support-channels)。以下致謝肯定本專案歷年來收到的貢獻。

**感謝你協助打造 Wails v3**

特別感謝[Fabio Massaioli (fbbdev)](https://github.com/fbbdev)建立靜態原始碼分析器與繫結產生器，為v3產生的 JavaScript 和 TypeScript 繫結提供支援，並感謝他在執行階段與服務 API 方面的工作。

也感謝：

- [Travis McLane](https://github.com/tmclane) — 早期在 Linux 與原生平台方面的大量工作，以及交叉編譯和 macOS 測試
- [Stffabi](https://github.com/stffabi) — 資產伺服器，以及原生 Windows 與 macOS 的基礎架構
- [Zach Botterman (popaprozac)](https://github.com/popaprozac) — 通知、Dock 整合、強制回應視窗與桌面服務
- [Ian VanSchooten (IanVS)](https://github.com/IanVS) — 型別化事件，以及執行階段與選單的改進
- [Lyimmi](https://github.com/Lyimmi) — Linux 相關貢獻
- [mortenolsrud](https://github.com/mortenolsrud) — Android 與 iOS 修正、封裝及行動平台整合
- [Andraz Vrhovec](https://github.com/overlordtm) — Linux 應用程式識別資訊與單一執行個體行為
- [Julian Storer](https://github.com/julianstorer) — macOS 焦點處理、鍵盤快速鍵與桌面行為
- [Simon Thomas](mailto:enquiries@wails.io) — 成長與社群工作

這裡僅列出部分貢獻，並非完整名單。感謝每一位貢獻程式碼、審查變更、測試版本、翻譯文件或協助其他使用者的人。

## 特別致謝

- [John Chadwick](https://github.com/jchv) — 他在[go-webview2](https://github.com/jchv/go-webview2)與[go-winloader](https://github.com/jchv/go-winloader)方面的傑出工作，讓 Windows 版本得以實現。
- [Tad Vizbaras](https://github.com/tadvi) — 他的 winc 專案是 Wails 邁向純 Go 實作的第一步。
- [Mat Ryer](https://github.com/matryer) — 感謝他的建議、支援與幽默交流。
- [Byron Chris](https://github.com/bh90210) — 感謝他長期以來對本專案的貢獻。
- [Dustin Krysak](https://wiki.ubuntu.com/bashfulrobot) — 他的支援與意見回饋極其寶貴。
- [Justen Walker](https://github.com/justenwalker/) — 感謝他協助處理棘手的 COM 問題，讓v2順利完成。
- [Wang, Chi](https://github.com/patr0nus/) — DeskGap 專案對 Wails v2的發展方向影響深遠。
- [Serge Zaitsev](https://github.com/zserge) — 儘管 Wails 並未使用 Webview 專案，它仍是靈感來源。
