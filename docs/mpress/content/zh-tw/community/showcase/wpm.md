![wpm 螢幕截圖](/assets/showcase-images/wpm.png)

一款 Windows 桌布應用程式，支援自訂桌布、多螢幕，以及隨機或依序切換桌布。

Windows 內建的投影片功能無法直接從多個資料夾選取圖片，必須先合併圖片。wpm 允許選擇多個資料夾，或為不同螢幕指定不同資料夾，並可依據各螢幕的長寬比隨機選擇合適的桌布。
