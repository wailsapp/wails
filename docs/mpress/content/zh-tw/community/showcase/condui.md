Condui 是一款 SSH 連線管理工具，支援端對端加密的多裝置同步。它能在您使用的所有裝置之間同步連線、SSH 通道及受保管庫保護的認證資料，且同步伺服器絕不會看到您的明文認證資料。

主要功能

- 🔐 使用端對端加密的保管庫，保護 SSH 密碼和私密金鑰複雜密碼
- 🔄 在多部裝置之間同步連線、資料夾和 SSH 通道
- 🌐 為每個連線持久保存本機連接埠轉送通道
- 🖥️ 整合式終端機、SFTP、Docker 和資料庫工具
- 💻 支援 macOS、Windows 和 Linux
