**[Zentro](https://zentro-ide.com)** 是適用於 PostgreSQL、MySQL、SQL Server 與 SQLite 的 **以專案為中心的桌面 SQL IDE** ，以 **Go、Wails v2 與 React**打造。每個專案都清楚自己指向哪個環境，在執行任何無法復原的操作之前，Zentro 都會先詢問，因此原本要給測試環境的查詢不會落到正式環境。

## 主要亮點

- **環境感知** - 專案內建環境（開發、測試、正式），並有醒目的正式環境標示、陳述式風險分級，以及破壞性寫入前的受影響資料列預覽
- **SQL 編輯器** - 依結構描述提示的自動完成、行內診斷與快速修正
- **結構描述瀏覽器與 ERD** - 瀏覽資料表、欄位、索引鍵與索引，並將關聯視覺化
- **以 Git 為基礎的追蹤** - 已儲存的指令碼與結構描述快照像程式碼一樣進行版本管理，並有歷程記錄與差異比較
- **SSH 通道與內建終端機** - 透過通道連線資料庫，並在查詢旁保留本機或 SSH 終端機
- **使用自己金鑰的 AI 助理** - 連線到你設定的模型端點，絕不經過 Zentro 營運的伺服器，並提供給外部代理程式使用的 MCP 伺服器
- **鍵盤優先** - 在瀏覽器與結果表格中以焦點導覽，提供命令面板與組合鍵序列
- **預設即保有隱私** - 資料庫憑證儲存在作業系統的金鑰鏈中

Zentro 為 Windows、macOS 與 Linux 的每個平台提供單一原生執行檔。核心採 GPL-3.0 開放原始碼，選用的付費 Pro 方案另外提供正式環境防護等功能，並有 30 天免費試用；Community Edition 的原始碼是公開的。
