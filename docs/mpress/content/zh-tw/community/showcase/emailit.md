[EmailIt](https://github.com/raguay/EmailIt/) 是一個 Wails 2 程式，這是一款以 Markdown 為基礎、僅用於傳送電子郵件的工具，附帶九個記事本、用於處理文字的指令碼和範本。它還提供指令碼終端機，可在 EmailIt 中對系統裡的檔案執行指令碼。您可以直接從命令列使用這些指令碼和範本，也可以透過 Alfred、Keyboard Maestro、Dropzone 或 PopClip 擴充功能使用。它還支援從 GitHub 下載的指令碼和佈景主題。文件尚不完整，但程式可以運作。它使用 Wails2 和 Svelte 建置，下載項目是通用 macOS 應用程式。
