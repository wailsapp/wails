參考 Burp Suite Repeater 的桌面端 HTTP 請求重放工具。編輯原始 HTTP 報文，按原樣透過 TCP/TLS socket 傳送，並為每個分頁保留歷史——不需要啟動代理，也不需要 JVM。支援匯入 curl/fetch 片段、按分頁設定下游代理，還可以用你自己的 LLM 端點產生請求和 payload。基於 Wails v2、Go、Vue 3 與 CodeMirror 6 建構；Apache-2.0。

[在 GitHub 上檢視](https://github.com/chenshiyi007/HttpRepeater)
