[Tiny RDM](https://redis.tinycraft.cc/) 是一款開放原始碼的現代化輕量級 Redis 圖形化使用者介面應用程式。它具備美觀的使用者介面與直覺易用的 Redis 資料庫管理功能，並相容於 Windows、Mac 和 Linux。它提供視覺化的鍵值資料操作、支援多種資料解碼與檢視方式、內建可執行命令的主控台、慢速日誌查詢等功能。
