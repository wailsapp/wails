MyGit 是一款以 worktree 為核心的桌面 Git 用戶端，使用 Wails 3、Go 與 React 打造。它把多個儲存庫依 root 組織在一起，每個 worktree 各自成為一個分頁，並在同一個原生視窗中整合了提交歷史、diff 與 blame、完整的 Git 操作、多分頁 PTY 終端，以及由 AI 產生的提交訊息。
