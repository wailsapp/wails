![Clip 螢幕截圖](/assets/showcase-images/clip.png)

- **三欄版面配置**：訂閱來源/資料夾樹狀結構 · 文章清單 · 閱讀檢視
- **訂閱管理**：新增訂閱來源、以資料夾整理、匯入/匯出 OPML
- **排程擷取**：解析 RSS / Atom，並在背景自動更新
- **專注閱讀**：全文閱讀檢視 + 不受干擾的專注模式
- **快速搜尋**：對標題、摘要和筆記進行全域全文搜尋
- **筆記**：為文章附加筆記，方便日後回顧
- **桌面通知**：新文章提醒、macOS Dock / Windows 工作列徽章
- **鍵盤操作**：提供完整的快速鍵
- **佈景主題與多語言**：淺色 / 深色 / 跟隨系統，支援多種語言
- **效能與離線使用**：輕量化清單查詢、本機快取、離線閱讀
