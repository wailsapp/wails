Lyyyra 是一款使用 Wails、Go 和 React 打造的桌面歌本應用程式。它會從 evangelickyzpevnik.cz 下載歌詞、中繼資料和樂譜 PDF，之後讓你離線搜尋、篩選和排序收藏。

主要功能：

- 對標題、作者和歌詞進行全文搜尋
- 依歌曲編號、標題、作曲者和作詞者排序
- 「已準備樂譜」面板，可收集歌曲並匯出為一個合併的 PDF
- 首次下載後可離線使用的本機資料庫
- 提供適用於 Windows 和 Linux 的預先建置二進位檔

[在 GitHub 上查看](https://github.com/tomvladik/Lyyyra)
