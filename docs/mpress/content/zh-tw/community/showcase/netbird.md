[NetBird](https://netbird.io/) 將免設定、以 WireGuard 為基礎的點對點私人網路與集中式存取控制系統結合，讓你輕鬆為組織或住家建立安全的私人網路。

其桌面應用程式使用 Wails 從零重新打造，提供包含基本功能的精簡預設檢視，以及可展開的進階模式，用於瀏覽對等節點和資源。獨立的設定視窗讓你能夠管理多個設定檔並設定用戶端，所有功能皆可在 macOS、Windows 和 Linux 上原生執行。

如需進一步瞭解圖形介面，請閱讀[部落格文章](https://netbird.io/knowledge-hub/new-desktop-app-release-candidate)，或在 GitHub 上查看[原始碼](https://github.com/netbirdio/netbird/tree/main/client/ui)。
