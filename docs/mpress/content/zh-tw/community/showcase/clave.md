主要功能

- 🎨 簡潔直覺的設計，帶來輕鬆順暢的使用體驗
- ✅ 可透過手動輸入或匯入 QR Code 圖片，輕鬆新增帳號。
- 🔒 使用 PIN 碼或 Touch ID（僅限 macOS）進行端對端加密。
- 💻 支援 macOS、Windows 和 Linux
- ⚡ 可從系統匣快速存取，方便使用
- 📂 輕鬆備份及還原您的設定檔
