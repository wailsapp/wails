Larvyn 是一款為 Laravel 開發者打造的桌面工作台，支援 Linux、macOS 和 Windows。它將你的 Laravel 應用程式、開發服務（artisan serve、Vite、佇列、Reverb 等）、真正的終端機、資料庫、Tinker、測試、日誌和 AI 程式代理整合在一個原生視窗中。

可同時啟動 Claude Code、Codex、OpenCode、Cursor Agent、Aider 等代理，每個都在獨立的 git worktree 中執行，接著比較差異並合併最佳結果。使用 Wails 3、Go 和 React 打造。

[官方網站](https://larvyn.dev) | [GitHub 發行版](https://github.com/larvyn/releases)
