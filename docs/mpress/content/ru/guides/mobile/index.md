Wails v3 работает на **iOS и Android** с теми же `main.go` и фронтендом, которые вы уже создаёте для настольных платформ. Не нужны ни отдельный мобильный проект, ни мост для совместного использования кода, ни переписывание: бинарный файл Go компилируется для целевой мобильной платформы, а нативный WebView отображает существующий фронтенд.

@cards{cols="2"}
iOS
Хост на базе WKWebView и UIKit. Ресурсы предоставляются через пользовательскую схему `wails://` — без открытых портов. Требуется **macOS** с полной версией Xcode.

[Руководство по iOS →](/guides/mobile/ios/)

---
Android
Android WebView + `WebViewAssetLoader`. Код Go компилируется как `libwails.so` с помощью NDK. Работает в macOS, Linux и Windows.

[Руководство по Android →](/guides/mobile/android/)

@end

## Посмотрите в действии: пример Kitchen Sink

Лучший способ понять доступные возможности — изучить **Kitchen Sink**: единое приложение Wails, которое одинаково работает на iOS, Android и настольных платформах из одной кодовой базы:

@linkcard{title="Мобильный Kitchen Sink — GitHub" href="https://github.com/wailsapp/wails/tree/v3.0.0/v3/examples/mobile" description="Привязки · События · Диалоговые окна · Тактильная отдача · Геолокация · Биометрия · Уведомления · Защищённое хранилище · и многое другое — всё из одного main.go"}
В нём на 7 вкладках показаны все основные мобильные API — и оно также работает на настольных платформах. Вкладки **Мобильные функции** и **Оборудование** скрываются на настольных платформах с помощью проверки платформы во фронтенде; при сборке для настольной платформы сторона Go не регистрирует обработчики мобильных событий `common:*`. Это рекомендуемый подход к выпуску одной кодовой базы для всех платформ.

| Вкладка | Платформы | Что демонстрирует |
| --- | --- | --- |
| **Привязки** | все | Вызовы сервисов из JS в Go с возвратом значений, структур и ошибок |
| **События** | все | Часы из Go в JS, ping/pong из JS в Go и обратно в JS, системные события ОС (батарея, сеть, тема) |
| **Диалоговые окна** | все | Нативные диалоговые окна сообщений на каждой платформе |
| **Система** | все | Буфер обмена, параметры экрана, сведения об устройстве |
| **Мобильные функции** | iOS + Android | Меню «Поделиться», предотвращение перехода в спящий режим, фонарик, яркость, биометрия, локальные уведомления, защищённое хранилище |
| **Оборудование** | iOS + Android | Тактильная отдача, геолокация, акселерометр, датчик приближения, синтез речи |
| **Нативные функции** | iOS + Android | iOS: тактильная отдача + переключатели WKWebView · Android: вибрация + всплывающие сообщения |

Чтобы запустить пример самостоятельно:

```bash
git clone https://github.com/wailsapp/wails.git
cd wails/v3/examples/mobile

wails3 task ios:run        # iOS Simulator (macOS + Xcode required)
wails3 task android:run    # Android Emulator
wails3 task run            # Desktop
```

## Как это работает

На всех платформах используется одна и та же модель приложения:

1. **Бэкенд Go** — ваши сервисы, обработчики событий и логика приложения без изменений компилируются для `GOOS=ios` и `GOOS=android`.
2. **Фронтенд** — в точности тот же HTML/JS/CSS. Пакет `@wailsio/runtime` работает одинаково; привязки сервисов, события, диалоговые окна и буфер обмена используют один и тот же внутрипроцессный транспорт.
3. **Хост WebView** — на iOS это `WKWebView` внутри `UIViewController`, а на Android — `WebView` внутри `Activity`. Wails автоматически настраивает мост обмена сообщениями.
4. **Внутрипроцессное предоставление ресурсов** — ресурсы предоставляются непосредственно из памяти Go, а не сервером localhost. Нет ни открытых портов, ни loopback-подключений, ни дополнительной задержки.

Поведение, специфичное для платформы, размещается в файлах, защищённых условиями `//go:build ios` или `//go:build android`, поэтому общий код остаётся чистым.

## Краткий обзор предварительных требований

| Требование | iOS | Android |
| --- | --- | --- |
| Операционная система | Только macOS | macOS, Linux, Windows |
| Набор инструментов | Полная версия Xcode (не только инструменты командной строки) | Android SDK + NDK 26.3.x + JDK |
| Go | 1.25+ | 1.25+ |
| npm | ✅ | ✅ |
| Команда для проверки | `wails3 doctor` | `wails3 doctor` |

@note{type="tip"}
После настройки набора инструментов выполните `wails3 doctor` — команда точно покажет, что найдено и чего не хватает для каждой платформы.

@end

| Диалоговые окна сообщений | ✅ UIAlertController | ✅ AlertDialog |
| Диалоговые окна открытия файлов | ✅ UIDocumentPicker | ✅ Storage Access Framework |
| Диалоговые окна сохранения файлов | ❌ вместо этого выполняйте запись в песочницу | ❌ вместо этого выполняйте запись в песочницу |
| Буфер обмена | ✅ UIPasteboard | ✅ ClipboardManager |
| Параметры экранов и безопасных областей | ✅ | ✅ |

## Правила тегов сборки

При написании платформозависимого кода учитывайте два важных правила:

- **`ios` подразумевает `darwin`** — файл с тегом `//go:build darwin` также будет компилироваться для iOS. Чтобы предназначить код только для macOS, используйте `//go:build darwin && !ios`.
- **`android` подразумевает `linux`** — файл с тегом `//go:build linux` также будет компилироваться для Android. Чтобы предназначить код только для настольного Linux, используйте `//go:build linux && !android`.

Во время выполнения `runtime.GOOS` возвращает соответственно `"ios"` и `"android"`.

## Определение платформы во время выполнения

Теги сборки предназначены для кода, который можно *скомпилировать* только на определённой платформе. Для обычного ветвления в общем коде используйте `application.System` — эта возможность доступна в каждой сборке (теги сборки не нужны), поэтому один и тот же файл работает везде:

```go
import "github.com/wailsapp/wails/v3/pkg/application"

if application.System.IsMobile() {
    // iOS or Android
} else if application.System.IsDesktop() {
    // macOS, Windows or Linux
}

// Or test a single target directly:
if application.System.IsPlatform(application.PlatformIOS) {
    // iOS only
}
```

Доступны: `IsMobile()`, `IsDesktop()`, `IsServer()` (тег сборки `server`) и `IsPlatform(application.PlatformMacOS | PlatformWindows | PlatformLinux | PlatformIOS | PlatformAndroid | PlatformServer)`.

Во фронтенде соответствующие вспомогательные функции находятся в `@wailsio/runtime`:

```js
import { System } from "@wailsio/runtime";

if (System.IsMobile()) { /* iOS or Android */ }
if (System.IsIOS()) { /* … */ }      // also IsAndroid, IsMac, IsWindows, IsLinux, IsDesktop
```
