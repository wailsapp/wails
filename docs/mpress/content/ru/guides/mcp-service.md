@note{type="caution" title="Экспериментальная функция"}
Встроенный сервер MCP является экспериментальным, и его API может измениться в будущих выпусках.

@end

В Wails v3 есть встроенный сервер [Model Context Protocol](https://modelcontextprotocol.io) (MCP), который позволяет LLM-агентам — Claude Code, помощникам в IDE и любым клиентам MCP — исследовать, тестировать и контролировать **работающее** приложение Wails.

Для автоматизации жизненного цикла проекта используйте отдельный сервер CLI `wails3 mcp`. Он позволяет агентам исследовать и инициализировать проекты, запускать диагностику, сборки и задачи разработки, генерировать привязки, выполнять именованные задачи Taskfile и получать ограниченный объём вывода заданий. По умолчанию сервер CLI работает только в пределах текущего каталога и не предоставляет возможность выполнять произвольные команды оболочки. Сведения о транспорте, аутентификации и инструментах см. в [документации по MCP для CLI](/guides/cli/#mcp).

После включения этой функции подключённый к приложению агент может:

- **Получать список окон и управлять ими** — изменять размер и положение, переводить фокус, включать полноэкранный режим, открывать инструменты разработчика, перезагружать и т. д.
- **Исследовать DOM** — находить элементы, получать HTML и создавать структурный снимок
- **Выполнять JavaScript** — запускать произвольный код в любом окне и получать результат
- **Имитировать пользовательский ввод** — перемещать указатель мыши, выполнять щелчки, перетаскивание и прокрутку с отображением **анимированного экранного курсора**, чтобы вы могли наблюдать за работой агента
- **Вводить текст и нажимать клавиши** — реалистичные события для каждого символа работают с управляемыми полями ввода React
- **Вызывать привязанные методы Go**, а также отправлять события приложения и ожидать их

## Как это работает

Сервер MCP компилируется в приложение только при наличии **тега сборки `mcp`**. Без этого тега код сервера полностью отсутствует в исполняемом файле: нет ни накладных расходов во время выполнения, ни открытых портов, ни дополнительной поверхности атаки.

При наличии тега сервер автоматически запускается внутри `App.Run()`, по умолчанию привязывается к `127.0.0.1:9099` и записывает свою конечную точку в журнал. Пользовательский код не требуется.

## Руководство

### Шаг 1 — создайте обычное приложение Wails

MCP не требует ни импорта пакетов, ни регистрации. Создайте приложение обычным способом:

```go {title="main.go"}
package main

import (
    "embed"
    "log"

    "github.com/wailsapp/wails/v3/pkg/application"
)

//go:embed assets
var assets embed.FS

func main() {
    app := application.New(application.Options{
        Name: "My App",
        Assets: application.AssetOptions{
            Handler: application.BundledAssetFileServer(assets),
        },
    })

    app.Window.NewWithOptions(application.WebviewWindowOptions{
        Title: "My App",
        Width: 1024, Height: 768,
    })

    if err := app.Run(); err != nil {
        log.Fatal(err)
    }
}
```

### Шаг 2 — соберите или запустите приложение с тегом `mcp`

@tabs
[Wails CLI (рекомендуется)]
Задайте `WAILS_MCP=1`, и Wails CLI автоматически добавит тег `mcp`:

```shell
# Development
WAILS_MCP=1 wails3 dev

# Production build
WAILS_MCP=1 wails3 build
```

[Непосредственно через Go]
Передайте тег непосредственно команде `go run` или `go build`:

```shell
go run -tags mcp .
go build -tags mcp -o myapp .
```

[Windows (PowerShell)]
```powershell
$env:WAILS_MCP = "1"
wails3 dev
# or
wails3 build
```

@end

При запуске приложение записывает в журнал конечную точку MCP:

```
INFO MCP server started. Connect MCP clients using the streamable HTTP transport.
     url=http://127.0.0.1:9099/mcp
```

### Шаг 3 — подключите клиент

Сервер использует **потоковый HTTP-транспорт MCP**. Подключитесь с помощью любого клиента, совместимого с MCP.

@tabs
[Claude Code]
```shell
claude mcp add --transport http my-app http://127.0.0.1:9099/mcp
```

Затем попросите Claude взаимодействовать с вашим приложением:

```
Click the "Submit" button, then verify a success toast appears.
```

[VS Code (GitHub Copilot)]
Добавьте в `.vscode/settings.json`:

```json
{
  "github.copilot.chat.mcp.enabled": true,
  "mcp": {
    "servers": {
      "my-wails-app": {
        "type": "http",
        "url": "http://127.0.0.1:9099/mcp"
      }
    }
  }
}
```

[Другие клиенты]
Укажите следующую конечную точку в любом клиенте MCP, поддерживающем потоковый HTTP-транспорт:

```
http://127.0.0.1:9099/mcp
```

@end

### Шаг 4 — проведите сеанс тестирования

Попросите агента проверить работу вашего приложения. Вот несколько примеров запросов:

```
Take a DOM snapshot of the main window.
```

```
Click the "Add item" button, type "Hello world" in the input field,
then press Enter and verify the item appears in the list.
```

```
Call the bound method main.GreetService.Greet with argument ["World"]
and return the result.
```

```
Wait for the event "save:complete" while clicking the Save button.
```

## Конфигурация

Вся конфигурация задаётся переменными окружения — изменять код не требуется.

| Переменная окружения | Значение по умолчанию | Описание |
| --- | --- | --- |
| `WAILS_MCP` | (не задано) | Установите значение `1`, `true`, `on` или `yes`, чтобы при использовании Wails CLI автоматически добавлялся тег сборки `mcp`. |
| `WAILS_MCP_HOST` | `127.0.0.1` | Интерфейс для привязки. Для привязки не к loopback-интерфейсу требуется `WAILS_MCP_TOKEN`. |
| `WAILS_MCP_TOKEN` | не задано | Необязательный bearer-токен при использовании loopback-интерфейса; обязателен для других адресов привязки. Клиенты отправляют `Authorization: Bearer <token>`. |
| `WAILS_MCP_PORT` | `9099` | Порт для прослушивания. Установите значение `0`, чтобы использовать случайно назначенный свободный порт (он будет указан в журнале). |
| `WAILS_MCP_TIMEOUT` | `30000` | Стандартный тайм-аут выполнения JavaScript в **миллисекундах**. |
| `WAILS_MCP_HIDE_CURSOR` | (не задано) | Установите значение `1` или `true`, чтобы отключить наложение анимированного курсора. |

Пример: пользовательский порт и тайм-аут 60 секунд:

```shell
WAILS_MCP=1 WAILS_MCP_PORT=9200 WAILS_MCP_TIMEOUT=60000 wails3 dev
```

## Доступные инструменты

| Инструмент | Назначение |
| --- | --- |
| `app_info` | Сведения о приложении: платформа, архитектура, все окна и конечная точка MCP |
| `windows_list` | Получение списка всех окон с их геометрией и состоянием |
| `window_control` | Перевод фокуса, изменение размера и положения, полноэкранный режим, инструменты разработчика, перезагрузка, задание URL и т. д. (действия 22) |
| `js_eval` | Выполнение JavaScript в окне (асинхронное тело, `return` для значения) |
| `dom_html` | Получение HTML страницы или определённого элемента |
| `dom_query` | Поиск элементов по селектору CSS — тег, текст, границы и видимость |
| `screenshot_dom` | Структурный снимок видимой страницы (на основе DOM, без пикселей) |
| `mouse_move` | Анимированное перемещение курсора в указанную точку или к элементу по селектору CSS |
| `mouse_click` | Щелчок с анимированным курсором (левой, правой или средней кнопкой; двойной щелчок; клавиши-модификаторы) |
| `mouse_drag` | Перетаскивание с анимированным курсором (поддерживаются элементы с перетаскиванием HTML5) |
| `mouse_scroll` | Прокрутка в указанной точке или на элементе |
| `keyboard_type` | Посимвольный ввод текста с реалистичными событиями |
| `keyboard_press` | Нажать одну клавишу (Enter, Tab, Escape, ArrowDown, …), при необходимости с модификаторами |
| `call_bound_method` | Вызвать метод привязанного сервиса Go, например `main.GreetService.Greet` |
| `emit_event` | Отправить событие приложения Wails |
| `wait_for_event` | Дождаться события приложения Wails и вернуть его данные |

### Поддержка нескольких окон

Все инструменты, работающие с окном, принимают необязательный аргумент `window`, содержащий **имя** окна (задаётся через `WebviewWindowOptions.Name`). Если аргумент не указан, инструмент обращается к окну, находящемуся сейчас в фокусе, а если ни одно окно не в фокусе — к первому окну.

```
List all windows, then click the "New" button in the window named "editor".
```

### Выбор элементов

Инструменты для работы с мышью и клавиатурой принимают один из следующих вариантов:

- **CSS-селектор** — `selector: "#submit-btn"` (элемент автоматически прокручивается в область видимости)
- **Координаты** — `x: 400, y: 300` (в CSS-пикселях относительно области просмотра)

Для операций перетаскивания используйте префиксы `from_` и `to_`:

```
Drag from selector: ".card" to selector: ".dropzone"
```

## Безопасность

@note{type="caution"}
Сервер MCP предоставляет полный программный контроль над вашим приложением. Любой, кто имеет доступ к его инструментам, может читать DOM, выполнять JavaScript, нажимать кнопки и вызывать методы Go.

@end

- По умолчанию сервер привязывается к `127.0.0.1`. Источники браузера должны быть loopback-источниками HTTP(S); непрозрачные (`null`), некорректные и внешние источники отклоняются.
- Нативные клиенты MCP без заголовков по-прежнему поддерживаются. Если `WAILS_MCP_TOKEN` не задан, локальные процессы и разрешённые локальные источники браузера считаются доверенными; проверка источника не является аутентификацией. Задайте токен с высокой энтропией, чтобы требовать аутентификацию по токену Bearer для всех вызовов `/mcp`. Укажите тот же токен в заголовке клиента `Authorization: Bearer <token>`. Для предварительных запросов токен не требуется.
- Обратный вызов `/eval-result` использует непредсказуемые идентификаторы, уникальные для каждого вычисления, а не клиентский токен Bearer, поэтому передача результатов в webview остаётся совместимой.
- Рабочие сборки **не должны** включать тег `mcp`. CLI Wails добавляет его, только когда явно задано `WAILS_MCP=1`, а стандартная сборка `wails3 build` не содержит кода сервера.
- Если сервер необходимо открыть на интерфейсе, отличном от loopback (например, для тестирования в локальной сети), задайте `WAILS_MCP_HOST=0.0.0.0` и `WAILS_MCP_TOKEN` с высокой энтропией; без токена запуск завершится ошибкой. В недоверенных сетях используйте зашифрованный туннель или прокси-сервер с терминацией TLS, поскольку встроенный сервер прослушивает HTTP.

## Пример приложения

Полное демонстрационное приложение, показывающее работу всех инструментов, доступно по адресу [`v3/examples/mcp`](https://github.com/wailsapp/wails/tree/v3.0.0/v3/examples/mcp). Оно включает:

- Счётчик с кнопками увеличения и сброса
- Поле ввода имени с привязанными методами Greet, Add и Shout
- Источник и цель перетаскивания HTML5
- Прокручиваемый список (50 элементов)
- Журнал событий

Запустите его следующей командой:

```shell
cd v3/examples/mcp
go run -tags mcp .
```

Затем подключите Claude Code или любой клиент MCP к `http://127.0.0.1:9099/mcp` и попросите его протестировать интерфейс.

## Обратная связь

Встроенный сервер MCP — экспериментальная функция, и от ваших отзывов зависит её дальнейшее развитие. Если вы её опробуете, мы будем рады узнать, какие клиент и инструменты вы использовали, чего ожидали и что произошло на самом деле, а также оказалось ли полезным управление приложением с помощью агента. Самые полезные отчёты точно указывают, что именно запускалось. Расскажите нам об этом в обсуждении [отзывов о сервере MCP](https://github.com/wailsapp/wails/discussions/5692).
