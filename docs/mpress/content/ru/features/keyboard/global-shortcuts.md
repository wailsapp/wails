Глобальные сочетания клавиш действуют во всей системе и срабатывают независимо от того, какое приложение сейчас находится в фокусе, пока работает ваше приложение Wails. Они идеально подходят для показа и скрытия приложения, инструментов быстрого захвата, управления мультимедиа и других функций, которые должны быть доступны пользователям отовсюду.

@note{type="info" title="Глобальные сочетания клавиш и привязки клавиш"}
[Привязки клавиш](/features/keyboard/shortcuts/) (`app.KeyBinding`) срабатывают, только когда одно из окон вашего приложения находится в фокусе. Глобальные сочетания клавиш (`app.GlobalShortcut`) действуют во всей системе, даже когда приложение работает в фоновом режиме. Выберите подходящий вариант в зависимости от задачи.

@end

Глобальные сочетания клавиш реализованы непосредственно на основе нативных средств каждой платформы и не добавляют сторонних зависимостей.

## Доступ к диспетчеру глобальных сочетаний клавиш

Диспетчер доступен через свойство `GlobalShortcut` экземпляра вашего приложения:

```go
app := application.New(application.Options{
    Name: "Global Shortcuts Demo",
})

globalShortcuts := app.GlobalShortcut
```

## Регистрация сочетания клавиш

`Register` принимает акселератор и функцию обратного вызова. При каждом нажатии сочетания клавиш функция обратного вызова выполняется в отдельной горутине.

```go
err := app.GlobalShortcut.Register("CmdOrCtrl+Shift+G", func() {
    // Runs even when another application is focused.
    window.Show()
    window.Focus()
})
if err != nil {
    app.Logger.Error("could not register shortcut", "error", err)
}
```

Сочетания клавиш можно зарегистрировать до вызова `app.Run`. В этом случае привязка средствами операционной системы автоматически выполняется при запуске приложения.

@note{type="tip" title="Взаимодействие с пользовательским интерфейсом из функции обратного вызова"}
Функции обратного вызова выполняются вне главного потока. Взаимодействие с окнами и другими элементами пользовательского интерфейса через методы окон обрабатывается автоматически, но пользовательские операции, которые должны выполняться в главном потоке, необходимо обернуть в `application.InvokeSync`.

@end

### Формат акселератора

Для глобальных сочетаний клавиш используется тот же формат акселераторов, что и для акселераторов меню и привязок клавиш:

```go
"CmdOrCtrl+Shift+G"  // Command on macOS, Control elsewhere
"Ctrl+Alt+K"         // Control + Alt + K
"Cmd+Option+Space"   // Command + Option + Space (macOS)
"Super+D"            // Super / Windows / Logo key + D
"Ctrl+Shift+F5"      // Function keys are supported
```

`CmdOrCtrl` соответствует Command в macOS и Control в Windows и Linux, что удобно для кроссплатформенных сочетаний клавиш.

## Управление сочетаниями клавиш

```go
// Check whether a shortcut is registered (modifier order does not matter).
registered := app.GlobalShortcut.IsRegistered("Ctrl+Shift+G")

// List every shortcut this application has registered.
for _, accelerator := range app.GlobalShortcut.GetAll() {
    app.Logger.Info("global shortcut", "accelerator", accelerator)
}

// Release a single shortcut.
app.GlobalShortcut.Unregister("Ctrl+Shift+G")

// Release everything (also done automatically on shutdown).
app.GlobalShortcut.UnregisterAll()
```

При завершении работы приложения все зарегистрированные сочетания клавиш освобождаются автоматически, поэтому вручную удалять их не требуется.

## Что происходит при повторной регистрации одного сочетания клавиш

Возможны два разных случая, которые Wails обрабатывает по-разному.

### Одно приложение дважды регистрирует сочетание клавиш

Этот случай обрабатывается самим Wails одинаково на всех платформах. Второй вызов `Register` возвращает ошибку, а исходная привязка сохраняется («ошибка с сохранением»). Благодаря этому поведение остаётся предсказуемым, а ошибка становится явной вместо незаметной замены работающего сочетания клавиш.

```go
app.GlobalShortcut.Register("Ctrl+Shift+G", showWindow)        // ok
err := app.GlobalShortcut.Register("Shift+Ctrl+G", doSomething) // err: already registered
// showWindow is still the active callback for this shortcut.
```

Чтобы изменить функцию обратного вызова для сочетания клавиш, сначала выполните для него `Unregister`, а затем снова `Register`.

### Сочетание клавиш уже занято другим приложением

Этот случай обрабатывает операционная система, поэтому результат зависит от платформы:

| Платформа | Поведение, если сочетание клавиш занято другим приложением |
| --- | --- |
| **macOS** | Регистрация завершается успешно. macOS позволяет нескольким приложениям регистрировать одно и то же сочетание клавиш, поэтому ваша функция обратного вызова добавляется наряду с функцией существующего владельца, а не отклоняется. |
| **Windows** | Регистрация завершается сбоем, а `Register` возвращает ошибку. Сочетание клавиш остаётся у приложения, которое зарегистрировало его первым. |
| **Linux (X11)** | Регистрация завершается сбоем, а `Register` возвращает ошибку, поскольку X-сервер отклоняет повторный захват того же сочетания. |
| **Linux (Wayland)** | Решение принимает композитор. Обычно пользователю предлагается подтвердить или выбрать привязку в диалоговом окне глобальных сочетаний клавиш среды рабочего стола. |

Из-за этих различий всегда проверяйте ошибку, возвращаемую `Register`, и предусматривайте резервное сочетание клавиш или уведомление пользователя на случай, если зарегистрировать сочетание не удаётся.

## Особенности платформ

@tabs
[macOS]
Для глобальных сочетаний клавиш используется API горячих клавиш Carbon Event Manager. Это стандартный механизм общесистемных сочетаний клавиш в macOS, который не требует разрешения на универсальный доступ.

Сочетания с буквами учитывают раскладку. API Carbon выполняет привязку к физическим позициям клавиш, поэтому Wails преобразует букву в клавишу, которая вводит её в активной раскладке клавиатуры (через `UCKeyTranslate`). Поэтому `Cmd+A` соответствует клавише с обозначением **A** в раскладках AZERTY, QWERTZ, Dvorak и аналогичных, а не позиции этой клавиши в QWERTY. Цифры, знаки препинания и именованные клавиши (стрелки, функциональные клавиши и т. п.) используют свои фиксированные физические позиции. Привязка определяется при регистрации сочетания клавиш. Если изменить раскладку клавиатуры во время работы приложения, существующие сочетания с буквами сохранят физическую клавишу, к которой они были изначально привязаны.

@note{type="caution" title="Скрытие окна с помощью сочетаний клавиш и `ApplicationShouldTerminateAfterLastWindowClosed`"}
В macOS `window.Hide()` использует `orderOut:`, в результате чего окно становится невидимым. AppKit считает последнее невидимое окно закрытым, поэтому, если задать `Mac.ApplicationShouldTerminateAfterLastWindowClosed: true` и скрыть единственное окно с помощью глобального сочетания клавиш, приложение завершит работу, а не останется в фоновом режиме. Если вы используете сочетание клавиш для скрытия и показа окна, не задавайте этот параметр (по умолчанию он не задан), чтобы окно можно было скрыть, а затем снова вызвать.

@end

[Windows]
Для глобальных сочетаний клавиш используется API Win32 `RegisterHotKey`. Автоповтор подавляется, поэтому при удержании клавиш функция обратного вызова срабатывает один раз, а не многократно.

Если сочетание уже занято другим приложением, регистрация завершается сбоем, поэтому в качестве сочетаний по умолчанию выбирайте менее распространённые варианты.

[Linux]
В сеансах **X11** Wails захватывает сочетание клавиш непосредственно у X-сервера, поэтому запрошенный акселератор привязывается в точности как указано.

В сеансах **Wayland** приложениям намеренно не предоставляется возможность напрямую захватывать клавиши. Вместо этого Wails использует интерфейс XDG Desktop Portal `org.freedesktop.portal.GlobalShortcuts`. При работе через портал переданный акселератор является *предпочтительным* триггером, а окончательное сочетание клавиш определяет композитор и, в конечном счёте, пользователь. При активации сочетания ваша функция обратного вызова по-прежнему срабатывает, однако точное совпадение клавиш с запросом не гарантируется, а `IsRegistered`/`GetAll` сообщают о запрошенном вами сочетании, а не о привязанном композитором.

Для работы портала требуется среда рабочего стола, реализующая портал глобальных сочетаний клавиш (например, современные версии GNOME или KDE Plasma).

@end

## Полный пример

```go
package main

import (
    "log"

    "github.com/wailsapp/wails/v3/pkg/application"
)

func main() {
    app := application.New(application.Options{
        Name: "Global Shortcuts Demo",
    })

    window := app.Window.New()

    // Bring the window to the front from anywhere.
    if err := app.GlobalShortcut.Register("CmdOrCtrl+Shift+G", func() {
        window.Show()
        window.Focus()
    }); err != nil {
        log.Printf("could not register show shortcut: %v", err)
    }

    // Hide the window from anywhere.
    if err := app.GlobalShortcut.Register("CmdOrCtrl+Shift+H", func() {
        window.Hide()
    }); err != nil {
        log.Printf("could not register hide shortcut: %v", err)
    }

    if err := app.Run(); err != nil {
        log.Fatal(err)
    }
}
```

@note{type="danger" title="Не используйте критически важные системные сочетания клавиш"}
Некоторые сочетания зарезервированы операционной системой или средой рабочего стола, поэтому приложения не могут их занять. Выбирайте сочетания по умолчанию с низкой вероятностью конфликта и всегда обрабатывайте ошибку от `Register`.

@end
