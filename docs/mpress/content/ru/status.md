## Wails v3.0.0 — Стабильная версия

Актуальную информацию см. в [журнале изменений](/changelog/).

Эта документация описывает Wails v3.0.0. Исправления ошибок получают приоритет по серьёзности и выпускаются в ночных корректирующих обновлениях. Новые возможности предназначены для v3.1.0; исправления ошибок не включаются в этот функциональный выпуск.

## Совместимость настольных приложений

Гарантии совместимости v3.0.0 распространяются на настольные приложения:

| Платформа | Поддерживаемые целевые архитектуры | Требования и примечания |
| --- | --- | --- |
| Windows | amd64 и arm64 | Среда выполнения WebView2 |
| macOS | Intel и Apple Silicon | Версии macOS и WebKit, указанные в руководстве по установке |
| Linux | amd64 и arm64 | По умолчанию — GTK4 + WebKitGTK 6.0; GTK3 + WebKit2GTK 4.1 остаётся устаревшим вариантом, выбираемым с помощью флага `-tags gtk3`, до версии v3.0.x включительно и удаляется в v3.1 |

Для разработки под все целевые платформы требуется Go 1.25 или более поздняя версия. Поддержка Android и iOS остаётся экспериментальной и не входит в гарантии совместимости стабильных настольных приложений.

## Как вы можете помочь

- Тестируйте Wails v3.0.0 и сообщайте о воспроизводимых ошибках
- Участвуйте в подготовке документации и примеров
- Участвуйте в обсуждениях и оставляйте отзывы о проектах WEP
- Отправляйте pull request с исправлениями ошибок, изменениями документации или реализацией принятых WEP

Мы приветствуем вклад сообщества. Если вы хотите помочь в достижении этих целей, присоединяйтесь к обсуждениям сообщества. Новые возможности следует предлагать в pull request с WEP, а не в issue с запросом функции.

## Обратная связь и обновления

Этот план развития может изменяться с учётом отзывов сообщества и приоритетов проекта. Мы будем регулярно обновлять его, отражая достигнутый прогресс и изменения направления развития. Сообщайте о воспроизводимых проблемах в виде issue; новые возможности предлагайте через pull request с [WEP (предложением по улучшению Wails)](https://github.com/wailsapp/wails/blob/releases/v3.0.0/v3/wep/README.md).
