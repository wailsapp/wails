## Текущее состояние: бета-версия

Актуальную информацию см. в [журнале изменений](/changelog/).

Наша цель — выпустить стабильную версию v3.0. В этом плане развития перечислены ключевые возможности и улучшения, которые необходимо реализовать до финального выпуска. Обратите внимание: этот документ постоянно обновляется и может изменяться при смене приоритетов или появлении новых сведений.

## Гарантии совместимости бета-версии

Гарантии для бета-версии v3 распространяются на настольные приложения:

| Платформа | Поддерживаемые целевые архитектуры | Требования и примечания |
| --- | --- | --- |
| Windows | amd64 и arm64 | Среда выполнения WebView2 |
| macOS | Intel и Apple Silicon | Версии macOS и WebKit, указанные в руководстве по установке |
| Linux | amd64 и arm64 | По умолчанию — GTK4 + WebKitGTK 6.0; GTK3 + WebKit2GTK 4.1 остаётся устаревшим вариантом, выбираемым с помощью флага `-tags gtk3`, до версии v3.0.x включительно и удаляется в v3.1 |

Для разработки под все целевые платформы требуется Go 1.25 или более поздней версии. Поддержка Android и iOS является экспериментальной и не препятствует выпуску настольной бета-версии. Цель — обеспечить стабильность API бета-версии, однако до выпуска v3.0.0 ещё могут быть исправлены дефекты предварительных версий и внесены явно объявленные изменения.

## Как вы можете помочь

- Тестируйте последнюю бета-версию и сообщайте о воспроизводимых ошибках
- Участвуйте в подготовке документации и примеров
- Участвуйте в обсуждениях и оставляйте отзывы о проектах WEP
- Отправляйте pull request с исправлениями ошибок, изменениями документации или реализацией принятых WEP

Мы приветствуем вклад сообщества. Если вы хотите помочь в достижении этих целей, присоединяйтесь к обсуждениям сообщества. Новые возможности следует предлагать в pull request с WEP, а не в issue с запросом функции.

## Обратная связь и обновления

Этот план развития может изменяться с учётом отзывов сообщества и приоритетов проекта. Мы будем регулярно обновлять его, отражая достигнутый прогресс и изменения направления развития. Сообщайте о воспроизводимых проблемах в виде issue; новые возможности предлагайте через pull request с [WEP (предложением по улучшению Wails)](https://github.com/wailsapp/wails/blob/master/v3/wep/README.md).
