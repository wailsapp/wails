## Общие вопросы

### Что такое Wails?

Wails — это фреймворк для разработки настольных приложений на Go с использованием веб-технологий. Логика приложения пишется на Go, интерфейс создаётся с помощью HTML, CSS и JavaScript (или любого фронтенд-фреймворка), а Wails отображает его во встроенном браузерном компоненте операционной системы. В результате получается компактное и быстрое приложение, воспринимаемое как нативное: без встроенного браузера, с низким потреблением памяти и в виде одного исполняемого файла, размер которого обычно составляет около 10 МБ.

### Какие платформы поддерживает Wails?

| Платформа | Требования |
| --- | --- |
| Windows | AMD64 и ARM64. Используется среда выполнения [WebView2](https://developer.microsoft.com/microsoft-edge/webview2/). |
| macOS | 10.15+ на компьютерах с процессорами Intel (приложения могут быть рассчитаны на 10.13+), 11.0+ на компьютерах с Apple Silicon. Поддерживаются универсальные исполняемые файлы. |
| Linux | AMD64 и ARM64. По умолчанию используется стек GTK4 с WebKitGTK 6.0 (Ubuntu 24.04+, Debian 13+, Fedora 40+ и аналогичные дистрибутивы). Дистрибутивы, в которых доступен только WebKit2GTK 4.1, например Ubuntu 22.04, Debian 12 и RHEL 9, поддерживаются через устаревшую сборку `-tags gtk3` (доступна до v3.1). Дистрибутивы, в которых доступен только WebKit2GTK 4.0, не поддерживаются. См. [руководство по сборке для Linux](/guides/build/linux/). |
| iOS и Android | Экспериментальная поддержка. См. [руководства по мобильным платформам](/guides/mobile/). |

Приложение также можно развернуть как обычное веб-приложение с помощью [серверной сборки](/guides/server-build/).

В любой момент запустите `wails3 doctor`, чтобы проверить систему и получить инструкции по установке для своей платформы.

### Что нужно для начала работы?

- Go 1.26 или новее
- Node.js и npm (для сборки фронтенда)
- Инструментарий платформы: WebView2 в Windows (предустановлен в 10/11), Xcode Command Line Tools в macOS, `gcc` и пакеты разработки GTK/WebKit в Linux

`wails3 doctor` проверит всё это и точно укажет, чего не хватает. Полное пошаговое руководство см. в разделе [«Установка»](/quick-start/installation/).

### Готов ли Wails v3 к промышленной эксплуатации?

Wails v3.0.0 — стабильный выпуск для настольных приложений в Windows, macOS и Linux. Поддержка Android и iOS остаётся экспериментальной и не входит в договорённости о совместимости стабильной настольной версии. См. [страницу состояния проекта](/status/).

## Разработка

### Нужно ли знать Go?

Базовые знания Go будут полезны, но быть экспертом необязательно. Логика приложения реализуется в обычных методах Go, а всё остальное пошагово объясняется в [учебных руководствах](/tutorials/overview/). Многие разработчики осваивают Go в процессе создания своего первого приложения Wails.

### Можно ли использовать любимый фронтенд-фреймворк?

Да. Если результат его сборки — HTML, CSS и JavaScript, он будет работать с Wails. В комплект входят шаблоны для React, Vue, Svelte и чистого JavaScript (каждый также доступен в варианте с TypeScript), а любой другой фреймворк можно подключить за несколько минут. См. [«Фронтенд-фреймворки»](/guides/dev/frontend-frameworks/).

### Как вызывать функции Go из JavaScript?

Зарегистрируйте сервис, и Wails создаст для него типизированные привязки:

```go
// Go
type GreetService struct{}

func (g *GreetService) Greet(name string) string {
    return "Hello " + name
}
```

```javascript
// JavaScript
import { GreetService } from "./bindings/changeme";

const message = await GreetService.Greet("World");
```

Привязки автоматически создаются заново во время `wails3 dev` или по запросу с помощью `wails3 generate bindings`. См. [«Сервисы»](/features/bindings/services/).

### Можно ли использовать TypeScript?

Да. Генератор привязок создаёт определения TypeScript для сервисов и их типов, поэтому вызовы Go полностью типизированы.

### Как отправлять события между Go и JavaScript?

```go
// Go
app.Event.Emit("time", time.Now().Format(time.RFC1123))
```

```javascript
// JavaScript
import { Events } from "@wailsio/runtime";

Events.On("time", (event) => {
    console.log(event.data);
});
```

Имена событий должны совпадать в точности. См. [справочник по событиям](/guides/events-reference/).

### Как отлаживать приложение?

Запустите `wails3 dev` и щёлкните в окне правой кнопкой мыши, чтобы открыть инструменты разработчика браузера — точно так же, как при веб-разработке. Сервер разработки также поддерживает горячую перезагрузку фронтенда. См. [«Отладка»](/guides/dev/debugging/).

## Сборка и распространение

### Как собрать приложение для промышленной эксплуатации?

```bash
wails3 build
```

Исполняемый файл будет помещён в `bin/`. При промышленной сборке уже применяются разумные параметры по умолчанию (теги сборки, `-trimpath`, удаление символов), поэтому для получения компактного исполняемого файла дополнительные флаги не требуются.

### Возможна ли кросс-компиляция?

С некоторыми ограничениями. Обычная кросс-компиляция Go неприменима, поскольку каждая платформа использует нативные библиотеки встроенного браузерного компонента, однако распространённые сценарии хорошо поддерживаются:

```bash
# Different architecture, same OS
wails3 build GOOS=windows GOARCH=arm64

# macOS universal binary
wails3 task darwin:build:universal
```

Для сборки под Linux в другой операционной системе используется инструментарий на основе Docker. Полную матрицу см. в разделе [«Кроссплатформенная сборка»](/guides/build/cross-platform/).

### Как создать установщик или пакет?

```bash
wails3 package
```

В результате создаётся нативный для платформы формат, а в [руководстве по установщикам](/guides/installers/) описаны NSIS в Windows, пакеты `.app` и образы DMG в macOS, а также пакеты Linux.

### Как подписать приложение цифровой подписью?

Подписание в Windows и macOS, включая нотариальное заверение, пошагово описано в [руководстве по подписанию](/guides/build/signing/).

## Возможности

### Можно ли создать несколько окон?

Да, в v3 есть встроенная поддержка нескольких окон:

```go
window1 := app.Window.New()
window2 := app.Window.New()
```

См. [«Несколько окон»](/features/windows/multiple/).

### Поддерживает ли Wails системный трей?

Да, включая меню и обработчики щелчков:

```go
systemTray := app.SystemTray.New()
systemTray.SetIcon(iconBytes)
systemTray.SetMenu(myMenu)
```

См. [«Системный трей»](/features/menus/systray/).

### Можно ли использовать нативные диалоговые окна?

Да. Диалоговые окна выбора файлов, сообщений и вопросов используют нативные реализации:

```go
path, err := app.Dialog.OpenFile().
    SetTitle("Select File").
    PromptForSingleSelection()
```

См. [«Диалоговые окна»](/features/dialogs/overview/).

### Поддерживает ли Wails автоматические обновления?

Да. Wails v3 включает встроенный механизм самообновления (`app.Updater`) с подключаемыми провайдерами для GitHub Releases, keygen.sh и Sparkle AppCast, проверкой криптографических подписей и стандартным интерфейсом, оформление которого можно изменить или который можно заменить. См. руководство [«Встроенное обновление приложения»](/guides/updater/) и учебное руководство [«Самообновляемое приложение Wails»](/tutorials/04-self-update-a-wails-app/).

## Устранение неполадок

### Что-то не работает. С чего начать?

```bash
wails3 doctor
```

Эта команда проверяет инструментарий, перечисляет отсутствующие зависимости вместе с командами для их установки и выводит сведения о версиях, которые следует включать во все отчёты об ошибках.

### Сборка завершается с ошибкой

Обычно помогают следующие действия в указанном порядке:

1. `go mod tidy`
2. `cd frontend && npm install` (чаще всего причина заключается в отсутствии `node_modules`)
3. Обновите CLI: `go install github.com/wailsapp/wails/v3/cmd/wails3@v3.0.0`
4. В Linux проверьте с помощью `wails3 doctor`, не отсутствуют ли пакеты GTK/WebKit

### Мои привязки отсутствуют или устарели

```bash
wails3 generate bindings
```

В режиме разработки привязки создаются заново автоматически. Если вы добавили новый сервис или изменили сигнатуры методов вне `wails3 dev`, создайте привязки заново вручную.

### События не срабатывают

Имена событий в `app.Event.Emit("name", ...)` в Go и `Events.On("name", ...)` в JavaScript должны совпадать в точности. Сначала проверьте их на опечатки и различия в регистре.

### Я обнаружил ошибку

[Создайте задачу](https://github.com/wailsapp/wails/issues) и приложите вывод `wails3 doctor`. В [руководстве по обратной связи](/feedback/) объясняется, как составить отчёт, с которым будет удобно работать.

## Переход с v2

### Стоит ли переходить с v2 на v3?

v3 предоставляет поддержку нескольких окон, более понятный API на основе сервисов, встроенный механизм обновления, гораздо более гибкую систему сборки и повышенную производительность. Новые проекты следует начинать на v3. Различия, важные для существующих проектов, пошагово описаны в [руководстве по миграции](/migration/v2-to-v3/).

### Будет ли поддерживаться v2?

Да. Wails v2 продолжает получать критические обновления. Для новых проектов следует использовать Wails v3.0.0.

### Можно ли использовать v2 и v3 параллельно?

Да. Интерфейсы командной строки поставляются как отдельные исполняемые файлы (`wails` и `wails3`), а модули имеют разные пути импорта, поэтому проекты на разных основных версиях могут без проблем сосуществовать на одном компьютере.
