[Ytd](https://github.com/marcio199226/ytd/tree/v2-wails) — приложение для скачивания треков с YouTube, создания офлайн-плейлистов и обмена ими с друзьями. Ваши друзья смогут воспроизводить ваши плейлисты или скачивать их для прослушивания без подключения к интернету. В приложение встроен проигрыватель.
