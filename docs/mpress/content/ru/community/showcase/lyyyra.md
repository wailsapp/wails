Lyyyra — настольное приложение-песенник, созданное с помощью Wails, Go и React. Оно загружает тексты песен, метаданные и PDF-файлы с нотами с evangelickyzpevnik.cz, а затем позволяет искать, фильтровать и сортировать коллекцию офлайн.

Основные возможности:

- Полнотекстовый поиск по названиям, авторам и текстам песен
- Сортировка по номеру песни, названию, автору музыки и автору текста
- Панель «Подготовленные листы» для сбора песен и экспорта одного объединённого PDF
- Локальная база данных, которая продолжает работать офлайн после первой загрузки
- Готовые бинарные файлы для Windows и Linux

[Посмотреть на GitHub](https://github.com/tomvladik/Lyyyra)
