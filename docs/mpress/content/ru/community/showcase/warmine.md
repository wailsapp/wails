[Лаунчер Minecraft для WarMine](https://warmine.ru/) — это приложение Wails, которое позволяет легко подключаться к игровым серверам с модификациями и управлять игровыми учётными записями.

Лаунчер загружает файлы игры, проверяет их целостность и запускает игру, предоставляя на стороне бэкенда широкий набор параметров для настройки аргументов запуска.

Фронтенд написан на Svelte, весь лаунчер занимает 9 МБ и поддерживает Windows 7-11.
