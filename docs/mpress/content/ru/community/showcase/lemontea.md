[lemontea](https://github.com/MikeLINGxZ/lemontea) — кроссплатформенный настольный клиент для ИИ, созданный с помощью Wails v3, Go, React и TypeScript. Основное внимание в нём уделено чату, вызову инструментов, выполнению многоагентных рабочих процессов и интеграции с локальной средой рабочего стола.
