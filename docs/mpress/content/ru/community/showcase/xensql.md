**[XenSQL](https://github.com/Bare7a/XenSQL)** — это **быстрая локальная настольная среда для работы с SQL**, созданная с использованием **Go, Wails и React**. Она объединяет PostgreSQL, MySQL/MariaDB и SQLite в едином лаконичном интерфейсе, воспринимающемся как нативный, — без облачных сервисов, телеметрии и учётных записей.

## Ключевые возможности

- **Мощный редактор SQL** — основан на Monaco и поддерживает интеллектуальное автодополнение с учётом схемы, выполнение нескольких операторов, потоковую передачу результатов и отдельные вкладки результатов для каждого оператора
- **Расширенный просмотр данных** — интерактивный инспектор JSON, редактор ячеек с учётом синтаксиса (JSON, XML, HTML и текст), редактирование непосредственно в таблице и полный просмотр записей
- **Удобное редактирование данных** — просмотр таблиц, подготовка изменений к последующему применению непосредственно в таблице, массовые операции и безопасные `INSERT`/`UPDATE`/`DELETE` с поддержкой `RETURNING`
- **Функции для продуктивной работы** — обозреватель схемы, сохранённые запросы, история запросов, быстрый поиск (`Ctrl+P`) и рабочий процесс, ориентированный на использование клавиатуры
- **Варианты экспорта** — CSV, JSON, Markdown и операторы SQL INSERT

Полностью автономная и переносимая работа. Все данные хранятся локально в одной папке `XenSQL-data/`, которую можно переносить вместе с приложением.

**Поддерживаемые базы данных**: PostgreSQL, MySQL, MariaDB и SQLite (с режимом только для чтения и вариантами безопасной передачи данных).

Предназначено для разработчиков, которым нужны скорость, ясность и контроль без громоздкости традиционных инструментов для работы с SQL.
