[October](https://october.utf9k.net) — небольшое приложение на Wails, которое позволяет очень легко извлекать выделенные фрагменты из [электронных книг Kobo](https://en.wikipedia.org/wiki/Kobo_eReader), а затем отправлять их в [Readwise](https://readwise.io).

Приложение решает сравнительно узкий круг задач, и размер каждой версии для поддерживаемых платформ составляет менее 10 МБ — даже без [сжатия с помощью UPX](https://upx.github.io/)!

Для сравнения: предыдущие попытки автора реализовать приложение с помощью Electron быстро разрастались до нескольких сотен мегабайт.
