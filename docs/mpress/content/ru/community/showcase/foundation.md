**[Foundation](https://github.com/FxRayHughes/foundation)** — готовый к продакшену **шаблон десктопного приложения для Wails v3**, созданный на **Go, React 19, TypeScript и Mantine 9**. Он сразу даёт новому проекту то, на что обычно уходят недели: многоуровневый бэкенд на Go, оформление окон для каждой платформы, хранение данных, темы, локализацию и сквозные тесты — так что можно сразу переходить к бизнес-логике.

## Основные возможности

- **Нативное окно на каждой платформе** — на Windows и Linux безрамочное окно с заголовком, отрисованным фронтендом; на macOS иммерсивный заголовок с сохранёнными системными кнопками окна.
- **Девять переключаемых макетов** — панель значков, боковая панель, верхняя навигация, навигация в заголовке, правая панель, нижний Dock, перетаскиваемый плавающий Dock, карточка с отступами и режим фокуса — всё на оболочке CSS Grid; собственный пресет регистрируется одной строкой.
- **Темы и локализация** — светлая, тёмная и Obsidian, а также редактор собственной палитры; английский и китайский из коробки; тема и язык синхронизируются между главным окном, дочерними окнами и панелью трея в реальном времени.
- **Хранение в SQLite** — GORM AutoMigrate без файлов миграций, выбор расположения базы данных пользователем и диаграммы использования по таблицам.
- **Интеграция с рабочим столом** — панель системного трея, дочерние окна, нативные диалоги файлов и сообщений, а также экспорт в CSV / XLSX через нативный диалог «Сохранить как».
- **Надёжные утилиты** — HTTP-клиент, дочерние процессы, привязанные к Windows Job Object, шифрование AES-GCM, ротация логов и атомарная запись.
- **Сквозное тестирование** — Playwright управляет сборкой Wails в серверном режиме (настоящий бэкенд на Go и настоящий фронтенд), и тот же набор тестов генерирует скриншоты для README.

Благодаря Wails всё это собирается в один бинарный файл для каждой платформы: сервисы на Go вызываются напрямую через сгенерированные привязки, а фронтенд следует строгой структуре MVVM, которую легко поддерживать по мере роста функциональности.

Доступно для Windows, macOS и Linux.
