**[Foundation](https://github.com/FxRayHughes/foundation)** — **шаблон десктопного приложения для Wails v3.1**, созданный на **Go, React 19, TypeScript и Mantine 9**. В качестве отправной точки для новых проектов он предоставляет многоуровневый бэкенд на Go, оформление окон для каждой платформы, хранение данных в SQLite, темы, локализацию и сквозные тесты.

## Возможности

- **Окна для каждой платформы** — на Windows и Linux безрамочное окно с заголовком, отрисованным фронтендом; на macOS иммерсивный заголовок с сохранёнными системными кнопками окна.
- **Девять пресетов макета** — панель значков, боковая панель, верхняя навигация, навигация в заголовке, правая панель, нижний Dock, перетаскиваемый плавающий Dock, карточка с отступами и режим фокуса на оболочке CSS Grid; можно регистрировать собственные пресеты.
- **Темы и локализация** — светлая, тёмная и Obsidian, а также редактор собственной палитры; интерфейс на английском и китайском; тема и язык синхронизируются между главным окном, дочерними окнами и панелью трея.
- **Хранение в SQLite** — GORM AutoMigrate без файлов миграций, выбор расположения базы данных пользователем и диаграммы использования по таблицам.
- **Интеграция с рабочим столом** — панель системного трея, дочерние окна, нативные диалоги файлов и сообщений, а также экспорт в CSV / XLSX через нативный диалог «Сохранить как».
- **Утилиты** — HTTP-клиент, дочерние процессы, привязанные к Windows Job Object, шифрование AES-GCM, ротация логов и атомарная запись.
- **Сквозные тесты** — Playwright запускается против сборки Wails в серверном режиме (настоящий бэкенд на Go и фронтенд); тот же набор тестов генерирует скриншоты для README.

Фронтенд вызывает сервисы на Go через привязки, сгенерированные Wails, а для каждой платформы собирается один бинарный файл. Фронтенд построен по структуре MVVM, а в README есть пошаговое руководство по переименованию шаблона под собственный проект.

Работает на Windows, macOS и Linux.
