**[Zentro](https://zentro-ide.com)** — это **настольная SQL IDE, ориентированная на проекты** для PostgreSQL, MySQL, SQL Server и SQLite, созданная на **Go, Wails v2 и React**. Каждый проект знает, на какое окружение он указывает, а Zentro спрашивает подтверждение перед любым необратимым действием, поэтому запрос для стейджинга не попадёт в продакшн.

## Основные возможности

- **Осведомлённость об окружении** - проекты хранят свои окружения (разработка, стейджинг, продакшн) с заметной пометкой продакшна, классификацией рисков запросов и предпросмотром затронутых строк перед разрушительной записью
- **SQL-редактор** - автодополнение по схеме, диагностика прямо в коде и быстрые исправления
- **Обозреватель схемы и ERD** - просмотр таблиц, столбцов, ключей и индексов и визуализация связей
- **Отслеживание через Git** - сохранённые скрипты и снимки схемы версионируются как код, с историей и сравнением
- **SSH-туннели и встроенный терминал** - доступ к базе через туннель и локальный или SSH-терминал рядом с запросами
- **ИИ-ассистент с вашим собственным ключом** - подключается к настроенной вами точке доступа модели, никогда через сервер Zentro, плюс MCP-сервер для внешних агентов
- **Клавиатура прежде всего** - навигация по обозревателю и таблице результатов, палитра команд и последовательности клавиш
- **Приватность по умолчанию** - учётные данные баз данных хранятся в связке ключей вашей операционной системы

Zentro поставляется как один нативный исполняемый файл для каждой платформы — Windows, macOS и Linux. Ядро с открытым исходным кодом под GPL-3.0, а необязательный платный уровень Pro добавляет защиту продакшна и другое, с бесплатной пробной версией на 30 дней; исходный код Community Edition открыт.
