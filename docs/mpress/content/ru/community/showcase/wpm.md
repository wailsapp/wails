Приложение для обоев Windows с поддержкой собственных изображений, нескольких мониторов и случайной или последовательной смены обоев.

Встроенное слайд-шоу Windows не позволяет выбирать изображения из нескольких папок без их предварительного объединения. wpm позволяет выбрать несколько папок или отдельные папки для разных мониторов. Приложение может случайным образом выбирать изображение с соотношением сторон, подходящим для каждого экрана.
