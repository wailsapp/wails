[Minecraft Updater](https://github.com/Gurkengewuerz/MinecraftModUpdater) — это утилита для обновления и синхронизации модификаций Minecraft для ваших пользователей. Она создана с использованием Wails2 и React, а в качестве фреймворка интерфейса используется [antd](https://ant.design/).
