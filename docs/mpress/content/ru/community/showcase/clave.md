Основные возможности

- 🎨 Простой и интуитивно понятный интерфейс для комфортной работы
- ✅ Легко добавляйте учётные записи вручную или импортируйте изображение QR-кода.
- 🔒 Сквозное шифрование с использованием PIN-кода или Touch ID (только в macOS).
- 💻 Доступно для macOS, Windows и Linux
- ⚡ Быстрый доступ из системного трея для удобной работы
- 📂 Легко создавайте резервные копии профилей и восстанавливайте их

Попробуйте Clave уже сегодня!
