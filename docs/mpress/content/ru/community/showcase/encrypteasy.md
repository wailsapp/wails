**[EncryptEasy](https://www.encrypteasy.app) — простой и удобный инструмент PGP-шифрования для управления всеми вашими ключами и ключами ваших контактов. Шифрование должно быть простым. Разработано с помощью Wails.**

Шифрование сообщений с помощью PGP — отраслевой стандарт. У каждого есть закрытый и открытый ключ. Закрытый ключ необходимо хранить в тайне, чтобы только вы могли читать сообщения. Открытый ключ передают всем, кто хочет отправлять вам конфиденциальные зашифрованные сообщения. Управление ключами, шифрование и расшифровка сообщений должны быть удобными. Цель EncryptEasy — сделать всё это проще.
