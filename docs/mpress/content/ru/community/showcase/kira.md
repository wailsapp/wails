**[Kira](https://kira.thiennguyen.dev)** — это **нативный настольный клиент AWS для macOS**, воплощающий принцип *«AWS без лишних сложностей»*. Он создан с использованием **Go, Wails и React + TypeScript** и объединяет работу с AWS в одном приложении с управлением с клавиатуры. Один раз пройдите аутентификацию через AWS SSO и управляйте инфраструктурой во многих учётных записях, не переключаясь между консолью, CLI и множеством инструментов для работы с базами данных.

Всё началось с личной потребности: постоянные переключения между вкладками браузера, командами `aws` и отдельным SQL-клиентом лишь для того, чтобы выпустить изменение, отнимали слишком много времени. Kira объединяет эти рабочие процессы в одном быстром нативном окне: войдите в систему, выберите учётную запись — и всё необходимое будет доступно по нажатию клавиш.

## Ключевые возможности

- **AWS SSO для нескольких учётных записей** — войдите один раз, а затем переключайтесь между учётными записями и регионами в одном месте
- **ECS** — просматривайте кластеры, сервисы и задачи; повторно развёртывайте, масштабируйте и откатывайте сервисы; просматривайте определения задач; отслеживайте метрики сервисов; открывайте интерактивную оболочку через ECS Exec
- **Базы данных** — выполняйте SQL-запросы к RDS, запросы и сканирование в DynamoDB, а также подключайтесь к PostgreSQL, MySQL и Redshift через защищённые SSH-туннели; учётные данные хранятся в Связке ключей macOS
- **S3** — перемещайтесь по бакетам и префиксам; просматривайте, загружайте, скачивайте, копируйте, переименовывайте и удаляйте объекты; создавайте папки
- **Secrets Manager** — просматривайте список секретов и получайте их значения для активной учётной записи
- **CloudWatch Logs** — отслеживайте потоки журналов в реальном времени и выполняйте поиск по ним
- **Smart Query** — необязательная генерация SQL с помощью ИИ на базе CLI `claude`
- **Расширения** — устанавливайте пользовательские пакеты `.kext`, добавляющие кнопки действий на основе небольших скриптов Go
- **Быстрая навигация** — глобальное сочетание клавиш для вызова приложения, палитра команд `Cmd+K` и глубокие ссылки `kira://`

## Подробнее

Следите за сервисами ECS в реальном времени — состоянием задач, загрузкой ЦП и памяти, состоянием развёртывания — и повторно развёртывайте, масштабируйте или откатывайте их, не покидая список.

![Просмотр сервисов ECS в Kira с метриками в реальном времени](/assets/showcase-images/kira_screenshot_17.png)

Работайте с S3 как с файловым менеджером. Предварительно просматривайте объекты, изучайте метаданные и версии, а также загружайте, скачивайте, переименовывайте и удаляйте их непосредственно в списке.

![Браузер объектов S3 в Kira с предварительным просмотром объектов и метаданными](/assets/showcase-images/kira_screenshot_5.png)

Распространяется в виде подписанного и прошедшего проверку Apple `.dmg` для macOS.
