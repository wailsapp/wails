Настольный редактор кода BMEditor (Bare Minimum Editor (batteries included)) для Windows и Linux готов к работе сразу после запуска. Отладчик, терминал, Docker, изменения Git в проекте и живой предпросмотр Markdown, HTML и OpenAPI встроены в сам редактор, так что ничего не нужно искать и настраивать заранее. Go работает из коробки, а сам редактор расширяемый: другие языки и инструменты добавляются расширениями.

Из того же окна можно открыть папку в WSL, на сервере по SSH или внутри контейнера Docker, ничего не устанавливая на другой стороне. Если вы пользуетесь Claude Code или GitHub Copilot CLI, он работает на боковой панели, а изменённые им файлы возвращаются к вам на проверку, и каждую правку можно принять или отклонить. Раскладка окон и сочетания клавиш как в VS Code, поэтому всё привычно с первой минуты.

Он сделан на Wails 3, Go и Vue и бесплатен.
