![Снимок экрана Clip](/assets/showcase-images/clip.png)

- **Трёхколоночный интерфейс**: дерево источников/папок · список статей · область чтения
- **Управление подписками**: добавление лент, организация по папкам, импорт/экспорт OPML
- **Загрузка по расписанию**: разбор RSS / Atom с автоматическим обновлением в фоновом режиме
- **Сосредоточенное чтение**: просмотр полного текста + режим концентрации без отвлекающих элементов
- **Быстрый поиск**: глобальный полнотекстовый поиск по заголовкам, кратким описаниям и заметкам
- **Заметки**: прикрепление заметок к статьям для последующего просмотра
- **Уведомления на рабочем столе**: оповещения о новых статьях, значки в macOS Dock / на панели задач Windows
- **Управление с клавиатуры**: полный набор сочетаний клавиш
- **Темы и языки**: светлая / тёмная / системная тема, многоязычная поддержка
- **Производительность и работа без сети**: легковесные запросы списков, локальный кеш, чтение без подключения к сети

[Посмотреть на GitHub](https://github.com/clip-rss/clip)
