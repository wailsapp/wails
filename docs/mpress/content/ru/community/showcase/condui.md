Condui — менеджер SSH-подключений со сквозным шифрованием и синхронизацией между несколькими устройствами. Он синхронизирует ваши подключения, SSH-туннели и защищённые хранилищем учётные данные на всех используемых вами устройствах, при этом сервер синхронизации никогда не получает доступ к учётным данным в незашифрованном виде.

Основные возможности

- 🔐 Хранилище со сквозным шифрованием для паролей SSH и парольных фраз закрытых ключей
- 🔄 Синхронизация подключений, папок и SSH-туннелей между несколькими устройствами
- 🌐 Сохраняемые для каждого подключения туннели локального перенаправления портов
- 🖥️ Встроенные инструменты для работы с терминалом, SFTP, Docker и базами данных
- 💻 Доступно для macOS, Windows и Linux
