**[MQ Studio](https://mq-studio.amigoer.com)** представляет собой **настольный клиент для очередей сообщений с приоритетом локального хранения данных**, созданный на **Go, Wails и React**. У каждого брокера своя консоль: у RocketMQ одна, у Kafka другая, а RabbitMQ поставляется с плагином управления. Разные интерфейсы, разная терминология, и каждый из них — отдельный сервис, который нужно развёртывать и поддерживать. MQ Studio заменяет их одним приложением: доступ к каждому брокеру осуществляется через драйвер за общим интерфейсом, поэтому страницы и рабочий процесс остаются одинаковыми независимо от подключённой системы.

## Основные возможности

- **Один интерфейс для всех брокеров** — сейчас поддерживаются RocketMQ, RabbitMQ и Kafka; Pulsar, NATS, MQTT и SQS запланированы.
- **Топики, очереди и сообщения** — просмотр топиков, очередей, обменников и привязок; поиск и трассировка сообщений, наблюдение за журналом, отправка с ключами и заголовками, повторная отправка и обработка недоставленных сообщений.
- **Потребители и отставание** — группы, клиенты, подписки и отставание по разделам, сброс смещений, обработка повторных попыток и очередей недоставленных сообщений (DLQ).
- **Кластер и оповещения** — состояние брокеров, показатели времени выполнения, пропускная способность, использование диска и системные уведомления рабочего стола.
- **Прозрачные возможности подключения** — каждый драйвер объявляет реальные возможности своей конечной точки, а интерфейс предлагает только операции, поддерживаемые брокером.
- **Конфиденциальность по умолчанию** — конфигурация остаётся на вашем устройстве, а учётные данные хранятся в зашифрованном виде.

Не нужно развёртывать серверный компонент или поддерживать веб-консоль; телеметрии нет. Это возможно благодаря Wails: клиенты администрирования этих брокеров — библиотеки Go. Слой драйверов обращается к ним напрямую внутри процесса, а интерфейс остаётся обычным приложением React — один исполняемый файл для каждой платформы вместо сервиса, который нужно обслуживать.

Доступно для macOS, Windows и Linux на английском и китайском языках.
