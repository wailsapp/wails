Larvyn — настольное рабочее место для Laravel-разработчиков на Linux, macOS и Windows. Оно объединяет ваши Laravel-приложения, их сервисы разработки (artisan serve, Vite, очереди, Reverb…), настоящие терминалы, базу данных, Tinker, тесты, логи и ИИ-агентов для кода в одном нативном окне.

Запускайте Claude Code, Codex, OpenCode, Cursor Agent, Aider и другие бок о бок, каждый в своём git worktree, затем сравнивайте диффы и сливайте лучший результат. Создано на Wails 3, Go и React.
