[Утилита экспорта FileHound](https://www.filehound.co.uk/) FileHound — это облачная платформа управления документами, предназначенная для безопасного хранения файлов, автоматизации бизнес-процессов и работы с возможностями SmartCapture.

Утилита экспорта FileHound позволяет администраторам FileHound выполнять безопасное извлечение документов и данных для альтернативного резервного копирования и восстановления. Приложение загружает все документы и/или метаданные, сохранённые в FileHound и соответствующие выбранным вами фильтрам. Метаданные экспортируются в форматах JSON и XML.

Серверная часть создана с использованием:

- Go 1.15
- Wails 1.11.0
- go-sqlite3 1.14.6
- go-linq 3.2

Клиентская часть создана с использованием:

- Vue 2.6.11
- Vuex 3.4.0
- TypeScript
- Tailwind 1.9.6
