[LTools](https://github.com/lian-yang/ltools) — это созданный с помощью Wails v3 кроссплатформенный набор инструментов для настольных систем с архитектурой на основе плагинов, вдохновлённый uTools. Он служит единым центром модульных плагинов с утилитами для разработчиков.

В состав входят глобальная строка поиска в стиле Spotlight, интеграция с системным треем и встроенные плагины, включая менеджер буфера обмена, инструмент для создания снимков экрана с аннотациями, редактор JSON, калькулятор, системный монитор и другие. Расширяемая система плагинов позволяет добавлять новые инструменты.
