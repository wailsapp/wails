Приложение [Tiny RDM](https://redis.tinycraft.cc/) — современный легковесный клиент Redis с графическим интерфейсом и открытым исходным кодом. Оно обладает красивым интерфейсом, позволяет интуитивно управлять базами данных Redis и совместимо с Windows, Mac и Linux. Приложение предоставляет визуальные средства для работы с данными в формате «ключ — значение», поддерживает различные способы декодирования и просмотра данных, включает встроенную консоль для выполнения команд, запросы к журналу медленных операций и многое другое.
