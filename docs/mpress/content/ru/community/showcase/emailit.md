[EmailIt](https://github.com/raguay/EmailIt/) — это программа на Wails 2, предназначенная исключительно для отправки электронных писем на основе Markdown. В ней есть девять блокнотов, скрипты для обработки текста и шаблоны. Также в ней есть терминал скриптов, позволяющий запускать в EmailIt скрипты для обработки файлов в вашей системе. Скрипты и шаблоны можно использовать непосредственно из командной строки или с помощью расширений Alfred, Keyboard Maestro, Dropzone либо PopClip. Также поддерживаются скрипты и темы, загруженные с GitHub. Документация ещё не завершена, но программа работает. Она создана с использованием Wails2 и Svelte, а для загрузки предлагается универсальное приложение для macOS.
