[Larder](https://github.com/599yongyang/larder) — локальное настольное приложение для разработчиков, которые используют несколько ИИ-агентов. Оно сканирует реально существующие на диске файлы — Skills, MCP-серверы, CLI-инструменты, файлы инструкций и пользовательские команды — и объясняет, что на самом деле видит каждый агент.

Larder помогает находить битые ссылки, дубликаты Skills и устаревшие настройки. Каждая запись проходит через план и снимок, поэтому изменения можно откатить. Также поддерживаются выбираемые пакеты данных и необязательное шифрованное резервное копирование WebDAV/S3.

Создано с использованием Go 1.26, Wails v3 beta.34, React 18, SQLite и Tailwind CSS. Лицензия MIT.
