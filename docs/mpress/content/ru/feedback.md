Мы приветствуем (и поощряем) обратную связь! Прежде чем создавать новую задачу или обсуждение, найдите уже существующие. Вот как можно внести свой вклад:

@tabs
[Ошибки]
Если вы обнаружили ошибку, [создайте задачу](https://github.com/wailsapp/wails/issues/new/choose) на GitHub, используя шаблон отчёта об ошибке.

- Чётко опишите ошибку и приведите простой воспроизводимый пример. Если из документации непонятно, что *должно* происходить, укажите это в отчёте.
- Добавьте в отчёт вывод команды `wails3 doctor`.
- Если ошибка заключается в том, что поведение не соответствует текущей документации, также выполните следующие действия:
  - Обновите существующий пример в каталоге `v3/examples` или создайте новый пример, наглядно демонстрирующий проблему.
  - Откройте [PR](https://github.com/wailsapp/wails/pulls) со ссылкой на задачу.


@note{type="caution"}
*Помните*: неожиданное поведение не обязательно является ошибкой — возможно, оно просто не соответствует вашим ожиданиям. В таком случае используйте `Suggestions`.

@end

Ошибки также можно обсудить в канале [#v3](https://discord.gg/bdj28QNHmT) в Discord.

[Исправления]
Если у вас есть исправление ошибки или улучшение документации:

- Откройте pull request в [репозитории Wails](https://github.com/wailsapp/wails), следуя [руководству по участию в разработке](https://github.com/wailsapp/wails/blob/master/CONTRIBUTING.md).
- Укажите ссылки на все связанные задачи в описании PR.

[Улучшения]
Новую функциональность и изменения общедоступного поведения следует предлагать в виде чернового pull request с **WEP (предложением по улучшению Wails)**, а не задачи с запросом функции.

- Ознакомьтесь с [процессом WEP](https://github.com/wailsapp/wails/blob/v3.0.0/v3/wep/README.md).
- Скопируйте шаблон, затем откройте черновой PR с заголовком `[WEP] <title>`, содержащий только WEP и вспомогательные материалы.
- Сначала можно неформально обсудить идею в [обсуждениях GitHub](https://github.com/wailsapp/wails/discussions) или в канале [#v3](https://discord.gg/bdj28QNHmT) в Discord, но для принятия решения сопровождающим требуется PR с WEP.

[Голосование]
- Поддержите отчёты об ошибках, WEP и обсуждения с помощью реакции :thumbsup: на GitHub.
- Пожалуйста, *не оставляйте* комментарии только с текстом «+1» или «у меня тоже».
- Оставьте комментарий, если можете сообщить что-то существенное, например: «эта ошибка также затрагивает сборки для ARM» или «Можно было бы использовать другой подход: ...».

@end

Список известных проблем и работ, которые сейчас выполняются, можно найти [здесь](https://github.com/orgs/wailsapp/projects/6).
