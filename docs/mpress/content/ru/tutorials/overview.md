## Сервис QR-кодов

![Пример работы с QR-кодами](/assets/qr1.png)

Изучите основы сервисов Wails, создав генератор QR-кодов. Это руководство познакомит вас с ключевыми принципами организации логики приложения в виде сервисов, пригодных для повторного использования.

**Чему вы научитесь:**

- Создавать и структурировать сервис Wails
- Управлять внешними зависимостями Go
- Привязывать методы Go к фронтенду
- Передавать данные между Go и JavaScript
- Организовывать код так, чтобы его было удобно сопровождать

**Для кого:** для тех, кто впервые использует Wails и хочет разобраться в сервисной архитектуре

### Список задач

![Приложение со списком задач](/assets/todo-app.png)

Создайте полноценное приложение со списком задач и красивым современным интерфейсом. В этом практическом руководстве вы освоите основные шаблоны Wails на примере реального приложения, использующего чистый JavaScript.

**Чему вы научитесь:**

- Применять сервисную архитектуру с потокобезопасным управлением состоянием
- Выполнять операции CRUD (создание, чтение, обновление и удаление)
- Использовать типобезопасные привязки между Go и JavaScript
- Создавать современные пользовательские интерфейсы без сложностей, связанных с фреймворками
- Правильно обрабатывать ошибки и применять шаблоны валидации

**Время выполнения:** около 20 минут

**Для кого:** для тех, кто создаёт своё первое полноценное приложение Wails. Оно идеально подходит для изучения основ перед добавлением сложностей, связанных с фреймворками

Создайте приложение в стиле Apple Notes с нативными диалоговыми окнами для работы с файлами и функцией автосохранения. ### Самообновляемое приложение Wails

Добавьте в приложение Wails возможность самообновления: от нового `wails3 init` до проверки подписанного выпуска и замены исполняемого файла во вспомогательном режиме. В качестве источника обновлений используются GitHub Releases.

**Чему вы научитесь:**

- Как `app.Updater` интегрируется в приложение Wails
- Настраивать провайдер GitHub Releases
- Публиковать выпуски вместе с `SHA256SUMS` для проверки контрольных сумм
- Добавлять подпись Ed25519 для защиты от несанкционированных изменений
- Настраивать стандартное окно с помощью CSS, собственного HTML или BYO
- Выполнять периодические фоновые проверки с помощью `CheckInterval`

**Время выполнения:** около 25 минут

**Для кого:** для тех, кто выпускает обновляемое настольное приложение: руководство охватывает весь процесс выпуска, а не только API
