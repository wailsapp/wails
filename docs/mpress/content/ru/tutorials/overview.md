Выберите пошаговое руководство, если хотите освоить Wails на практике. Каждое руководство посвящено одному проекту и приводит к конкретному результату.

Если вы здесь впервые, сначала изучите разделы [Установка](/quick-start/installation/) и [Ваше первое приложение](/quick-start/first-app/).

## Выберите учебное руководство

После создания первого приложения изучайте руководства по разработке настольных приложений в следующем порядке:

| Руководство | Что вы освоите |
| --- | --- |
| [Сервис QR-кодов](/tutorials/01-creating-a-service/) | Предоставление доступа к логике Go через сервис и её вызов из фронтенда |
| [Список задач](/tutorials/02-todo-vanilla/) | Создание, обновление и удаление данных приложения |
| [Приложение для заметок](/tutorials/03-notes-vanilla/) | Использование нативных диалоговых окон и сохранение данных в файлы |
| [Самообновляемое приложение](/tutorials/04-self-update-a-wails-app/) | Проверка и установка обновлений из GitHub Releases |

В качестве дополнительного руководства по мобильной разработке изучите раздел [Ваше первое мобильное приложение](/guides/mobile/first-mobile-app/). Поддержка мобильных платформ является экспериментальной.

Если вы работаете с существующим приложением и хотите выполнить конкретную задачу, выберите вместо этого подходящее [практическое руководство](/quick-start/next-steps/#features). Основы проектирования изложены в разделе [Основные концепции](/concepts/architecture/).

@note{type="tip" title="Не знакомы с Go?"}
Перед началом работы с учебными руководствами пройдите [тур по Go](https://go.dev/tour/).

@end

![Приложение со списком задач](/assets/todo-app.png)

Создайте полноценное приложение со списком задач и красивым современным интерфейсом. В этом практическом руководстве вы освоите основные шаблоны Wails на примере реального приложения, использующего чистый JavaScript.

**Что вы узнаете:**

**Лучше всего подходит:** для создания первого полноценного приложения Wails — идеальный вариант, чтобы разобраться в основах до добавления сложностей, связанных с фреймворками

### Самообновляемое приложение Wails

Добавьте в приложение Wails встроенное самообновление, начав с нового `wails3 init` и реализовав проверку подписанных выпусков и замену исполняемого файла во вспомогательном режиме. В качестве источника обновлений используются GitHub Releases.

**Что вы узнаете:**

- Как `app.Updater` подключается к приложению Wails
- Настройка провайдера GitHub Releases
- Публикация выпусков с помощью `SHA256SUMS` для проверки контрольной суммы
- Добавление подписи Ed25519 для защиты от подмены
- Настройка стандартного окна с помощью CSS, собственного HTML или BYO
- Периодические фоновые проверки с помощью `CheckInterval`

**Время выполнения:** около 25 минут

**Лучше всего подходит:** для выпуска обновляемого настольного приложения — рассматривается весь процесс выпуска, а не только API
