Начните здесь, чтобы найти команду по назначению. Флаги и примеры использования конкретных команд приведены в разделе [«Флаги CLI и примеры»](/guides/cli/).

## Обзор

Wails CLI (`wails3`) — интерфейс командной строки для создания, разработки, сборки, подписания, упаковки и анализа приложений Wails 3. Большинство операций сборки делегируется файлам Taskfile отдельных проектов (в каталоге `build/` вашего проекта): многие команды `wails3` представляют собой тонкие обёртки, запускающие определённую задачу.

Чтобы получить самую актуальную справку по любой команде, выполните:

```bash
wails3 --help
wails3 <command> --help
```

## Жизненный цикл проекта

| Команда | Описание |
| --- | --- |
| `wails3 init` | Создаёт новый проект из шаблона. Флаги: `-n` (имя проекта), `-t` (шаблон; по умолчанию `vanilla`), `-p` (имя пакета Go; по умолчанию `main`), `-d` (каталог проекта; по умолчанию `.`), `-q` (режим без вывода), `-l` (вывести список шаблонов), `-mod` (путь модуля Go), `--git` (URL Git-репозитория), `--skipgomodtidy`, `-s` (не показывать предупреждение об удалённом шаблоне), `--productname`/`--productdescription`/`--productversion`/`--productcompany`/`--productcopyright`/`--productcomments`/`--productidentifier`. |
| `wails3 dev` | Запускает приложение в режиме разработки с горячей перезагрузкой фронтенда. Флаги: `--config` (по умолчанию `./build/config.yml`), `--port` (порт сервера разработки Vite), `-s` (включить HTTPS). |
| `wails3 build` | Собирает проект. Представляет собой тонкую обёртку над задачей `build` из Taskfile. Флаги: `--tags` (передаётся как `EXTRA_TAGS=`), `--obfuscated` (сборка с помощью Garble; см. [«Обфусцированные сборки»](/guides/build/obfuscation/)), `--garbleargs` (дополнительные флаги, передаваемые `garble` перед подкомандой `build`). |
| `wails3 package` | Запускает платформозависимую задачу `package` из Taskfile. |
| `wails3 task [name]` | Запускает любую задачу из Taskfile; если имя не указано, `--list` выводит все зарегистрированные задачи. |
| `wails3 mcp` | Запускает MCP-сервер проекта. Для процессов, запущенных агентом, автоматически использует stdio, а при интерактивной работе в терминале — Streamable HTTP через интерфейс обратной петли. |
| `wails3 doctor` | Выводит диагностический отчёт о вашей среде. |
| `wails3 doctor-ng` | Более новый вариант `doctor` с текстовым пользовательским интерфейсом (TUI). |
| `wails3 version` | Выводит версию CLI. |
| `wails3 releasenotes` | Выводит примечания к последним выпускам. |
| `wails3 docs` | Открывает сайт документации в браузере. |
| `wails3 sponsor` | Открывает страницу спонсорской поддержки. |

## Генерация

`wails3 generate <subcommand>`:

| Подкоманда | Описание |
| --- | --- |
| `generate bindings` | Генерирует привязки между Go и фронтендом. Флаги: `-d` (выходной каталог), `-models`, `-index`, `-ts`, `-i` (интерфейсы), `-b` (пакет), `-names` (сгенерировать `Call.ByName`), `-noevents`, `-noindex`, `-dry`, `-silent`, `-v`, `-clean` (по умолчанию `true`), `-f`, `-obfuscated` (сгенерировать `wails_obfuscated.gen.go` со стабильными идентификаторами привязок для сборок Garble; см. [«Обфусцированные сборки»](/guides/build/obfuscation/)), `-obfuscated-output` (каталог для сгенерированного файла; по умолчанию — каталог основного пакета). Принимает шаблоны пакетов (например, `./...`); если они не заданы, используется текущий каталог. |
| `generate icons` | Преобразует исходный PNG-файл в форматы значков для соответствующих платформ. Флаги: `-input`, `-windowsfilename`, `-macfilename`, `-iconcomposerinput`, `-macassetdir`. |
| `generate build-assets` | Генерирует из `build/config.yml` содержимое каталога `build/`: фрагменты Taskfile, файлы NSIS, `Info.plist`, шаблон `.desktop` и т. д. |
| `generate runtime` | Повторно генерирует предварительно собранный `/wails/runtime.js`, поставляемый в webview. |
| `generate syso` | Генерирует файл ресурсов Windows `.syso` (значок, манифест и сведения о версии). |
| `generate webview2bootstrapper` | Генерирует загрузочный установщик WebView2 для Windows. |
| `generate constants` | Генерирует константы имён событий JS из типов событий Go. |
| `generate template` | Создаёт каркас нового шаблона проекта. |
| `generate .desktop` | Генерирует файл Linux `.desktop`, используемый AppImage, DEB и RPM. |
| `generate appimage` | Генерирует каталог сборки AppImage. |

## Обновление

`wails3 update <subcommand>`:

| Подкоманда | Описание |
| --- | --- |
| `update build-assets` | Обновляет каталог `build/` из `build/config.yml`, по возможности сохраняя изменения пользователя. |
| `update cli` | Обновляет исполняемый файл `wails3`. |

## Подписание кода и упаковка

| Команда | Описание |
| --- | --- |
| `wails3 signing` | Интерактивный мастер, настраивающий подписание для платформ, обнаруженных в `build/`. Флаг: `--platform` (можно указывать несколько раз; по умолчанию платформы автоматически определяются по каталогу сборки). |
| `wails3 entitlements` | Интерактивный мастер настройки разрешений macOS. Флаг: `--output` (путь; по умолчанию `build/darwin/entitlements.plist`). |
| `wails3 sign [GOOS=…]` | Обёртка, запускающая платформозависимую задачу `*:sign` из Taskfile для текущей ОС или ОС, указанной с помощью `GOOS`. |
| `wails3 tool sign` | Низкоуровневая точка входа для непосредственного подписания. Флаги: `--input`, `--output`, `--verbose`, `--certificate`, `--password`, `--thumbprint`, `--timestamp`, `--identity`, `--entitlements`, `--hardened-runtime`, `--notarize`, `--keychain-profile`, `--pgp-key`, `--pgp-password`, `--role`. |

В этом выпуске синтаксический анализатор CLI предоставляет `signing` и `entitlements` на верхнем уровне. Проверьте `wails3 signing --help` и `wails3 entitlements --help`; `wails3 setup signing` не выбирает мастер подписывания. Для непосредственного управления учётными данными используйте `xcrun notarytool store-credentials` или `gpg`.

## Инструменты

`wails3 tool <subcommand>`:

| Подкоманда | Описание |
| --- | --- |
| `tool checkport` | Проверяет, открыт ли TCP-порт (полезно при ожидании запуска Vite). |
| `tool watcher` | Запускает команду при каждом изменении отслеживаемых файлов. |
| `tool cp` | Кроссплатформенное копирование файлов. |
| `tool buildinfo` | Выводит встроенную в двоичный файл информацию о сборке Go. |
| `tool package` | Создаёт пакет Linux (`deb`, `rpm`, `archlinux`) из `build/linux/nfpm`. |
| `tool version` | Повышает семантическую версию проекта. |
| `tool lipo` | Объединяет двоичные файлы для нескольких архитектур macOS в универсальный двоичный файл. |
| `tool capabilities` | Проверяет наличие в системе GTK3/GTK4 и WebKit. |
| `tool sign` | (См. раздел [«Подписывание кода и упаковка»](#---).) |

## Пути к результатам сборки

- Нативные двоичные файлы помещаются в `bin/<APP_NAME>` (или в `bin/<APP_NAME>.exe` в Windows). `build/bin/` не существует.
- Упакованные результаты (`.app`, `.dmg`, установщик NSIS, MSIX, DEB/RPM/AppImage) также помещаются в `bin/` (или в подкаталоги для конкретных платформ, создаваемые соответствующей задачей Taskfile).

## Общие флаги

| Флаг | Применяется к | Описание |
| --- | --- | --- |
| `-nocolour` | Команды, в которых он указан в `--help` (например, `init` и `update cli`) | Отключает цвета ANSI в выводе CLI. Этот флаг принимают не все команды, в том числе `version`. |
