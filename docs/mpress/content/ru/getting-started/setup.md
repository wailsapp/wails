## Быстрый старт

```bash
# 1. Install the Wails CLI
go install github.com/wailsapp/wails/v3/cmd/wails3@v3.0.0

# 2. Run the setup wizard
wails3 setup
```

Мастер открывается в браузере и помогает проверить зависимости, настроить глобальные параметры проектов, дополнительные кроссплатформенные инструменты и учётные данные для подписывания. Эти настройки можно повторно использовать в разных проектах.

После этого можно приступить к созданию первого проекта:

```bash
wails3 init -n myapp -t vanilla
cd myapp && wails3 dev
```

## Возможности мастера

- **Проверка зависимостей** — проверяет Go, npm и инструменты платформы
- **Настройка параметров по умолчанию** — сведения об авторе, префикс идентификатора пакета и предпочтительные шаблоны
- **Кроссплатформенная сборка** — дополнительная настройка Docker для сборки на любой хост-системе
- **Подпись кода** — дополнительная настройка для macOS, Windows и Linux

Конфигурация сохраняется в `$XDG_CONFIG_HOME/wails/defaults.yaml`, а при невозможности — в `~/.config/wails/defaults.yaml`, и используется командой `wails3 init`. Она не связана с файлом `build/config.yml` проекта.

## Создание проекта Wake

Если экспериментальная поддержка Wake включена, `wails3 init -ui` собирает выбранные вами параметры сборки для конкретного проекта и после успешного создания сохраняет их в `wails.yaml`. При создании настольного проекта следуйте [руководству по началу работы с Wake](/experimental/wake/), чтобы выбрать бэкенд сборки, целевые платформы и форматы пакетов. `wails3 setup` по-прежнему отвечает за глобальные настройки.

Существующие проекты Wake настраиваются в `wails.yaml`. Чтобы изменить их профили и параметры упаковки, воспользуйтесь [руководством по сборке с помощью YAML](/experimental/yaml-builds/). Прежде чем использовать Wake в существующих проектах Taskfile, необходимо выполнить [проверенную одностороннюю миграцию](/experimental/wake/#migrate-an-existing-project); мастер настройки не преобразует и не выполняет их Taskfile-файлы.

## Повторное использование параметров подписи

При подписанной сборке Wake недостающие параметры подписи берутся из пользовательских настроек по умолчанию, включая файлы сертификатов за пределами проекта. Явно заданные параметры проекта имеют приоритет. Закрытые ключи, пароли и глобальные пути к учётным данным не копируются в `wails.yaml`.

Для глобально настроенных ключей Windows и Linux передайте пароль через существующее хранилище учётных данных либо через `WAILS_WINDOWS_CERT_PASSWORD` или `WAILS_PGP_PASSWORD`. Для зашифрованного удостоверения Apple задайте в `darwin.signing.credential` имя переменной окружения, содержащей пароль к нему.

## Подкоманды

```bash
wails3 signing      # Configure code signing
wails3 entitlements # Configure macOS entitlements
```

## Возникли проблемы?

1. Для диагностики проблем выполните `wails3 doctor`
2. Выполните [инструкции по установке вручную](/getting-started/installation/#platform-specific-dependencies)
3. [Сообщите о проблеме](https://github.com/wailsapp/wails/issues/4904), приложив вывод `wails3 doctor`
