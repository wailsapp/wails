## Поддерживаемые платформы

- Windows AMD64/ARM64
- macOS 10.15+ AMD64 (можно развертывать на macOS 10.13+)
- macOS 11.0+ ARM64
- Ubuntu 24.04 AMD64/ARM64 (другие дистрибутивы Linux также могут работать!)

## Зависимости

Перед установкой Wails необходимо установить ряд общих зависимостей.

@note{type="tip"}
После установки Wails CLI можно выполнить `wails3 setup`, чтобы автоматически проверить эти зависимости и получить помощь с их установкой.

@end

@tabs
[Go (не ниже 1.24)]
Скачайте Go со [страницы загрузки Go](https://go.dev/dl/).

Обязательно следуйте официальным [инструкциям по установке Go](https://go.dev/doc/install). Также убедитесь, что переменная среды `PATH` содержит путь к каталогу `~/go/bin`. Перезапустите терминал и выполните следующие проверки:

- Убедитесь, что Go установлен правильно: `go version`
- Убедитесь, что `~/go/bin` входит в переменную PATH
  - Mac / Linux: `echo $PATH | grep go/bin`
  - Windows: `$env:PATH -split ';' | Where-Object { $_ -like '*\go\bin' }`


[npm (необязательно)]
Хотя для Wails не требуется устанавливать npm, он необходим для большинства встроенных шаблонов.

Скачайте последнюю версию установщика Node со [страницы загрузки Node](https://nodejs.org/en/download/). Лучше использовать последний выпуск, поскольку обычно тестирование проводится именно с ним.

Для проверки выполните `npm --version`.

@note{type="info"}
Если вместо npm вы предпочитаете другой менеджер пакетов, можете использовать его. Для этого потребуется обновить файлы Taskfile проекта.

@end

## Зависимости для отдельных платформ

Также необходимо установить зависимости для вашей платформы:

@tabs{sync-key="platform"}
[Mac]
Для Wails необходимо установить инструменты командной строки Xcode. Для этого выполните:

```sh
xcode-select --install
```

[Windows]
Для Wails необходимо установить [среду выполнения WebView2](https://developer.microsoft.com/en-us/microsoft-edge/webview2/). Она уже установлена почти во всех системах Windows. Проверить ее наличие можно с помощью команды `wails doctor`.

[Linux]
Для Linux требуются стандартные инструменты сборки `gcc`, а также `gtk4` и `webkitgtk-6.0`. После установки выполните <code>wails3 doctor</code>, чтобы получить инструкции по установке зависимостей. Устаревший стек GTK3 / WebKit2GTK 4.1 до версии v3.1 по-прежнему доступен через `-tags gtk3` (см. [«Создание пакетов для Linux — поддержка устаревшего GTK3»](/guides/build/linux/#legacy-gtk3-support)). Если ваш дистрибутив или менеджер пакетов не поддерживается, сообщите нам об этом в Discord.

@end

## Установка

Чтобы установить Wails CLI с помощью Go Modules, выполните следующие команды:

```shell
go install -v github.com/wailsapp/wails/v3/cmd/wails3@latest
```

Чтобы установить последнюю разрабатываемую версию, выполните следующие команды:

```shell
git clone https://github.com/wailsapp/wails.git
cd wails
cd v3/cmd/wails3
go install
```

При использовании разрабатываемой версии во всех создаваемых проектах будет применяться директива Go [replace](https://go.dev/ref/mod#go-mod-file-replace), чтобы проекты использовали разрабатываемую версию Wails.

## Дальнейшие действия

После установки CLI запустите мастер настройки, чтобы настроить среду разработки:

```shell
wails3 setup
```

@note{type="caution" title="Экспериментальная функция"}
Мастер настройки появился недавно и тестировался преимущественно в Linux. Если возникнут проблемы, [сообщите о них](https://github.com/wailsapp/wails/issues/4904) и установите зависимости вручную, как описано ниже.

@end

Мастер настройки выполнит следующие действия:

- Проверит зависимости для платформы и поможет их установить
- Настроит параметры проекта по умолчанию (сведения об авторе и префикс идентификатора пакета)
- При желании настроит Docker для кроссплатформенной сборки
- Настроит подпись кода (если требуется)

Дополнительные сведения см. в [руководстве по настройке](/getting-started/setup/).

## Установка зависимостей вручную

Если вы предпочитаете устанавливать зависимости вручную или мастер настройки не работает в вашей системе, следуйте приведенным выше инструкциям для своей платформы, а затем выполните:

```shell
wails3 doctor
```

Эта команда проверит, установлены ли необходимые зависимости, и сообщит, каких из них не хватает.

## Команда `wails3` не найдена?

Если система сообщает, что команда `wails3` не найдена, проверьте следующее:

- Убедитесь, что вы правильно выполнили инструкции из приведённого выше **руководства по установке Go** и что каталог `go/bin` указан в переменной среды `PATH`.
- Закройте и снова откройте текущие терминалы, чтобы в них стала доступна новая переменная `PATH`.
