## Поддерживаемые платформы

- Windows AMD64/ARM64
- macOS AMD64/ARM64. Созданные задачи сборки предназначены для macOS 12.0 или более поздней версии. Это целевая версия развертывания для стандартной сборки, а не утверждение о том, что любая пользовательская конфигурация сборки поддерживает более старые системы.
- Ubuntu 24.04 AMD64/ARM64 (другие дистрибутивы Linux также могут работать!)

## Зависимости

Перед установкой Wails необходимо установить ряд общих зависимостей.

@note{type="tip"}
После установки Wails CLI можно выполнить команду `wails3 setup`, чтобы автоматически проверить эти зависимости и получить помощь в их установке.

@end

@tabs
[Go (не ниже 1.26)]
Wails v3 выбирает набор инструментов Go 1.26 или более поздней версии. Более старая программа запуска Go может автоматически скачать его с помощью `GOTOOLCHAIN=auto`; в противном случае установите его явно. Более низкая версия Go, указанная в начальном модуле, не переопределяет зависимость Wails.

Скачайте Go со [страницы загрузки Go](https://go.dev/dl/).

Обязательно следуйте официальным [инструкциям по установке Go](https://go.dev/doc/install). Также убедитесь, что переменная среды `PATH` содержит путь к каталогу `~/go/bin`. Перезапустите терминал и выполните следующие проверки:

- Проверьте правильность установки Go: `go version`
- Проверьте, что `~/go/bin` входит в переменную PATH
  - Mac / Linux: `echo $PATH | grep go/bin`
  - Windows: `$env:PATH -split ';' | Where-Object { $_ -like '*\go\bin' }`


[npm (необязательно)]
Хотя для Wails не требуется устанавливать npm, он необходим для большинства встроенных шаблонов.

Скачайте последнюю версию установщика Node со [страницы загрузки Node](https://nodejs.org/en/download/). Рекомендуется использовать самый свежий выпуск, поскольку обычно мы тестируем именно с ним.

Для проверки выполните `npm --version`.

@note{type="info"}
Если вы предпочитаете другой менеджер пакетов вместо npm, можете использовать его. Для этого потребуется соответствующим образом изменить Taskfile-файлы проекта.

@end

@end

## Зависимости для отдельных платформ

Также потребуется установить зависимости для вашей платформы:

@tabs{sync-key="platform"}
[Mac]
Для Wails необходимо установить инструменты командной строки Xcode. Для этого выполните:

```sh
xcode-select --install
```

[Windows]
Для Wails необходимо установить [среду выполнения WebView2](https://developer.microsoft.com/en-us/microsoft-edge/webview2/). Она уже установлена почти во всех системах Windows. Проверить ее наличие можно с помощью команды `wails doctor`.

[Linux]
Для Linux требуются стандартные инструменты сборки `gcc`, а также `gtk4` и `webkitgtk-6.0`. После установки выполните <code>wails3 doctor</code>, чтобы получить инструкции по установке зависимостей. Устаревший стек GTK3 / WebKit2GTK 4.1 по-прежнему доступен через `-tags gtk3` (см. [«Создание пакетов для Linux — поддержка устаревшего GTK3»](/guides/build/linux/#legacy-gtk3-support)) до версии v3.1. Если ваш дистрибутив или менеджер пакетов не поддерживается, сообщите нам об этом в Discord.

@end

## Установка

Чтобы установить Wails CLI с помощью модулей Go, выполните следующие команды:

```shell
go install -v github.com/wailsapp/wails/v3/cmd/wails3@v3.0.0
```

Чтобы установить последнюю версию для разработки, выполните следующие команды:

```shell
git clone https://github.com/wailsapp/wails.git
cd wails
cd v3/cmd/wails3
go install
```

При использовании версии для разработки во всех созданных проектах будет применяться директива Go [replace](https://go.dev/ref/mod#go-mod-file-replace), чтобы проекты использовали версию Wails для разработки.

## Дальнейшие действия

После установки CLI запустите мастер настройки, чтобы настроить среду разработки:

```shell
wails3 setup
```

@note{type="caution" title="Экспериментальная функция"}
Мастер настройки появился недавно и преимущественно протестирован в Linux. Если у вас возникнут проблемы, [сообщите о них](https://github.com/wailsapp/wails/issues/4904) и воспользуйтесь приведенными ниже инструкциями по ручной установке зависимостей.

@end

Мастер настройки выполнит следующие действия:

- Проверит зависимости платформы и поможет их установить
- Настроит параметры проекта по умолчанию (сведения об авторе и префикс идентификатора пакета)
- При необходимости настроит Docker для кроссплатформенных сборок
- Настроит подписание кода (если требуется)

Дополнительные сведения см. в [руководстве по настройке](/getting-started/setup/).

## Ручная установка зависимостей

Если вы предпочитаете устанавливать зависимости вручную или мастер настройки не работает в вашей системе, следуйте приведенным выше инструкциям для вашей платформы, а затем выполните:

```shell
wails3 doctor
```

Эта команда проверит, установлены ли необходимые зависимости, и сообщит, каких из них не хватает.

## Команда `wails3` не найдена?

Если система сообщает, что команда `wails3` не найдена, проверьте следующее:

- Убедитесь, что вы правильно выполнили приведенные выше инструкции из **руководства по установке Go** и что каталог `go/bin` входит в переменную среды `PATH`.
- Закройте и снова откройте текущие терминалы, чтобы они получили новую переменную `PATH`.
