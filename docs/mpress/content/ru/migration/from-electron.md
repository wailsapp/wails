Wails позволяет создавать настольные приложения с помощью Go и веб-технологий, заменяя среду выполнения Node.js из Electron одним исполняемым файлом Go. О различиях между Wails v2 и v3 см. в разделе [«Переход с v2 на v3»](/migration/v2-to-v3/).
