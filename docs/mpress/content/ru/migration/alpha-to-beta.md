Это руководство предназначено для существующих проектов v3 alpha. Для Wails v2 используйте [руководство по переходу с v2 на v3](/migration/v2-to-v3/).

## Перед обновлением

Создайте коммит или резервную копию проекта. Прочитайте [журнал изменений](/changelog/) между вашей альфа-версией и выбранной бета-версией: могут потребоваться изменения исходного кода, API или конфигурации сборки. Проверьте [политику совместимости настольных приложений](/status/) и требования вашей платформы.

В командах ниже опубликованный выпуск `v3.0.0-beta.23` используется как пример точной версии, а не как рекомендация постоянно следовать за последним выпуском. При выборе другого выпуска проверьте версии его CLI, модуля Go и среды выполнения npm и измените команды согласованно. В этом примере версия npm совпадает с версией Go без префикса `v`.

## 1. Обновите CLI

```sh
go install github.com/wailsapp/wails/v3/cmd/wails3@v3.0.0-beta.23
wails3 version
```

Убедитесь, что `wails3 version` показывает установленную версию. Старый исполняемый файл, расположенный раньше в `PATH`, может скрывать новый CLI.

## 2. Обновите модуль Go

Выполняйте команды из корня проекта. Проверьте изменения зависимостей; не обновляйте все несвязанные модули без разбора.

```sh
go get github.com/wailsapp/wails/v3@v3.0.0-beta.23
go mod tidy
```

## 3. Обновите среду выполнения фронтенда

Для проектов с npm и каталогом `frontend`:

```sh
cd frontend
npm install --save-exact @wailsio/runtime@3.0.0-beta.23
cd ..
```

Сохраните файл фиксации зависимостей и проверьте его изменения. Если фронтенд использует другой менеджер пакетов или каталог, адаптируйте этот шаг, сохраняя точную версию среды выполнения.

## 4. Повторно сгенерируйте, соберите и протестируйте

Из корня проекта повторно сгенерируйте привязки на основе Go-сервисов и выполните сборку:

```sh
wails3 generate bindings
wails3 build
```

Запустите собранное приложение и проверьте рабочие сценарии на каждой поддерживаемой платформе, для которой вы его поставляете. Проверьте и закоммитьте вместе исходный код, сгенерированные привязки, файлы модуля и изменения файла фиксации зависимостей фронтенда.

## Если обновление не удалось

Проверьте CLI в `PATH`, версию модуля командой `go list -m github.com/wailsapp/wails/v3` и установленную среду выполнения командой `npm --prefix frontend ls @wailsio/runtime`. После устранения несовпадений версий повторно сгенерируйте привязки. Не предполагайте, что любую альфа-версию можно обновить без изменений кода.

Если проблема сохраняется, [сообщите о воспроизводимой проблеме](https://github.com/wailsapp/wails/issues/new/choose), указав старую и новую версии, точную ошибку и вывод `wails3 doctor`. Для уязвимостей следуйте [политике безопасности](https://github.com/wailsapp/wails/blob/master/SECURITY.md).
