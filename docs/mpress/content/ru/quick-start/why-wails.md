Wails сочетает **производительность и простоту Go** с **гибкостью современных веб-интерфейсов**, позволяя создавать красивые нативные настольные приложения с помощью уже знакомых вам инструментов.

## Производительность, которую замечают пользователи

**Приложения Wails:**

- **Бинарные файлы размером около 15 МБ** (против 150 МБ у Electron)
- **Базовое потребление памяти — около 10 МБ** (против 100 МБ и более у Electron)
- **&lt;0.5 с на запуск** (против 2-3 с у Electron)
- **Нативный рендеринг** с помощью WebView, предоставляемого ОС

Пользователи воспринимают ваше приложение как быстрое, легковесное и профессиональное.

## Удобство разработки

**Напишите один раз — запускайте везде:**

- Единая кодовая база на Go для Windows, macOS и Linux
- Использование любого веб-фреймворка (React, Vue, Svelte, ванильный JS)
- Горячая перезагрузка во время разработки
- Автоматическое создание привязок TypeScript из кода Go

Выпускайте приложения быстрее и поддерживайте меньше кода.

## Возможности для промышленной эксплуатации

**Всё необходимое:**

- Несколько окон с независимыми жизненными циклами
- Нативные меню (приложения, контекстные и системного трея)
- Диалоговые окна для работы с файлами с нативным интерфейсом платформы
- Интеграция с системой (уведомления, буфер обмена, сочетания клавиш)
- Подписание кода и упаковка для всех платформ

Создавайте профессиональные приложения, а не прототипы.

## Ускоренная разработка

- **Одна кодовая база, три платформы** — пишите один раз и собирайте для Windows, macOS и Linux
- **Используйте имеющиеся навыки** — Go для серверной части, HTML/CSS/JS для интерфейса
- **Мгновенная обратная связь** — горячая перезагрузка во время разработки и компиляция за считаные секунды
- **Небольшие бинарные файлы** — приложения размером 15 МБ означают более быструю сборку, загрузку и итеративную разработку

## Когда стоит выбрать Wails

**Wails идеально подходит для:**

- **Бизнес-приложений** (CRM, учёт запасов, информационные панели, инструменты администрирования)
- **Инструментов разработчика** (клиенты баз данных, средства тестирования API, инструменты развёртывания)
- **Приложений для повышения продуктивности** (заметки, приложения для управления задачами, средства учёта времени)
- **Инструментов для творческой работы** (редакторы изображений, средства обработки видео, утилиты для дизайна)
- **Внутренних инструментов** (специализированные приложения компании, средства автоматизации)

## Как работает Wails

В отличие от Electron, который включает в комплект целый браузер и среду выполнения Node.js, Wails использует принципиально иной подход: ваш код Go компилируется в нативный бинарный файл, а пользовательский интерфейс работает во встроенном в операционную систему WebView. Эта архитектура обеспечивает небольшие бинарные файлы, быстрый запуск и низкое потребление памяти, благодаря чему приложения Wails воспринимаются как нативные.

### Архитектура

Приложения Wails состоят из двух основных частей, которые бесшовно взаимодействуют между собой: серверной части на Go, отвечающей за бизнес-логику и системные операции, и веб-интерфейса. Предоставляемый ОС WebView отображает интерфейс без необходимости включать браузер в комплект приложения, а слой привязок обеспечивает типобезопасное взаимодействие между Go и JavaScript.

Эта простая архитектура позволяет коду JavaScript напрямую вызывать функции Go через автоматически созданные привязки, а Go — отправлять события и данные обратно во фронтенд. Оба слоя взаимодействуют через эффективный мост в памяти с накладными расходами менее одной миллисекунды.

**Как Wails обеспечивает высокую производительность:**

1. **Среда выполнения не включается в комплект** — используется скомпилированный бинарный файл Go
2. **Нативный WebView** — предоставляемый ОС механизм рендеринга
3. **Прямой мост Go ↔ JS** — взаимодействие в памяти без сетевых накладных расходов
4. **Скомпилированный бинарный файл** — мгновенный запуск без JIT-компиляции
