Вы создали своё первое приложение на Wails. Следуйте приведённой ниже последовательности обучения или сразу переходите к нужному руководству, если уже знаете, что хотите создать.

## Дальнейшее обучение

Продолжайте обучение, последовательно создавая полноценные приложения:

1. **[Создайте сервис QR-кодов](/tutorials/01-creating-a-service/).** Научитесь предоставлять фронтенду доступ к логике Go через сервис.
2. **[Создайте список задач](/tutorials/02-todo-vanilla/).** Добавляйте, изменяйте и удаляйте данные приложения с помощью вызовов сервисов.
3. **[Создайте приложение для заметок](/tutorials/03-notes-vanilla/).** Поработайте с файлами, нативными диалоговыми окнами и сохранёнными данными.

Когда будете готовы изучить механизм выпуска новых версий, пройдите [руководство по созданию приложения с автоматическим обновлением](/tutorials/04-self-update-a-wails-app/). Результаты каждого урока приведены в разделе [со всеми учебными руководствами](/tutorials/overview/).

## Возможности

**Уже создаёте собственное приложение?** Воспользуйтесь практическим руководством по текущей задаче:

| Я хочу… | С чего начать |
| --- | --- |
| Вызывать Go из фронтенда | [Вызов Go из JavaScript](/features/bindings/methods/) |
| Открыть окно или управлять им | [Основы работы с окнами](/features/windows/basics/) |
| Добавить нативные меню или значок в области уведомлений | [Меню приложения](/features/menus/application/) или [меню в области уведомлений](/features/menus/systray/) |
| Предложить пользователю открыть или сохранить файл | [Диалоговые окна для работы с файлами](/features/dialogs/file/) |
| Передавать события между компонентами | [Система событий](/features/events/system/) |
| Копировать текст или принимать перетаскиваемые файлы | [Буфер обмена](/features/clipboard/basics/) или [перетаскивание файлов](/features/drag-and-drop/files/) |
| Добавить сочетания клавиш | [Сочетания клавиш](/features/keyboard/shortcuts/) |
| Собрать и упаковать приложение | [Сборка приложений](/guides/build/building/), затем упаковка для [Windows](/guides/build/windows/), [macOS](/guides/build/macos/) или [Linux](/guides/build/linux/) |

Эти страницы находятся в разделе **«Практические руководства»** на боковой панели. Можно сразу открыть нужную тему, не читая весь раздел по порядку.

## Как работает Wails

Обратитесь к разделу **«Основные концепции»**, чтобы понять архитектурные решения, лежащие в основе кода:

- В разделе [«Как работает Wails»](/concepts/architecture/) описана связь между бэкендом на Go, фронтендом и нативным WebView.
- В разделе [«Мост между Go и фронтендом»](/concepts/bridge/) объясняется, как выполняются вызовы между Go и JavaScript.
- В разделе [«Жизненный цикл приложения»](/concepts/lifecycle/) описаны запуск и завершение работы.
- В разделе [«Система сборки»](/concepts/build-system/) объясняется роль задач проекта и инструментов фронтенда.

## Справочник по API

Если вместо учебного материала вам нужны сведения о типе, методе, параметре или команде, обратитесь к [справочнику по API](/reference/overview/). Для работы в командной строке начните с [обзора команд CLI](/reference/cli/), а подробные сведения об отдельных командах ищите в разделе [«Флаги CLI и примеры»](/guides/cli/).
