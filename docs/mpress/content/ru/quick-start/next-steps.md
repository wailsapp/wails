Вы создали своё первое приложение Wails и освоили основы. Вот что можно изучить дальше.

## Узнайте больше

Закрепите навыки, создавая полноценные приложения:

- [Приложение со списком задач](/tutorials/02-todo-vanilla/) — CRUD-операции, управление состоянием, современный пользовательский интерфейс
- [Все руководства](/tutorials/overview/) — приложения для заметок, панели мониторинга, приложения в области уведомлений и многое другое

## Возможности

Wails предоставляет нативные возможности для настольных приложений:

- [Окна](/features/windows/basics/) — несколько окон, окна без рамки, позиционирование
- [Меню](/features/menus/application/) — меню приложения, контекстные меню, область уведомлений
- [Диалоговые окна](/features/dialogs/file/) — открытие и сохранение файлов, диалоговые окна сообщений
- [События](/features/events/system/) — взаимодействие между компонентами
- [Привязки](/features/bindings/methods/) — типобезопасные вызовы между Go и JavaScript
- [Буфер обмена](/features/clipboard/basics/) — операции копирования и вставки
- [Перетаскивание](/features/drag-and-drop/files/) — перетаскивание файлов
- [Клавиатура](/features/keyboard/shortcuts/) — глобальные сочетания клавиш
