You've built your first Wails app. Follow the learning path below, or jump to a guide when you already know what you want to build.

## Learn More

Continue learning with one complete application at a time:

1. **[Create a QR code service](/tutorials/01-creating-a-service/).** Practise exposing Go logic to your frontend through a service.
2. **[Build a TODO list](/tutorials/02-todo-vanilla/).** Add, change and delete application data through service calls.
3. **[Build a Notes app](/tutorials/03-notes-vanilla/).** Work with files, native dialogs and saved data.

Once you're ready to explore releases, follow the [self-updating app tutorial](/tutorials/04-self-update-a-wails-app/). See [all tutorials](/tutorials/overview/) for the lesson outcomes.

## Features

**Already building your own app?** Use a how-to guide for the task in front of you:

| I want to… | Start here |
| --- | --- |
| Call Go from my frontend | [Call Go from JavaScript](/features/bindings/methods/) |
| Open or manage a window | [Window basics](/features/windows/basics/) |
| Add native menus or a tray icon | [Application menus](/features/menus/application/) or [system tray menus](/features/menus/systray/) |
| Ask the user to open or save a file | [File dialogs](/features/dialogs/file/) |
| Send events between components | [Event system](/features/events/system/) |
| Copy text or accept dropped files | [Clipboard](/features/clipboard/basics/) or [file drag and drop](/features/drag-and-drop/files/) |

| Build and package my app | [Building applications](/guides/build/building/), then package for [Windows](/guides/build/windows/), [macOS](/guides/build/macos/) or [Linux](/guides/build/linux/) |

## Understand How Wails Works

Use **Core Concepts** when you want to understand the design behind the code:

- [How Wails works](/concepts/architecture/) connects the Go backend, frontend and native WebView.
- [Go-frontend bridge](/concepts/bridge/) explains how calls cross between Go and JavaScript.
- [Application lifecycle](/concepts/lifecycle/) explains startup and shutdown.
- [Build system](/concepts/build-system/) explains the role of project tasks and frontend tooling.

## Look Up an API

Use the [API Reference](/reference/overview/) when you need a type, method, option or command rather than a lesson. For command-line work, start with the [CLI command overview](/reference/cli/); use [CLI flags and examples](/guides/cli/) for individual command details.

## Get Help

Check the [frequently asked questions](/faq/), browse the [working examples](https://github.com/wailsapp/wails/tree/releases/v3-beta/v3/examples), or ask in [Discord](https://discord.gg/JDdSxwjhGf). Platform-specific problems are grouped under **Troubleshooting** in the sidebar.
