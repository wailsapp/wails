Sie können RESTful APIs aus Ihrer Wails-v3-Anwendung mithilfe standardmäßiger Go-`net/http`-Handler oder eines Frameworks wie [Gin](/guides/gin-routing/) bereitstellen. Da Wails Ihr Frontend über einen Asset-Handler bereitstellt, können Sie jeden HTTP-Handler einbinden und über Ihre Benutzeroberfläche oder andere Clients darauf zugreifen.
