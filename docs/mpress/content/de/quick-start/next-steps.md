Du hast deine erste Wails-App erstellt. Folge dem nachstehenden Lernpfad oder gehe direkt zu einer Anleitung, wenn du bereits weißt, was du entwickeln möchtest.

## Mehr erfahren

Vertiefe dein Wissen anhand jeweils einer vollständigen Anwendung:

1. **[Erstelle einen QR-Code-Dienst](/tutorials/01-creating-a-service/).** Übe, Go-Logik über einen Dienst für dein Frontend bereitzustellen.
2. **[Erstelle eine TODO-Liste](/tutorials/02-todo-vanilla/).** Füge Anwendungsdaten über Dienstaufrufe hinzu, ändere und lösche sie.
3. **[Erstelle eine Notizen-App](/tutorials/03-notes-vanilla/).** Arbeite mit Dateien, nativen Dialogfeldern und gespeicherten Daten.

Wenn du dich mit Releases beschäftigen möchtest, arbeite das [Tutorial zu selbstaktualisierenden Apps](/tutorials/04-self-update-a-wails-app/) durch. Unter [Alle Tutorials](/tutorials/overview/) findest du die Lernziele.

## Funktionen

**Entwickelst du bereits deine eigene App?** Nutze für deine aktuelle Aufgabe eine Schritt-für-Schritt-Anleitung:

| Ich möchte … | Hier beginnen |
| --- | --- |
| Go aus meinem Frontend aufrufen | [Go aus JavaScript aufrufen](/features/bindings/methods/) |
| Ein Fenster öffnen oder verwalten | [Grundlagen zu Fenstern](/features/windows/basics/) |
| Native Menüs oder ein Taskleistensymbol hinzufügen | [Anwendungsmenüs](/features/menus/application/) oder [Taskleistenmenüs](/features/menus/systray/) |
| Den Benutzer eine Datei öffnen oder speichern lassen | [Dateidialogfelder](/features/dialogs/file/) |
| Ereignisse zwischen Komponenten senden | [Ereignissystem](/features/events/system/) |
| Text kopieren oder abgelegte Dateien annehmen | [Zwischenablage](/features/clipboard/basics/) oder [Drag-and-drop für Dateien](/features/drag-and-drop/files/) |
| Tastenkombinationen hinzufügen | [Tastenkombinationen](/features/keyboard/shortcuts/) |
| Meine App erstellen und paketieren | [Anwendungen erstellen](/guides/build/building/) und anschließend für [Windows](/guides/build/windows/), [macOS](/guides/build/macos/) oder [Linux](/guides/build/linux/) paketieren |

Diese Seiten findest du in der Seitenleiste unter **Schritt-für-Schritt-Anleitungen**. Du kannst das relevante Thema direkt öffnen, ohne den gesamten Abschnitt der Reihe nach zu lesen.

## Funktionsweise von Wails verstehen

Nutze **Grundlegende Konzepte**, wenn du den Aufbau hinter dem Code verstehen möchtest:

- [Funktionsweise von Wails](/concepts/architecture/) erläutert die Verbindung zwischen dem Go-Backend, dem Frontend und der nativen WebView.
- [Go-Frontend-Bridge](/concepts/bridge/) erläutert, wie Aufrufe zwischen Go und JavaScript übertragen werden.
- [Anwendungslebenszyklus](/concepts/lifecycle/) erläutert das Starten und Beenden.
- [Build-System](/concepts/build-system/) erläutert die Rolle von Projekt-Tasks und Frontend-Werkzeugen.

## Eine API nachschlagen

Nutze die [API-Referenz](/reference/overview/), wenn du statt einer Lektion einen Typ, eine Methode, eine Option oder einen Befehl benötigst. Beginne für Arbeiten auf der Befehlszeile mit der [Übersicht der CLI-Befehle](/reference/cli/). Einzelheiten zu bestimmten Befehlen findest du unter [CLI-Flags und Beispiele](/guides/cli/).
