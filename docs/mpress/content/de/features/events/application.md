Anwendungsereignisse werden bei anwendungsweiten Änderungen des Lebenszyklus ausgegeben, etwa beim Starten und Beenden sowie bei Vorgängen zur Fensterverwaltung.

Eine vollständige Dokumentation der Anwendungsereignisse finden Sie im Leitfaden zum [Ereignissystem](/features/events/system/#application-events).
