Verwende die offiziellen Wails-Grafiken, wenn du ein mit Wails erstelltes Projekt vorstellst. Die folgenden Buttons verlinken auf [wails.io](https://wails.io) und werden weiterhin von Wails gehostet. Du musst das Bild daher nicht in dein Projekt kopieren.

## Mit Wails erstellt

Wähle die Variante mit ausreichendem Kontrast zum Hintergrund. Jede Vorschau zeigt genau das verlinkte Bild, das deine Besucher sehen werden.

#### HTML

```html
<a href="https://wails.io">
  <img src="https://wails.io/img/wails-button-light.svg" width="180" height="48" alt="Built with Wails">
</a>
```

Verwende für die kompakte Variante `width="90" height="24"`.

#### Markdown

```md
[![Built with Wails](https://wails.io/img/wails-button-light.svg)](https://wails.io)
```

#### Markdown

```md
[![Built with Wails](https://wails.io/img/wails-button-dark.svg)](https://wails.io)
```

Markdown zeigt das Bild in seiner ursprünglichen Größe von `180` mal `48` Pixeln an. Verwende die HTML-Variante, wenn du eine andere Anzeigegröße festlegen möchtest. Behalte das ursprüngliche Seitenverhältnis der Buttons von `15:4` bei.
