BMEditor, der Bare Minimum Editor (batteries included), ist ein Desktop-Code-Editor für Windows und Linux, der sofort nach dem Öffnen einsatzbereit ist. Debugger, Terminal, Docker, die Git-Änderungen im Projekt und Live-Vorschauen für Markdown, HTML und OpenAPI gehören zum Editor selbst, du musst also nichts erst suchen oder einrichten. Go funktioniert ohne Einrichtung, und der Editor ist erweiterbar: weitere Sprachen und Werkzeuge kommen über Erweiterungen dazu.

Aus demselben Fenster heraus öffnest du einen Ordner in WSL, auf einem Server über SSH oder in einem Docker-Container, ohne dort etwas zu installieren. Wenn du Claude Code oder GitHub Copilot CLI nutzt, läuft es im Seitenpanel, und die Dateien, die es ändert, kommen als Review zu dir zurück, das du Änderung für Änderung annimmst oder ablehnst. Layout und Tastenkürzel folgen VS Code, deshalb fühlt es sich von der ersten Minute an vertraut an.

Gebaut mit Wails 3, Go und Vue, und kostenlos nutzbar.
