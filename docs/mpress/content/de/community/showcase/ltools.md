[LTools](https://github.com/lian-yang/ltools) ist ein von uTools inspirierter, Plugin-basierter plattformübergreifender Desktop-Werkzeugkasten, der mit Wails v3 erstellt wurde. Eine modulare Plugin-Architektur bündelt darin verschiedene Dienstprogramme für Entwickler an einem zentralen Ort.

LTools bietet eine globale Suchleiste im Stil von Spotlight, eine Integration in den Systembereich der Taskleiste sowie integrierte Plugins, darunter eine Zwischenablageverwaltung, ein Screenshot-Werkzeug mit Anmerkungsfunktion, einen JSON-Editor, einen Taschenrechner, eine Systemüberwachung und weitere Werkzeuge. Über das erweiterbare Plugin-System lassen sich neue Werkzeuge hinzufügen.
