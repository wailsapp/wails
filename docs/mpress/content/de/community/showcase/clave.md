Hauptfunktionen

- 🎨 Einfaches, intuitives Design für eine mühelose Bedienung
- ✅ Konten einfach durch manuelle Eingabe oder Import eines QR-Code-Bildes hinzufügen.
- 🔒 Ende-zu-Ende-Verschlüsselung mit PIN oder Touch ID (nur macOS).
- 💻 Verfügbar für macOS, Windows und Linux
- ⚡ Bequemer Schnellzugriff über den Infobereich
- 📂 Profile einfach sichern und wiederherstellen

Clave noch heute ausprobieren!
