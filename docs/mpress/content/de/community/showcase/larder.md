[Larder](https://github.com/599yongyang/larder) ist eine Local-First-Desktop-App für Entwickler, die mit mehreren KI-Agenten arbeiten. Sie scannt die tatsächlich auf dem Datenträger vorhandenen Dateien – Skills, MCP-Server, CLI-Tools, Anweisungsdateien und benutzerdefinierte Befehle – und erklärt, was jeder Agent wirklich sieht.

Larder findet defekte Links, doppelte Skills und veraltete Konfiguration. Jede Änderung läuft über einen Plan und einen Snapshot und kann zurückgerollt werden. Außerdem unterstützt Larder auswählbare Datenpakete und optional verschlüsselte WebDAV/S3-Backups.

Erstellt mit Go 1.26, Wails v3 beta.34, React 18, SQLite und Tailwind CSS. MIT-Lizenz.
