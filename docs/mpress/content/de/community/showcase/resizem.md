[Resizem](https://github.com/barats/resizem) ist eine App zur Stapelverarbeitung von Bildern. Sie ist besonders nützlich für Benutzer, die eine große Anzahl von Bilddateien gleichzeitig skalieren, konvertieren und verwalten müssen.
