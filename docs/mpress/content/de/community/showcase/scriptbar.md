[ScriptBar](https://GitHub.com/raguay/ScriptBarApp) ist ein Programm, das die Ausgabe von Skripten oder eines [Node-Red](https://nodered.org)-Servers anzeigt. Es führt im Programm EmailIt definierte Skripte aus und zeigt deren Ausgabe an. Skripte aus xBar oder TextBar können verwendet werden, derzeit funktionieren jedoch nur die TextBar-Skripte zuverlässig. Außerdem zeigt es die Ausgabe von Skripten auf Ihrem System an. ScriptBar platziert sie nicht in der Menüleiste, sondern fasst sie zur einfachen Anzeige in einem übersichtlichen Fenster zusammen. Sie können mehrere Registerkarten verwenden, um viele verschiedene Inhalte anzuzeigen. Außerdem können Sie Links zu den von Ihnen am häufigsten besuchten Websites speichern.
