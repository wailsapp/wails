Die Anwendung [BulletinBoard](https://github.com/raguay/BulletinBoard) ist ein vielseitiges Nachrichtenbrett für statische Mitteilungen oder Dialogfelder, mit denen ein Skript Informationen vom Benutzer abfragen kann. Sie verfügt über eine TUI zum Erstellen neuer Dialogfelder, die später zur Abfrage von Informationen beim Benutzer verwendet werden können. Sie ist dafür ausgelegt, dauerhaft auf dem System ausgeführt zu werden, Informationen bei Bedarf anzuzeigen und sich anschließend wieder auszublenden. Ich verwende einen Prozess, der eine Datei auf meinem System überwacht und ihren Inhalt bei Änderungen an BulletinBoard sendet. Das funktioniert hervorragend mit meinen Arbeitsabläufen. Außerdem gibt es einen [Alfred-Arbeitsablauf](https://github.com/raguay/MyAlfred/blob/master/Alfred%205/EmailIt.alfredworkflow) zum Senden von Informationen an das Programm. Der Arbeitsablauf unterstützt auch die Verwendung mit [EmailIt](https://github.com/raguay/EmailIt).
