## 기능

Wails는 네이티브 데스크톱 기능을 제공합니다.

- [창](/features/windows/basics/) - 다중 창, 프레임 없는 창, 위치 지정
- [메뉴](/features/menus/application/) - 애플리케이션 메뉴, 컨텍스트 메뉴, 시스템 트레이
- [대화 상자](/features/dialogs/file/) - 파일 열기 및 저장, 메시지 대화 상자
- [이벤트](/features/events/system/) - 컴포넌트 간 통신
- [바인딩](/features/bindings/methods/) - 타입 안전성을 갖춘 Go ↔ JavaScript 호출
- [클립보드](/features/clipboard/basics/) - 복사 및 붙여넣기 작업
- [드래그 앤 드롭](/features/drag-and-drop/files/) - 파일 드래그 앤 드롭
- [키보드](/features/keyboard/shortcuts/) - 전역 단축키
