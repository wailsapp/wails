[Larder](https://github.com/599yongyang/larder)는 여러 AI Agent를 함께 사용하는 개발자를 위한 로컬 우선 데스크톱 앱입니다. 디스크에 실제로 존재하는 Skills, MCP 서버, CLI 도구, 지침 파일, 사용자 지정 명령을 스캔하고 각 Agent가 실제로 무엇을 보는지 설명합니다.

깨진 링크, 중복 Skill, 오래된 설정을 찾는 데 도움을 줍니다. 모든 쓰기는 계획과 스냅샷을 거치므로 변경을 되돌릴 수 있습니다. 선택 가능한 데이터 패키지와 선택적 암호화 WebDAV/S3 백업도 지원합니다.

Go 1.26, Wails v3 beta.34, React 18, SQLite, Tailwind CSS로 제작했습니다. MIT 라이선스.

[GitHub에서 보기](https://github.com/599yongyang/larder)
