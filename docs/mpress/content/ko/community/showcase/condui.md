Condui는 종단 간 암호화 다중 기기 동기화 기능을 갖춘 SSH 연결 관리자입니다. 사용하는 모든 기기에서 연결, SSH 터널, 볼트로 보호된 자격 증명을 동기화하며, 동기화 서버에는 평문 자격 증명이 절대 노출되지 않습니다.

주요 기능

- 🔐 SSH 비밀번호와 개인 키 암호 구문을 위한 종단 간 암호화 볼트
- 🔄 연결, 폴더 및 SSH 터널의 다중 기기 동기화
- 🌐 연결별로 유지되는 로컬 포트 포워딩 터널
- 🖥️ 통합 터미널, SFTP, Docker 및 데이터베이스 도구
- 💻 macOS, Windows 및 Linux 지원
