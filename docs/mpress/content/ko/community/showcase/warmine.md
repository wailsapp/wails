[WarMine용 Minecraft 런처](https://warmine.ru/)는 모드가 적용된 게임 서버에 쉽게 접속하고 게임 계정을 관리할 수 있는 Wails 애플리케이션입니다.

런처는 게임 파일을 다운로드하고 무결성을 검사한 후, 백엔드에서 실행 인수를 폭넓게 사용자 지정할 수 있도록 게임을 실행합니다.

프런트엔드는 Svelte로 작성되었으며, 전체 런처의 용량은 9MB이고 Windows 7-11을 지원합니다.
