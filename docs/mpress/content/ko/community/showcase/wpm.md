사용자 지정 배경 화면, 여러 모니터, 무작위 또는 순차적 배경 화면 변경을 지원하는 Windows 배경 화면 앱입니다.

Windows 기본 슬라이드 쇼는 여러 폴더의 이미지를 먼저 모으지 않으면 함께 선택할 수 없습니다. wpm에서는 여러 폴더를 선택하거나 모니터마다 다른 폴더를 사용할 수 있습니다. 각 화면의 가로세로 비율에 맞는 이미지를 무작위로 선택할 수 있습니다.
