[FileHound 내보내기 유틸리티](https://www.filehound.co.uk/) FileHound는 안전한 파일 보존, 비즈니스 프로세스 자동화 및 SmartCapture 기능을 위해 개발된 클라우드 문서 관리 플랫폼입니다.

FileHound 내보내기 유틸리티를 사용하면 FileHound 관리자가 대체 백업 및 복구를 위해 문서와 데이터를 안전하게 추출하는 작업을 실행할 수 있습니다. 이 애플리케이션은 선택한 필터에 따라 FileHound에 저장된 모든 문서 및/또는 메타데이터를 다운로드합니다. 메타데이터는 JSON 및 XML 형식으로 모두 내보냅니다.

백엔드에 사용된 기술:

- Go 1.15
- Wails 1.11.0
- go-sqlite3 1.14.6
- go-linq 3.2

프런트엔드에 사용된 기술:

- Vue 2.6.11
- Vuex 3.4.0
- TypeScript
- Tailwind 1.9.6
