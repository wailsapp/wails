MyGit은 Wails 3, Go, React로 만든 worktree 중심의 데스크톱 Git 클라이언트입니다. 여러 저장소를 공통 루트 아래에 묶고, 각 worktree를 별도의 탭으로 열며, 기록, diff와 blame, 모든 Git 작업, 다중 탭 PTY 터미널, AI가 생성한 커밋 메시지를 하나의 네이티브 창에 모아 줍니다.
