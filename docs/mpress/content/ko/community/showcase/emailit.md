[EmailIt](https://github.com/raguay/EmailIt/)은 9개의 메모장, 텍스트 조작용 스크립트, 템플릿을 갖춘 Markdown 기반 이메일 전송 전용 Wails 2 프로그램입니다. 또한 EmailIt에서 시스템의 파일을 대상으로 스크립트를 실행할 수 있는 스크립트 터미널도 제공합니다. 스크립트와 템플릿은 명령줄에서 직접 사용하거나 Alfred, Keyboard Maestro, Dropzone 또는 PopClip 확장 프로그램을 통해 사용할 수 있습니다. GitHub에서 다운로드한 스크립트와 테마도 지원합니다. 문서는 완성되지 않았지만 프로그램은 작동합니다. Wails2와 Svelte를 사용해 빌드했으며, 다운로드 파일은 macOS 범용 애플리케이션입니다.
