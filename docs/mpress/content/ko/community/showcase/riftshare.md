누구나 쉽고 안전하게 무료로 파일을 공유할 수 있습니다. 자세한 내용은 다음에서 확인하세요. [Riftshare.app](https://riftshare.app)

## 기능

- 로컬 네트워크와 인터넷을 통해 컴퓨터 간에 파일을 쉽고 안전하게 공유
- [magic wormhole 프로토콜](https://magic-wormhole.readthedocs.io/en/latest/)을 통해 파일이나 디렉터리를 안전하게 전송할 수 있음
- magic wormhole을 사용하는 다른 모든 앱과 호환됨(magic-wormhole 또는 wormhole-william CLI, wormhole-gui 등)
- 선택한 여러 파일을 한 번에 전송할 수 있도록 자동으로 압축
- 송수신 시 전체 애니메이션, 진행률 표시줄 및 취소 기능 지원
- 운영 체제 기본 파일 선택 기능
- 수신한 파일을 클릭 한 번으로 열기
- 자동 업데이트 - 최신 릴리스인지 걱정하지 않아도 됩니다!
