Burp Suite Repeater에서 영감을 받은 데스크톱 HTTP 요청 리플레이어입니다. 원시 HTTP 요청을 편집하고, 작성한 그대로 TCP/TLS 소켓으로 전송하며, 탭별 히스토리를 유지합니다. 프록시도 JVM도 필요 없습니다. curl/fetch 스니펫 가져오기, 탭별 다운스트림 프록시, 자체 LLM 엔드포인트로 요청과 페이로드 초안 작성을 지원합니다. Wails v2, Go, Vue 3, CodeMirror 6로 제작; Apache-2.0.

[GitHub에서 보기](https://github.com/chenshiyi007/HttpRepeater)
