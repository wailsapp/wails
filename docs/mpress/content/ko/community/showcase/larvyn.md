Larvyn은 Linux, macOS, Windows용 Laravel 개발자를 위한 데스크톱 워크벤치입니다. Laravel 앱과 개발 서비스(artisan serve, Vite, 큐, Reverb 등), 실제 터미널, 데이터베이스, Tinker, 테스트, 로그, AI 코딩 에이전트를 하나의 네이티브 창에 모았습니다.

Claude Code, Codex, OpenCode, Cursor Agent, Aider 등을 각자의 git worktree에서 나란히 실행하고, diff를 비교한 뒤 가장 좋은 결과를 병합하세요. Wails 3, Go, React로 만들었습니다.
