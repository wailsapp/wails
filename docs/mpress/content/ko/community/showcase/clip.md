![Clip 스크린샷](/assets/showcase-images/clip.png)

- **3열 레이아웃**: 소스/폴더 트리 · 글 목록 · 읽기 보기를 제공합니다.
- **구독 관리**: 피드를 추가하고 폴더로 정리하며 OPML을 가져오거나 내보낼 수 있습니다.
- **예약 가져오기**: RSS / Atom을 파싱하고 백그라운드에서 자동으로 새로 고칩니다.
- **집중 읽기**: 전문 읽기 보기와 방해 요소를 없앤 집중 모드를 제공합니다.
- **빠른 검색**: 제목, 요약, 메모 전체를 대상으로 전문 검색을 수행합니다.
- **메모**: 글에 메모를 첨부해 나중에 다시 살펴볼 수 있습니다.
- **데스크톱 알림**: 새 글 알림과 macOS Dock / Windows 작업 표시줄 배지를 제공합니다.
- **키보드 조작**: 다양한 작업을 위한 단축키를 제공합니다.
- **테마 및 다국어 지원**: 밝은 테마 / 어두운 테마 / 시스템 설정 따르기와 여러 언어를 지원합니다.
- **성능 및 오프라인 사용**: 가벼운 목록 쿼리, 로컬 캐시, 오프라인 읽기를 지원합니다.
