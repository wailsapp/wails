애플리케이션 이벤트는 시작, 종료, 창 관리 작업과 같이 애플리케이션 전체에 영향을 주는 수명 주기 변경 시 발생합니다.

애플리케이션 이벤트에 관한 전체 문서는 [이벤트 시스템](/features/events/system/#application-events) 가이드에서 확인할 수 있습니다.
