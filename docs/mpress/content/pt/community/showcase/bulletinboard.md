O aplicativo [BulletinBoard](https://github.com/raguay/BulletinBoard) é um quadro de mensagens versátil para exibir mensagens estáticas ou caixas de diálogo que coletam informações do usuário para um script. Ele conta com uma TUI para criar novas caixas de diálogo que podem ser usadas posteriormente para coletar informações do usuário. Foi projetado para permanecer em execução no sistema, exibir as informações conforme necessário e depois se ocultar. Tenho um processo que monitora um arquivo no meu sistema e envia o conteúdo ao BulletinBoard quando ele é alterado. Ele funciona muito bem com meus fluxos de trabalho. Também há um [fluxo de trabalho do Alfred](https://github.com/raguay/MyAlfred/blob/master/Alfred%205/EmailIt.alfredworkflow) para enviar informações ao programa. Esse fluxo de trabalho também permite trabalhar com o [EmailIt](https://github.com/raguay/EmailIt).
