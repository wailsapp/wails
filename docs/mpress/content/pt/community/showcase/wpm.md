Um aplicativo de papel de parede para Windows com suporte a imagens personalizadas, vários monitores e trocas aleatórias ou sequenciais.

A apresentação de slides integrada ao Windows não permite selecionar imagens de várias pastas sem antes reuni-las. O wpm permite escolher várias pastas ou usar pastas diferentes para cada monitor. Ele pode selecionar uma imagem aleatória com proporções adequadas a cada tela.
