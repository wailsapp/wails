O [EmailIt](https://github.com/raguay/EmailIt/) é um programa desenvolvido com Wails 2 que funciona exclusivamente como um cliente de envio de e-mails baseado em Markdown, com nove blocos de notas, scripts para manipular o texto e modelos. Ele também inclui um terminal de scripts para executar, no EmailIt, scripts em arquivos do seu sistema. Os scripts e modelos podem ser usados diretamente pela linha de comando ou com as extensões Alfred, Keyboard Maestro, Dropzone ou PopClip. Ele também oferece suporte a scripts e temas baixados do GitHub. A documentação não está completa, mas o programa funciona. Ele foi desenvolvido com Wails2 e Svelte, e o arquivo para download é um aplicativo universal para macOS.
