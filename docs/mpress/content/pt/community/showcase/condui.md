O Condui é um gerenciador de conexões SSH com sincronização entre vários dispositivos e criptografia de ponta a ponta. Ele mantém suas conexões, seus túneis SSH e suas credenciais protegidas por cofre sincronizados em todos os dispositivos que você usa, sem que o servidor de sincronização jamais tenha acesso às suas credenciais em texto simples.

Principais recursos

- 🔐 Cofre com criptografia de ponta a ponta para senhas SSH e frases secretas de chaves privadas
- 🔄 Sincronização de conexões, pastas e túneis SSH entre vários dispositivos
- 🌐 Túneis de encaminhamento de portas locais mantidos por conexão
- 🖥️ Ferramentas integradas para terminal, SFTP, Docker e bancos de dados
- 💻 Disponível para macOS, Windows e Linux
