O [LTools](https://github.com/lian-yang/ltools) é uma caixa de ferramentas multiplataforma para desktop baseada em plugins, desenvolvida com Wails v3 e inspirada no uTools. Ele oferece uma central unificada de utilitários para desenvolvedores por meio de uma arquitetura modular de plugins.

Ele conta com uma barra de pesquisa global (no estilo Spotlight), integração com a bandeja do sistema e plugins integrados, incluindo gerenciador da área de transferência, ferramenta de captura de tela com anotações, editor de JSON, calculadora, monitor do sistema e muito mais. Novas ferramentas podem ser adicionadas por meio do seu sistema extensível de plugins.
