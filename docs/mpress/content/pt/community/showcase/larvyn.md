Larvyn é uma bancada de trabalho desktop para desenvolvedores Laravel no Linux, macOS e Windows. Reúne seus apps Laravel, os serviços de desenvolvimento (artisan serve, Vite, filas, Reverb…), terminais reais, banco de dados, Tinker, testes, logs e agentes de IA de código em uma única janela nativa.

Inicie Claude Code, Codex, OpenCode, Cursor Agent, Aider e outros lado a lado, cada um em seu próprio git worktree, compare os diffs e faça merge do melhor. Feito com Wails 3, Go e React.
