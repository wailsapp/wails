O [ScriptBar](https://GitHub.com/raguay/ScriptBarApp) é um programa que exibe a saída de scripts ou de um servidor [Node-Red](https://nodered.org). Ele executa scripts definidos no programa EmailIt e exibe a saída. É possível usar scripts do xBar ou do TextBar, mas, no momento, apenas os scripts do TextBar funcionam bem. Ele também exibe a saída de scripts do seu sistema. O ScriptBar não os coloca na barra de menus; em vez disso, reúne todos em uma janela conveniente para facilitar a visualização. Você pode usar várias abas para exibir muitas informações diferentes. Também pode manter links para os sites que visita com mais frequência.
