[Utilitário de Exportação FileHound](https://www.filehound.co.uk/) O FileHound é uma plataforma de gerenciamento de documentos na nuvem criada para retenção segura de arquivos, automação de processos de negócios e recursos do SmartCapture.

O Utilitário de Exportação FileHound permite que os administradores do FileHound executem tarefas seguras de extração de documentos e dados para fins alternativos de backup e recuperação. Este aplicativo baixará todos os documentos e/ou metadados salvos no FileHound com base nos filtros escolhidos. Os metadados serão exportados nos formatos JSON e XML.

Backend criado com:

- Go 1.15
- Wails 1.11.0
- go-sqlite3 1.14.6
- go-linq 3.2

Frontend criado com:

- Vue 2.6.11
- Vuex 3.4.0
- TypeScript
- Tailwind 1.9.6
