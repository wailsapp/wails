O [Minecraft Updater](https://github.com/Gurkengewuerz/MinecraftModUpdater) é uma ferramenta utilitária para atualizar e sincronizar mods do Minecraft para sua base de usuários. Ele foi desenvolvido usando Wails2 e React, com [antd](https://ant.design/) como framework de frontend.
