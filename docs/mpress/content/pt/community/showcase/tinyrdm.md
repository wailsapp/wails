O aplicativo [Tiny RDM](https://redis.tinycraft.cc/) é uma interface gráfica moderna, leve e de código aberto para o Redis. Ele oferece uma interface bonita, gerenciamento intuitivo de bancos de dados Redis e compatibilidade com Windows, Mac e Linux. Inclui operações visuais com dados de chave-valor, diversas opções de decodificação e visualização de dados, um console integrado para executar comandos, consultas a logs de operações lentas e muito mais.
