[Larder](https://github.com/599yongyang/larder) é um aplicativo desktop local-first para desenvolvedores que usam vários Agentes de IA. Ele examina os arquivos que realmente existem no disco — Skills, servidores MCP, ferramentas CLI, arquivos de instruções e comandos personalizados — e explica o que cada Agente realmente vê.

O Larder ajuda a encontrar links quebrados, Skills duplicadas e configurações desatualizadas. Toda gravação passa por um plano e um snapshot, então as alterações podem ser revertidas. O Larder também oferece pacotes de dados selecionáveis e backup opcional criptografado em WebDAV/S3.

Criado com Go 1.26, Wails v3 beta.34, React 18, SQLite e Tailwind CSS. Licença MIT.
