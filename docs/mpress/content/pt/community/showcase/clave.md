Principais recursos

- 🎨 Design simples e intuitivo para uma experiência sem complicações
- ✅ Adicione contas facilmente por inserção manual ou importando uma imagem de código QR.
- 🔒 Criptografia de ponta a ponta com PIN ou Touch ID (somente no macOS).
- 💻 Disponível para macOS, Windows e Linux
- ⚡ Acesso rápido pela bandeja do sistema para maior praticidade
- 📂 Faça backup e restaure seus perfis facilmente
