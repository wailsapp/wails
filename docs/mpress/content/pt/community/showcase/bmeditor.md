O BMEditor, o Bare Minimum Editor (batteries included), é um editor de código para desktop, no Windows e no Linux, que está pronto para trabalhar assim que abre. O depurador, um terminal, o Docker, as alterações do Git no projeto e pré-visualizações ao vivo de Markdown, HTML e OpenAPI fazem parte do editor, então não há nada para procurar ou configurar antes. Go funciona de imediato, e o editor é extensível: outras linguagens e ferramentas chegam por extensões.

Na mesma janela, você abre uma pasta no WSL, em um servidor via SSH ou dentro de um contêiner Docker, sem instalar nada do outro lado. Se você usa o Claude Code ou o GitHub Copilot CLI, ele roda no painel lateral, e os arquivos que ele altera voltam para você como uma revisão, que você aceita ou rejeita alteração por alteração. O layout e os atalhos seguem o VS Code, então tudo parece familiar desde o primeiro minuto.

Foi feito com Wails 3, Go e Vue, e é gratuito.
