## Recursos

O Wails oferece recursos nativos para desktop:

- [Janelas](/features/windows/basics/) - Várias janelas, janelas sem moldura, posicionamento
- [Menus](/features/menus/application/) - Menus do aplicativo, menus de contexto, bandeja do sistema
- [Caixas de diálogo](/features/dialogs/file/) - Abrir/salvar arquivos, caixas de diálogo de mensagem
- [Eventos](/features/events/system/) - Comunicação entre componentes
- [Vinculações](/features/bindings/methods/) - Chamadas Go ↔ JavaScript com segurança de tipos
- [Área de transferência](/features/clipboard/basics/) - Operações de copiar e colar
- [Arrastar e soltar](/features/drag-and-drop/files/) - Arrastar e soltar arquivos
- [Teclado](/features/keyboard/shortcuts/) - Atalhos globais
