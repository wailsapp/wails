A focused desktop HTTP request replayer inspired by Burp Suite Repeater. Edit a raw HTTP request, send it exactly as written over a TCP/TLS socket, and keep per-tab history — without launching a proxy or a JVM. Imports curl/fetch snippets, routes each tab through an optional downstream proxy, and can draft requests and payloads with your own LLM endpoint. Built with Wails v2, Go, Vue 3 and CodeMirror 6; Apache-2.0.
