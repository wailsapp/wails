Larvyn is a desktop workbench for Laravel developers on Linux, macOS and Windows. It puts your Laravel apps, their dev services (artisan serve, Vite, queues, Reverb…), real terminals, database, Tinker, tests, logs and AI coding agents in one native window.

Launch Claude Code, Codex, OpenCode, Cursor Agent, Aider and more side by side, each in its own git worktree, then compare the diffs and merge the winner. Built with Wails 3, Go and React.
