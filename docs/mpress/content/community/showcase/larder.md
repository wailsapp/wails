[Larder](https://github.com/599yongyang/larder) is a local-first desktop app for developers who work with multiple AI agents. It scans the real files on disk — Skills, MCP servers, CLI tools, instruction files and custom commands — and explains what each Agent can actually see.

It helps find broken links, duplicate Skills and stale configuration. Every write goes through a plan and a snapshot, so changes can be rolled back. Larder also supports selectable data packages and optional encrypted WebDAV/S3 backup.

Built with:

- Go 1.26
- Wails v3 beta.34
- React 18
- SQLite
- Tailwind CSS
- MIT licensed
