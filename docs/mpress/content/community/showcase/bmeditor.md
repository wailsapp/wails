BMEditor, the Bare Minimum Editor (batteries included), is a desktop code editor for Windows and Linux that is ready to work the moment it opens. The debugger, a terminal, Docker, the Git changes in your project and live previews for Markdown, HTML and OpenAPI are part of the editor, so there is nothing to hunt down or set up first. Go works out of the box, and the editor is extensible: other languages and tools come in through extensions.

You can open a folder in WSL, on a server over SSH or inside a Docker container from the same window, with nothing to install on the other side. If you use Claude Code or GitHub Copilot CLI, it runs in the side panel, and the files it touches come back to you as a review you accept or reject change by change. The layout and shortcuts follow VS Code, so it should feel familiar from the first minute.

It is built with Wails 3, Go and Vue, and it is free to use.
