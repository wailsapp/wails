A Windows wallpaper application supporting custom wallpapers, multiple monitors, and random or sequential wallpaper changes.

Windows’ built-in slideshow cannot select images from multiple directories without first combining them. wpm lets you choose multiple directories or use different directories for different monitors. It can select a random image with an aspect ratio suited to each screen.
