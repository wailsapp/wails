[MyGit](https://github.com/ushaio/MyGit) is a worktree-centered desktop Git client built with Wails 3, Go and React. It groups several repositories under shared roots, opens each worktree as its own tab, and brings history, diff and blame, the full set of Git operations, multi-tab PTY terminals and AI-generated commit messages into one native window.

MyGit 是一款以 worktree 为核心的桌面 Git 客户端，使用 Wails 3、Go 与 React 构建。它把多个仓库按 root 组织在一起，每个 worktree 独立成一个标签页，并在同一个原生窗口中集成了提交历史、diff 与 blame、完整的 Git 操作、多标签 PTY 终端，以及由 AI 生成的提交信息。
