Lyyyra is a desktop songbook application built with Wails, Go and React. It downloads lyrics, metadata and sheet-music PDFs from evangelickyzpevnik.cz, then lets you search, filter and sort the collection offline.

Key features:

- Full-text search across titles, authors and lyrics
- Sorting by song number, title, music author and lyric author
- "Prepared sheets" panel for collecting songs and exporting one combined PDF
- Local database that keeps working offline after the first download
- Prebuilt binaries for Windows and Linux
