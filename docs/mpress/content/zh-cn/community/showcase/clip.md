![Clip 截图](/assets/showcase-images/clip.png)

- **三栏布局**：订阅源/文件夹树 · 文章列表 · 阅读视图
- **订阅管理**：添加订阅源、按文件夹整理、导入/导出 OPML
- **定时获取**：解析 RSS / Atom，并在后台自动刷新
- **专注阅读**：全文阅读视图 + 无干扰专注模式
- **快速搜索**：对标题、摘要和笔记进行全局全文搜索
- **笔记**：为文章添加笔记，方便日后回顾
- **桌面通知**：新文章提醒、macOS Dock / Windows 任务栏徽标
- **键盘操作**：提供完整的快捷键
- **主题与多语言**：浅色 / 深色 / 跟随系统，支持多种语言
- **性能与离线使用**：轻量级列表查询、本地缓存、离线阅读
