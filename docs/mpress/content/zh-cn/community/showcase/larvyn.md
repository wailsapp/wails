Larvyn 是一款面向 Laravel 开发者的桌面工作台，支持 Linux、macOS 和 Windows。它把你的 Laravel 应用、开发服务（artisan serve、Vite、队列、Reverb 等）、真正的终端、数据库、Tinker、测试、日志和 AI 编程代理集中在一个原生窗口中。

可同时启动 Claude Code、Codex、OpenCode、Cursor Agent、Aider 等代理，每个都在独立的 git worktree 中运行，然后比较差异并合并最佳结果。使用 Wails 3、Go 和 React 构建。

[官网](https://larvyn.dev) | [GitHub 发布版](https://github.com/larvyn/releases)
