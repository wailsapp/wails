Lyyyra 是一款使用 Wails、Go 和 React 构建的桌面歌本应用。它会从 evangelickyzpevnik.cz 下载歌词、元数据和乐谱 PDF，然后让你离线搜索、筛选和整理收藏。

主要功能：

- 对标题、作者和歌词进行全文搜索
- 按歌曲编号、标题、作曲作者和作词作者排序
- “已准备乐谱”面板，可收集歌曲并导出为一个合并的 PDF
- 首次下载后可离线使用的本地数据库
- 提供适用于 Windows 和 Linux 的预编译二进制文件

[在 GitHub 上查看](https://github.com/tomvladik/Lyyyra)
