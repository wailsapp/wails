一款 Windows 壁纸应用，支持自定义壁纸、多显示器，以及随机或顺序切换壁纸。

Windows 自带的幻灯片功能无法直接从多个文件夹选取图片，必须先合并图片。wpm 允许选择多个文件夹，或为不同显示器指定不同文件夹，并可根据各屏幕的横纵比例随机选择合适的壁纸。
