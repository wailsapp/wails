参考 Burp Suite Repeater 的桌面端 HTTP 请求重放工具。编辑原始 HTTP 报文，按原样通过 TCP/TLS socket 发送，并为每个标签保留历史——不需要启动代理，也不需要 JVM。支持导入 curl/fetch 片段、按标签配置下游代理，还可以用你自己的 LLM 接口生成请求和 payload。基于 Wails v2、Go、Vue 3 和 CodeMirror 6 构建；Apache-2.0。

[在 GitHub 上查看](https://github.com/chenshiyi007/HttpRepeater)
