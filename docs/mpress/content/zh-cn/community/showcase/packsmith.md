[Packsmith](https://github.com/sqot0/packsmith) 是一款用于管理 Minecraft 模组包的开源应用程序，可让你：

- 使用 Forge、Fabric、Neoforge 或 Quilt 模组加载器管理模组包。
- 从 Modrinth 和 CurseForge 搜索并下载模组。
- 将客户端模组与服务器模组分开管理。
- 更新模组、切换模组版本，或从模组包中删除模组。
