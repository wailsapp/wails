[EmailIt](https://github.com/raguay/EmailIt/) 是一个使用 Wails 2 构建的程序。它仅用于发送基于 Markdown 的电子邮件，配有九个记事本、用于处理文本的脚本和模板。它还提供脚本终端，可在 EmailIt 中对系统里的文件运行脚本。脚本和模板既可直接通过命令行使用，也可通过 Alfred、Keyboard Maestro、Dropzone 或 PopClip 扩展使用。它还支持从 GitHub 下载的脚本和主题。文档尚不完整，但程序可以正常运行。它使用 Wails2 和 Svelte 构建，下载文件是通用 macOS 应用程序。
