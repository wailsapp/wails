Condui 是一款支持端到端加密和多设备同步的 SSH 连接管理器。它可以在你使用的所有设备间同步连接、SSH 隧道和受保险库保护的凭据，而同步服务器永远无法看到你的明文凭据。

主要功能

- 🔐 端到端加密的保险库，用于保存 SSH 密码和私钥口令
- 🔄 在多台设备间同步连接、文件夹和 SSH 隧道
- 🌐 为每个连接持久保存本地端口转发隧道
- 🖥️ 集成终端、SFTP、Docker 和数据库工具
- 💻 支持 macOS、Windows 和 Linux
