[NetBird](https://netbird.io/) 将无需配置、基于 WireGuard 的点对点私有网络与集中式访问控制系统相结合，让你轻松为组织或家庭搭建安全的私有网络。

其桌面应用使用 Wails 从零重新构建，提供包含基本功能的紧凑默认视图，以及可展开的高级模式，用于浏览对等节点和资源。独立的设置窗口让你能够管理多个配置文件并配置客户端，所有功能均可在 macOS、Windows 和 Linux 上原生运行。

有关图形界面的更多信息，请阅读[博客文章](https://netbird.io/knowledge-hub/new-desktop-app-release-candidate)，或在 GitHub 上查看[源代码](https://github.com/netbirdio/netbird/tree/main/client/ui)。
