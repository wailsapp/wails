Wails 由维护者和贡献者社区共同构建。无论目前是否仍参与该项目，所有为其建设提供过帮助的人都值得肯定。

**维护者**

- [Lea Anthony](https://github.com/leaanthony) — 项目所有者兼首席开发者
- [Atterpac](https://github.com/atterpac) — 维护者；负责开发工具、桌面集成和社区支持

如需帮助，请使用[社区支持渠道](/community/links/#support-channels)。以下致谢旨在表彰项目发展历程中的各项贡献。

**感谢你们构建 Wails v3**

特别感谢[Fabio Massaioli (fbbdev)](https://github.com/fbbdev)创建静态源代码分析器和绑定生成器，为v3生成 JavaScript 和 TypeScript 绑定提供支持，并参与运行时和服务 API 的开发。

同时感谢：

- [Travis McLane](https://github.com/tmclane) — 早期在 Linux 和原生平台方面开展了大量工作，并参与交叉编译和 macOS 测试
- [Stffabi](https://github.com/stffabi) — 为资源服务器以及 Windows 和 macOS 原生支持奠定基础
- [Zach Botterman (popaprozac)](https://github.com/popaprozac) — 通知、Dock 集成、模态窗口和桌面服务
- [Ian VanSchooten (IanVS)](https://github.com/IanVS) — 类型化事件、运行时和菜单改进
- [Lyimmi](https://github.com/Lyimmi) — Linux 相关贡献
- [mortenolsrud](https://github.com/mortenolsrud) — Android 和 iOS 修复、打包及移动端集成
- [Andraz Vrhovec](https://github.com/overlordtm) — Linux 应用标识和单实例行为
- [Julian Storer](https://github.com/julianstorer) — macOS 焦点、键盘快捷键和桌面行为
- [Simon Thomas](mailto:enquiries@wails.io) — 项目发展和社区工作

以上仅列举了部分贡献，并非完整清单。感谢每一位贡献代码、审查变更、测试版本、翻译文档或帮助其他用户的人。

- [Tad Vizbaras](https://github.com/tadvi) - 他的 winc 项目是 Wails 迈向纯 Go 实现的第一步。

- [Byron Chris](https://github.com/bh90210) - 感谢他长期以来对本项目的贡献。
- [Dustin Krysak](https://wiki.ubuntu.com/bashfulrobot) - 他的支持和反馈弥足珍贵。
- [Justen Walker](https://github.com/justenwalker/) - 感谢他协助处理棘手的 COM 问题，使v2得以顺利完成。
