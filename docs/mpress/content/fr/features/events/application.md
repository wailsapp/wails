---

Les événements de l’application sont émis lors de changements du cycle de vie qui concernent l’ensemble de l’application, tels que son démarrage, son arrêt et les opérations de gestion des fenêtres.

La documentation complète sur les événements de l’application est disponible dans le guide [Système d’événements](/features/events/system/#application-events).
