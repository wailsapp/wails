![Capture d'écran de HttpRepeater](/assets/showcase-images/httprepeater.png)

Un replayer de requêtes HTTP de bureau inspiré de Burp Suite Repeater. Modifiez une requête HTTP brute, envoyez-la exactement telle quelle via un socket TCP/TLS et conservez un historique par onglet — sans proxy ni JVM. Importe les extraits curl/fetch, achemine chaque onglet via un proxy aval optionnel et peut rédiger requêtes et payloads avec votre propre endpoint LLM. Construit avec Wails v2, Go, Vue 3 et CodeMirror 6 ; Apache-2.0.

[Voir sur GitHub](https://github.com/chenshiyi007/HttpRepeater)
