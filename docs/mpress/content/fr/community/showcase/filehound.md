[Utilitaire d’exportation FileHound](https://www.filehound.co.uk/) FileHound est une plateforme cloud de gestion documentaire conçue pour la conservation sécurisée des fichiers, l’automatisation des processus métier et les fonctionnalités SmartCapture.

L’utilitaire d’exportation FileHound permet aux administrateurs FileHound d’exécuter des tâches sécurisées d’extraction de documents et de données à des fins de sauvegarde et de restauration alternatives. Cette application téléchargera tous les documents et/ou toutes les métadonnées enregistrés dans FileHound selon les filtres que vous choisissez. Les métadonnées seront exportées aux formats JSON et XML.

Backend conçu avec :

- Go 1.15
- Wails 1.11.0
- go-sqlite3 1.14.6
- go-linq 3.2

Frontend conçu avec :

- Vue 2.6.11
- Vuex 3.4.0
- TypeScript
- Tailwind 1.9.6
