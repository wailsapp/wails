Fonctionnalités principales

- 🎨 Conception simple et intuitive pour une expérience sans tracas
- ✅ Ajoutez facilement des comptes par saisie manuelle ou en important l’image d’un code QR.
- 🔒 Chiffrement de bout en bout avec un code PIN ou Touch ID (macOS uniquement).
- 💻 Disponible pour macOS, Windows et Linux
- ⚡ Accès rapide depuis la zone de notification pour plus de commodité
- 📂 Sauvegardez et restaurez facilement vos profils
