MyGit est un client Git de bureau centré sur les worktrees, construit avec Wails 3, Go et React. Il regroupe plusieurs dépôts sous des racines communes, ouvre chaque worktree dans son propre onglet et réunit dans une même fenêtre native l’historique, le diff et le blame, l’ensemble des opérations Git, des terminaux PTY à onglets multiples et des messages de commit générés par IA.
