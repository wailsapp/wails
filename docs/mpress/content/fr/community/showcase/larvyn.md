Larvyn est un atelier de bureau pour les développeurs Laravel sous Linux, macOS et Windows. Il réunit vos applications Laravel, leurs services de développement (artisan serve, Vite, files d’attente, Reverb…), de vrais terminaux, la base de données, Tinker, les tests, les logs et des agents de code IA dans une seule fenêtre native.

Lancez Claude Code, Codex, OpenCode, Cursor Agent, Aider et d’autres côte à côte, chacun dans son propre worktree git, puis comparez les diffs et fusionnez le meilleur. Construit avec Wails 3, Go et React.
