Lyyyra est une application de bureau de recueil de chants construite avec Wails, Go et React. Elle télécharge les paroles, les métadonnées et les partitions PDF depuis evangelickyzpevnik.cz, puis vous permet de rechercher, filtrer et trier la collection hors ligne.

Fonctionnalités principales :

- Recherche plein texte dans les titres, les auteurs et les paroles
- Tri par numéro de chant, titre, auteur de la musique et auteur des paroles
- Panneau « Feuilles préparées » pour rassembler des chants et exporter un PDF combiné
- Base de données locale qui reste utilisable hors ligne après le premier téléchargement
- Binaires précompilés pour Windows et Linux

[Voir sur GitHub](https://github.com/tomvladik/Lyyyra)
