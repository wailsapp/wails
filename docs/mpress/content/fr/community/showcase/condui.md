Condui est un gestionnaire de connexions SSH avec synchronisation chiffrée de bout en bout sur plusieurs appareils. Il synchronise vos connexions, vos tunnels SSH et vos identifiants protégés dans un coffre-fort sur tous les appareils que vous utilisez, sans que le serveur de synchronisation puisse jamais voir vos identifiants en clair.

Fonctionnalités principales

- 🔐 Coffre-fort chiffré de bout en bout pour les mots de passe SSH et les phrases secrètes des clés privées
- 🔄 Synchronisation des connexions, des dossiers et des tunnels SSH sur plusieurs appareils
- 🌐 Tunnels de redirection de ports locaux conservés pour chaque connexion
- 🖥️ Outils intégrés pour le terminal, SFTP, Docker et les bases de données
- 💻 Disponible pour macOS, Windows et Linux
