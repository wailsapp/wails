BMEditor, le Bare Minimum Editor (batteries included), est un éditeur de code de bureau pour Windows et Linux, prêt à travailler dès son ouverture. Le débogueur, un terminal, Docker, les modifications Git du projet et des aperçus en direct pour Markdown, HTML et OpenAPI font partie de l’éditeur : rien à chercher ni à configurer avant de commencer. Go fonctionne tout de suite, et l’éditeur est extensible : les autres langages et outils arrivent par des extensions.

Depuis la même fenêtre, vous ouvrez un dossier dans WSL, sur un serveur en SSH ou dans un conteneur Docker, sans rien installer de l’autre côté. Si vous utilisez Claude Code ou GitHub Copilot CLI, il tourne dans le panneau latéral, et les fichiers qu’il modifie vous reviennent sous forme de relecture, que vous acceptez ou refusez modification par modification. La disposition et les raccourcis suivent VS Code, on s’y retrouve donc dès la première minute.

Il est construit avec Wails 3, Go et Vue, et il est gratuit.
