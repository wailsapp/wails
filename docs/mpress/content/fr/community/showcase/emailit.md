[EmailIt](https://github.com/raguay/EmailIt/) est un programme Wails 2 destiné uniquement à l’envoi d’e-mails rédigés en Markdown, doté de neuf blocs-notes, de scripts permettant de manipuler le texte et de modèles. Il comprend également un terminal de scripts permettant d’exécuter, depuis EmailIt, des scripts sur les fichiers de votre système. Les scripts et les modèles peuvent être utilisés directement depuis la ligne de commande ou avec les extensions Alfred, Keyboard Maestro, Dropzone ou PopClip. Il prend également en charge les scripts et les thèmes téléchargés depuis GitHub. La documentation n’est pas complète, mais le programme fonctionne. Il est créé avec Wails2 et Svelte, et le téléchargement fournit une application macOS universelle.
