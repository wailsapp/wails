[ScriptBar](https://GitHub.com/raguay/ScriptBarApp) est un programme qui affiche la sortie de scripts ou d’un serveur [Node-Red](https://nodered.org). Il exécute les scripts définis dans le programme EmailIt et affiche leur sortie. Vous pouvez utiliser des scripts provenant de xBar ou de TextBar, mais actuellement, seuls les scripts TextBar fonctionnent correctement. Il affiche également la sortie des scripts présents sur votre système. ScriptBar ne les place pas dans la barre des menus, mais les regroupe dans une fenêtre pratique pour faciliter leur consultation. Vous pouvez ouvrir plusieurs onglets afin d’afficher de nombreux éléments différents. Vous pouvez également conserver les liens vers les sites web que vous consultez le plus souvent.
