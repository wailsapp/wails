[Ytd](https://github.com/marcio199226/ytd/tree/v2-wails) est une application qui permet de télécharger des morceaux depuis YouTube, de créer des playlists hors ligne et de les partager avec vos amis. Ceux-ci pourront lire vos playlists ou les télécharger pour les écouter hors ligne. Elle intègre également un lecteur.
