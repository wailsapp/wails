Les applications Wails v3 étant des applications Go, vous pouvez utiliser n’importe quel pilote de base de données Go standard — notamment [SQLite](https://github.com/mattn/go-sqlite3), [PostgreSQL](https://github.com/jackc/pgx) et [MySQL](https://github.com/go-sql-driver/mysql) — dans vos services liés.

Pour consulter un exemple fonctionnel, reportez-vous au [tutoriel TODO](/tutorials/02-todo-vanilla/), qui montre comment ajouter la persistance avec SQLite à une application complète.
