Wails is built by its maintainers and a community of contributors. The people who helped build it deserve credit whether or not they are currently involved in the project.

**Maintainers**

- [Lea Anthony](https://github.com/leaanthony) — Project owner and lead developer
- [Atterpac](https://github.com/atterpac) — Maintainer; development tooling, desktop integration and community support

For help, use the [community support channels](/community/links/#support-channels). The acknowledgements below recognise contributions over the project's history.

**Thanks for building Wails v3**

Special thanks to [Fabio Massaioli (fbbdev)](https://github.com/fbbdev) for creating the static source analyser and binding generator that power v3's generated JavaScript and TypeScript bindings, and for his work on the runtime and service APIs.

Thank you also to:

- [Travis McLane](https://github.com/tmclane) — Extensive early Linux and native platform work, cross-compilation and macOS testing
- [Stffabi](https://github.com/stffabi) — Asset server and native Windows and macOS foundations
- [Zach Botterman (popaprozac)](https://github.com/popaprozac) — Notifications, Dock integration, modal windows and desktop services
- [Ian VanSchooten (IanVS)](https://github.com/IanVS) — Typed events, runtime and menu improvements
- [Lyimmi](https://github.com/Lyimmi) — Linux contributions
- [mortenolsrud](https://github.com/mortenolsrud) — Android and iOS fixes, packaging and mobile integration
- [Andraz Vrhovec](https://github.com/overlordtm) — Linux application identity and single-instance behaviour
- [Julian Storer](https://github.com/julianstorer) — macOS focus, keyboard accelerators and desktop behaviour
- [Simon Thomas](mailto:enquiries@wails.io) — Growth and community work

This is a selection of contributions, not an exhaustive list. Thank you to everyone who has contributed code, reviewed changes, tested releases, translated documentation or helped other users.
