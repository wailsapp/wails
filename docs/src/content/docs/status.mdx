## Current status: beta

Wails v3 is in beta. The API is stable, applications are running in production
with it, and the work now is the final polish before the 3.0 release.

Wails v2 remains the current stable release and continues to receive fixes.

## What beta means for your project

Beta is a commitment, so it is worth being precise about what is being promised
and what is not.

**What is settled**

- The public API is stable. Changes from here to 3.0 are additive or fixes.
  If something does have to change, it will be deprecated first, with the
  removal version named in the deprecation.
- Beta releases receive security fixes. See the
  [security policy](https://github.com/wailsapp/wails/blob/master/SECURITY.md)
  for the supported-version table. Alpha releases no longer receive them, so if
  you are on an alpha, upgrading is the fix.
- The documentation on this site describes the beta. Where a page still
  describes older behaviour, that is a documentation bug worth reporting.

**What is still moving**

- Pin an exact version rather than tracking the latest release. Prereleases move
  faster than your release schedule does.
- Platform coverage is not uniform. Desktop support on macOS, Windows and Linux
  is the mature part. Mobile targets are newer, and some pieces ship as examples
  rather than as project templates.
- Some rough edges are known and tracked rather than hidden. The lists below are
  generated from the issue tracker rather than hand-maintained here, so they do
  not go stale.

## How you can contribute

- Run the beta on a real project and report what breaks. Reports from real
  applications are worth more than any amount of internal testing.
- Improve the documentation and examples. If a page confused you, it will
  confuse the next person.
- Take part in discussions and give feedback on proposed features before they
  are built.
- Send pull requests for fixes. See
  [CONTRIBUTING.md](https://github.com/wailsapp/wails/blob/master/CONTRIBUTING.md)
  for how contributions are accepted.

## Feedback

This page changes as the project does. If something here is out of date, or a
commitment above does not match what you experienced, please open an issue: a
status page that quietly drifts from reality is worse than no status page.
