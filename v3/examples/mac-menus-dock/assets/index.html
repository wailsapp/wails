macOS menus and Dock demo

Everything in this demo lives in the native menu bar and the Dock:

  • Demo menu: SF Symbol images, badges, a section header, mixed state, indentation, an alternate item (hold Option).
  • Demo > Tag colour: a macOS 14 palette menu.
  • File > Open Recent: recent documents from NSDocumentController.
  • Dock icon: right-click for the dock menu; the Dock menu items drive the badge and progress bar.
