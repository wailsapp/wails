    Aplikasi Pertama Anda

    Panduan ini menunjukkan cara membuat aplikasi Wails v3 pertama Anda, mencakup setup proyek, build, dan alur kerja pengembangan.



    1

    Membuat Proyek Baru

    Buka terminal Anda dan jalankan perintah berikut untuk membuat proyek Wails baru:

    bash
    wails3 init -n myfirstapp

    Perintah ini membuat direktori baru bernama myfirstapp dengan semua file yang diperlukan.

    2

    Menjelajahi Struktur Proyek

    Masuk ke direktori myfirstapp. Anda akan menemukan beberapa file dan folder:

    • buildBerisi file yang digunakan proses build
      • appicon.pngIkon aplikasi
      • config.ymlKonfigurasi build
      • Taskfile.yml Tugas build
      • darwinFile build khusus macOS
        • Info.dev.plist Konfigurasi development
        • Info.plistKonfigurasi production
        • Taskfile.ymlTugas build macOS
        • icons.icnsIkon aplikasi macOS
      • linuxFile build khusus Linux
        • Taskfile.ymlTugas build Linux
        • appimagePackaging AppImage
          • build.shSkrip build AppImage
        • nfpmPackaging NFPM
          • nfpm.yaml Konfigurasi paket
          • scriptsSkrip build
      • windowsFile build khusus Windows
        • Taskfile.ymlTugas build Windows
        • icon.icoIkon aplikasi Windows
        • info.jsonMetadata aplikasi
        • wails.exe.manifest File manifest Windows
        • nsisFile installer NSIS
          • project.nsiFile proyek NSIS
          • wails_tools.nshSkrip helper NSIS
    • frontendFile aplikasi frontend
      • index.htmlFile HTML utama
      • main.jsFile JavaScript utama
      • package.json Konfigurasi paket NPM
      • publicAset statis
      • Inter Font License.txt Lisensi font
    • .gitignoreFile git ignore
    • README.mdDokumentasi proyek
    • Taskfile.ymlTugas proyek
    • go.modFile modul Go
    • go.sumChecksum modul Go
    • greetservice.go Layanan greeting
    • main.goKode aplikasi utama

    Luangkan waktu untuk menjelajahi file-file ini dan familiar dengan strukturnya.

    Info

    Meskipun Wails v3 menggunakan Task sebagai sistem build default, tidak ada yang mencegah Anda menggunakan make atau sistem build alternatif lainnya.

    3

    Mem-build Aplikasi Anda

    Untuk mem-build aplikasi Anda, jalankan:

    bash
    wails3 build

    Perintah ini mengompilasi versi debug aplikasi Anda dan menyimpannya di direktori bin yang baru.

    Info

    wails3 build adalah shorthand untuk wails3 task build dan akan menjalankan tugas build di Taskfile.yml.

    <video src="/assets/wails_build.mp4" controls></video>

    Setelah di-build, Anda dapat menjalankannya seperti aplikasi biasa:

    sh
    ./bin/myfirstapp
    sh
    bin\myfirstapp.exe
    sh
    ./bin/myfirstapp

    Anda akan melihat UI sederhana, titik awal untuk aplikasi Anda. Karena ini versi debug, Anda juga akan melihat log di jendela konsol. Ini berguna untuk keperluan debugging.

    4

    Mode Dev

    Kita juga dapat menjalankan aplikasi dalam mode development. Mode ini memungkinkan Anda membuat perubahan pada kode frontend dan melihat perubahan tersebut tercermin di aplikasi yang berjalan tanpa harus mem-build ulang seluruh aplikasi.

    1. Buka jendela terminal baru.
    2. Jalankan wails3 dev. Aplikasi akan dikompilasi dan dijalankan dalam mode debug.
    3. Buka frontend/index.html di editor pilihan Anda.
    4. Edit kode dan ubah Please enter your name below menjadi Please enter your name below!!!.
    5. Simpan file.

    Perubahan ini akan langsung tercermin di aplikasi Anda.

    Setiap perubahan pada kode backend akan memicu rebuild:

    1. Buka greetservice.go.
    2. Ubah baris yang berisi return "Hello " + name + "!" menjadi return "Hello there " + name + "!".
    3. Simpan file.

    Aplikasi akan diperbarui dalam hitungan detik.

    <video src="/assets/wails_dev.mp4" controls></video>
    5

    Mengemas Aplikasi Anda

    Setelah aplikasi Anda siap untuk didistribusikan, Anda dapat membuat paket spesifik platform:

    Untuk membuat bundle .app:

    bash
    wails3 package

    Ini akan membuat build production dan mengemasnya ke bundle .app di direktori bin.

    Untuk membuat installer NSIS:

    bash
    wails3 package

    Ini akan membuat build production dan mengemasnya ke installer NSIS di direktori bin.

    Wails mendukung berbagai format paket untuk distribusi Linux:

    bash
    # Buat semua jenis paket (AppImage, deb, rpm, dan Arch Linux)
wails3 package

# Atau buat jenis paket spesifik
wails3 task linux:create:appimage  # Format AppImage
wails3 task linux:create:deb       # Paket Debian
wails3 task linux:create:rpm       # Paket Red Hat
wails3 task linux:create:aur       # Paket Arch Linux

    Untuk informasi lebih detail tentang opsi dan konfigurasi packaging,
lihat [Panduan Packaging](/guides/installers/).
    6

    Menyiapkan Version Control dan Nama Modul

    Proyek Anda dibuat dengan nama modul placeholder changeme. Disarankan untuk memperbaruinya agar sesuai dengan URL repositori Anda:

    1. Buat repositori baru di GitHub (atau Git host pilihan Anda)
    2. Inisialisasi git di direktori proyek Anda:
    bash
    git init
git add .
git commit -m "Initial commit"
    1. Atur remote repository Anda (ganti dengan URL repositori Anda):
    bash
    git remote add origin https://github.com/username/myfirstapp.git
    1. Perbarui nama modul di go.mod agar sesuai dengan URL repositori Anda:
    bash
    go mod edit -module github.com/username/myfirstapp
    1. Push kode Anda:
    bash
    git push -u origin main

    Ini memastikan nama modul Go Anda selaras dengan konvensi penamaan modul Go dan memudahkan berbagi kode.

    Pro Tip

    Anda dapat mengotomatisasi semua langkah inisialisasi dengan menggunakan flag -git saat membuat proyek:

    bash
    wails3 init -n myfirstapp -git github.com/username/myfirstapp

    Ini mendukung berbagai format URL Git:

    • HTTPS: https://github.com/username/project
    • SSH: git@github.com:username/project atau ssh://git@github.com/username/project
    • Git protocol: git://github.com/username/project
    • Filesystem: file:///path/to/project.git
