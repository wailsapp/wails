    次のステップ

    最初の Wails アプリを構築し、基本を理解しましたね。次に進むべき場所をご紹介します。

    さらに学ぶ

    完全なアプリケーションを構築して実践しましょう：

    • TODO アプリ - CRUD 操作、状態管理、モダン UI
    • すべてのチュートリアル - ノートアプリ、ダッシュボード、システムトレイアプリなど

    機能

    Wails はネイティブなデスクトップ機能を提供します：

    • Windows - 複数ウィンドウ、フレームレスウィンドウ、配置
    • メニュー - アプリケーションメニュー、コンテキストメニュー、システムトレイ
    • ダイアログ - ファイルの開く/保存、メッセージダイアログ
    • イベント - コンポーネント間の通信
    • バインディング - 型安全な Go ↔ JavaScript 呼び出し
    • クリップボード - コピー/ペースト操作
    • ドラッグ & ドロップ - ファイルのドラッグ & ドロップ
    • キーボード - グローバルショートカット

    サポート

    • Discord - 質問の投稿、プロジェクトの共有
    • 例 - 動作する例が 50 以上
    • API リファレンス - 完全なドキュメント
