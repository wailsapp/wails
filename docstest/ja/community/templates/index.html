    テンプレート

    注意

    このページはWails v3では古くなっている可能性があります。

    このページはコミュニティがサポートするテンプレートのリストです。独自のテンプレートを作成するには、テンプレート ガイドを参照してください。

    テンプレートの提出方法

    下部の Edit this page をクリックして、あなたのテンプレートを含めることができます。

    これらのテンプレートを使用するには、 wails init -n "Your Project Name" -t [以下のリンク[@version]] を実行します。

    バージョン接尾辞がない場合、デフォルトでmainブランチのコードテンプレートが使用されます。 バージョン接尾辞がある場合、そのバージョンのタグに対応するコードテンプレートが使用されます。

    例: wails init -n "Your Project Name" -t https://github.com/misitebao/wails-template-vue

    注意

    Wailsプロジェクトは、サードパーティのテンプレートを維持せず、それらに対して責任を負いません！

    テンプレートについて確信が持てない場合は、package.json と wails.json を確認して、 どのスクリプトが実行され、どのパッケージがインストールされているかを確認してください。

    Vue

    • wails-template-vue - Vueエコシステムに基づくWails テンプレート (TypeScript統合、ダークテーマ、 国際化、シングルページルーティング、TailwindCSS)
    • wails-template-quasar-js - JavaScript + Quasar V2を使用するテンプレート (Vue 3, Vite, Sass, Pinia, ESLint, Prettier)
    • wails-template-quasar-ts - TypeScript + Quasar V2を使用するテンプレート (Vue 3, Vite, Sass, Pinia, ESLint, Prettier, <script setup>付きのComposition API)
    • wails-template-naive - Naive UI (Vue 3のコンポーネントライブラリ)に基づくWailsテンプレート
    • wails-template-nuxt - Wails テンプレートはクリーンなNuxt3とTypeScriptを使用し、wails js ランタイムの自動インポートに対応
    • Wails-Tool-Template - Wails テンプレートはVue+TypeScript+Vite+Element-plus(NetEase Cloud Music風)を使用

    Angular

    • wails-template-angular - Angular 15+ で機能満載、本番環境への展開準備完了。
    • wails-angular-template - TypeScript、Sass、ホットリロード、コード分割、i18nを備えたAngular

    React

    • wails-react-template - reactjsを使用するテンプレート
    • wails-react-template - リモート開発に対応した React用のミニマルなテンプレート
    • wails-template-nextjs - Next.jsとTypeScriptを使用する テンプレート
    • wails-template-nextjs-app-router - App routerを備えたNext.jsとTypeScriptを使用するテンプレート
    • wails-template-nextjs-app-router-src - App router srcと例を備えたNext.jsとTypeScriptを使用するテンプレート
    • wails-vite-react-ts-tailwind-template - React + TypeScript + Vite + TailwindCSS用のテンプレート
    • wails-vite-react-ts-tailwind-shadcnui-template - Vite、React、TypeScript、TailwindCSS、shadcn/uiを備えたテンプレート

    Svelte

    • wails-svelte-template - Svelteを使用するテンプレート
    • wails-vite-svelte-template - SvelteとViteを使用するテンプレート
    • wails-vite-svelte-tailwind-template - TailwindCSS v3を備えたSvelteとViteを使用するテンプレート
    • wails-svelte-tailwind-vite-template - Svelte v4.2.0とVite、TailwindCSS v3.3.3を使用する更新されたテンプレート
    • wails-sveltekit-template - SvelteKitを使用するテンプレート
    • wails-template-shadcn-svelte - SveltekitとShadcn-Svelteを使用するテンプレート

    Solid

    • wails-template-vite-solid-ts - Solid + Ts + Viteを使用するテンプレート
    • wails-template-vite-solid-js - Solid + Js + Viteを使用するテンプレート

    Elm

    • wails-elm-template - 関数型プログラミングと高速なホットリロードセットアップでGUIアプリを開発しましょう :tada: :rocket:
    • wails-template-elm-tailwind - Elm + Tailwind CSS + Wailsの力を組み合わせましょう :muscle:! ホットリロードに対応。

    HTMX

    • wails-htmx-templ-chi-tailwind - インタラクティブ性のために純粋なhtmxを使用し、コンポーネントとフォームの作成にはtemplを使用する 独自の組み合わせ

    純粋なJavaScript (Vanilla)

    • wails-pure-js-template - 基本的なJavaScript、HTML、CSS のみを使用したテンプレート

    Lit (web components)

    • wails-lit-shoelace-esbuild-template - フロントエンドにlit、Shoelaceコンポーネントライブラリ、 事前に設定されたprettierとtypescriptを提供するWailsテンプレート。
