    Установка

    Быстрая установка (5 минут)

    TL;DR - для опытных разработчиков

    bash
    # Установите Go 1.25+, затем:
go install github.com/wailsapp/wails/v3/cmd/wails3@latest
wails3 doctor  # Проверка установки

    Если команда wails3 doctor прошла успешно, установка завершена. Перейти к созданию первого приложения →

    Пошаговая установка

    1

    Установка Go (обязательно)

    Для работы Wails требуется Go версии 1.25 или новее.

    Скачайте установщик для Windows с go.dev/dl и запустите его.

    Проверка установки:

    PowerShell
    go version  # Должна отобразиться версия 1.25 или новее

    Проверка PATH:

    PowerShell
    $env:PATH -split ';' | Where-Object { $_ -like '*\go\bin' }

    Если вывод пустой, добавьте C:\Users\YourName\go\bin в переменную PATH.

    Вариант 1: Официальный установщик

    Скачайте установщик для macOS (файл .pkg) с go.dev/dl и запустите его.

    Вариант 2: Homebrew

    bash
    brew install go

    Проверка установки:

    bash
    go version  # Должна отобразиться версия 1.25 или новее
echo $PATH | grep go/bin  # Должен отобразиться ~/go/bin

    Если ~/go/bin отсутствует в PATH, добавьте его в ~/.zshrc или ~/.bash_profile:

    bash
    export PATH=$PATH:~/go/bin

    Вариант 1: Официальный архив (Tarball)

    Скачайте архив для Linux с go.dev/dl, затем выполните:

    bash
    sudo rm -rf /usr/local/go
sudo tar -C /usr/local -xzf go1.25.linux-amd64.tar.gz

    Вариант 2: Менеджер пакетов

    bash
    # Ubuntu/Debian
sudo apt install golang-go

# Fedora
sudo dnf install golang

# Arch
sudo pacman -S go

    Добавление в PATH (добавьте в ~/.bashrc или ~/.zshrc):

    bash
    export PATH=$PATH:/usr/local/go/bin:~/go/bin
source ~/.bashrc  # Перезагрузка конфигурации

    Проверка:

    bash
    go version
echo $PATH | grep go/bin
    2

    Установка зависимостей платформы

    WebView2 Runtime (обычно уже установлен)

    Windows 10/11 включает WebView2 по умолчанию. Если он отсутствует:
- Скачайте его с [Microsoft](https://developer.microsoft.com/microsoft-edge/webview2/)
- Или выполните `wails3 doctor` позже — он подскажет, что делать

**На этом всё!** Другие зависимости не требуются.

    Совет по производительности для Windows 11

    Рекомендуется использовать Dev Drive для хранения проектов. Диски Dev Drive оптимизированы для задач разработки и могут значительно ускорить время сборки и доступ к диску (до 30%).

    Инструменты командной строки Xcode (обязательно)

    bash
    xcode-select --install

    Нажмите “Install” в появившемся диалоговом окне.

    Проверка:

    bash
    xcode-select -p  # Должен отобразиться /Library/Developer/CommandLineTools

    На этом всё! macOS включает WebKit по умолчанию.

    Инструменты сборки и WebKit

    Минимальные версии дистрибутивов

    Wails v3 требует WebKitGTK 4.1 (использует libsoup3). Более старые релизы, которые поставляются только с версией 4.0 — Ubuntu 20.04, Debian 11, RHEL 8/9 и их производные — не поддерживаются.

    Требуется Ubuntu 22.04+ или Debian 12+.

    bash
    sudo apt update
sudo apt install build-essential pkg-config libgtk-3-dev libwebkit2gtk-4.1-dev
    bash
    sudo dnf install gcc pkg-config gtk3-devel webkit2gtk4.1-devel
    bash
    sudo pacman -S base-devel gtk3 webkit2gtk-4.1
    bash
    sudo zypper install gcc pkg-config gtk3-devel webkit2gtk3-devel
    bash
    sudo emerge --ask net-libs/webkit-gtk:4.1

    Добавьте в ваш shell.nix или devShell:

    buildInputs = with pkgs; [ webkitgtk_4_1 gtk3 pkg-config gcc ];

    Выполните wails3 doctor после установки Wails — он покажет точные пакеты, необходимые для вашего дистрибутива.

    Дополнительно: поддержка GTK4

    Wails также имеет экспериментальную поддержку GTK4 / WebKitGTK 6.0. Если вы хотите собирать приложения с GTK4, установите дополнительные зависимости для вашего дистрибутива и выполните сборку с помощью wails3 build -tags gtk4. Подробности см. в разделе Упаковка для Linux - GTK4.

    Если команда `wails3` не найдена

    Ваша директория ~/go/bin не добавлена в PATH. См. шаг 1 выше, чтобы исправить это, затем перезапустите терминал.

    5

    Установка npm (необязательно, но рекомендуется)

    Большинство шаблонов Wails используют npm для фронтенд-инструментов.

    Скачайте с nodejs.org и запустите установщик.

    Проверка:

    PowerShell
    npm --version

    Вариант 1: Официальный установщик Скачайте с nodejs.org

    Вариант 2: Homebrew

    bash
    brew install node

    Проверка:

    bash
    npm --version

    Вариант 1: NodeSource

    bash
    curl -fsSL https://deb.nodesource.com/setup_lts.x | sudo -E bash -
sudo apt-get install -y nodejs  # Ubuntu/Debian

    Вариант 2: Менеджер пакетов

    bash
    sudo dnf install nodejs  # Fedora
sudo pacman -S nodejs npm  # Arch

    Проверка:

    bash
    npm --version

    Альтернативные менеджеры пакетов

    Предпочитаете pnpm, yarn или bun? Без проблем! Просто обновите Taskfile.yml в вашем проекте для использования предпочтительного инструмента.

    Устранение неполадок

    Команда wails3 не найдена

    Причина: ~/go/bin (или %USERPROFILE%\go\bin на Windows) не добавлен в PATH.

    Решение:

    1. Откройте «Переменные среды» (поиск в меню Пуск)
    2. В разделе «Переменные пользователя» найдите Path
    3. Нажмите «Изменить» → «Создать»
    4. Добавьте: C:\Users\ВашеИмя\go\bin (замените ВашеИмя)
    5. Нажмите «ОК» во всех диалогах
    6. Перезапустите терминал

    Проверка:

    PowerShell
    $env:PATH -split ';' | Where-Object { $_ -like '*\go\bin' }

    Добавьте в ~/.zshrc (macOS) или ~/.bashrc (Linux):

    bash
    export PATH=$PATH:~/go/bin

    Перезагрузите:

    bash
    source ~/.zshrc  # или ~/.bashrc

    Проверка:

    bash
    echo $PATH | grep go/bin
wails3 version
    ---

    wails3 doctor сообщает об отсутствующих зависимостях

    Linux: Вывод показывает точно, какие пакеты нужно установить. Пример:

    ❌ webkit2gtk не найден
   Установите: sudo apt install libwebkit2gtk-4.1-dev

    Windows: Если WebView2 отсутствует:

    • Скачайте с Microsoft
    • Или будет установлен автоматически при первом запуске приложения

    macOS: Если инструменты Xcode отсутствуют:

    bash
    xcode-select --install

    Версия Go слишком старая

    Wails v3 требует Go 1.25+. Если у вас более старая версия:

    Загрузите последнюю версию с go.dev/dl и переустановите.

    Загрузите последний архив tarball с go.dev/dl, затем:

    bash
    sudo rm -rf /usr/local/go
sudo tar -C /usr/local -xzf go1.25.linux-amd64.tar.gz

    Версия для разработчиков (Bleeding Edge)

    Хотите использовать абсолютно последний код из основной ветки разработки? Это даст вам доступ к новым функциям и исправлениям до их официального выпуска, но сопряжено с риском наличия ошибок и ломающих изменений. Рекомендуется только для участников разработки или тех, кому необходимо тестировать предстоящие функции.

    bash
    git clone https://github.com/wailsapp/wails.git
cd wails
git checkout v3
cd v3/cmd/wails3
go install

    Версия для разработчиков

    • Может содержать ошибки или ломающие изменения
    • Проекты, созданные с её помощью, будут использовать директиву replace для указания на локальный Wails
    • Рекомендуется только для участников разработки или тестирования новых функций
