    Vous avez créé votre première application Wails et vous en comprenez les bases. Voici les prochaines étapes.

    En savoir plus

    Pratiquez en créant des applications complètes :

    • Application TODO - Opérations CRUD, gestion d’état, interface utilisateur moderne
    • Tous les tutoriels - Applications de notes, tableaux de bord, applications de barre d’état système, et plus encore

    Fonctionnalités

    Wails offre des capacités de bureau natif :

    • Windows - Fenêtres multiples, fenêtres sans bordure, positionnement
    • Menus - Menus d’application, menus contextuels, barre d’état système
    • Boîtes de dialogue - Ouverture/sauvegarde de fichiers, boîtes de dialogue de message
    • Événements - Communication entre composants
    • Liaisons - Appels Go ↔ JavaScript typés
    • Presse-papiers - Opérations de copie/coller
    • Glisser-déposer - Glisser-déposer de fichiers
    • Clavier - Raccourcis globaux
