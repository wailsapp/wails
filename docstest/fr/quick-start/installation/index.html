    Installation

    Installez Wails et préparez-vous à créer des applications

    Installation rapide (5 minutes)

    TL;DR - Développeurs expérimentés

    bash
    # Installez Go 1.25+, puis :
go install github.com/wailsapp/wails/v3/cmd/wails3@latest
wails3 doctor  # Vérifiez l'installation

    Si wails3 doctor réussit, vous avez terminé. Passer à la première application →

    Installation étape par étape

    1

    Installer Go (Requis)

    Wails nécessite Go 1.25 ou une version ultérieure.

    Téléchargez l’installateur Windows depuis go.dev/dl et exécutez-le.

    Vérifier l’installation :

    PowerShell
    go version  # Doit afficher 1.25 ou une version ultérieure

    Vérifier le PATH :

    PowerShell
    $env:PATH -split ';' | Where-Object { $_ -like '*\go\bin' }

    Si le résultat est vide, ajoutez C:\Users\VotreNom\go\bin à votre PATH.

    Option 1 : Installateur officiel

    Téléchargez l’installateur macOS (fichier .pkg) depuis go.dev/dl et exécutez-le.

    Option 2 : Homebrew

    bash
    brew install go

    Vérifier l’installation :

    bash
    go version  # Doit afficher 1.25 ou une version ultérieure
echo $PATH | grep go/bin  # Doit afficher ~/go/bin

    Si ~/go/bin n’est pas dans le PATH, ajoutez-le à ~/.zshrc ou ~/.bash_profile :

    bash
    export PATH=$PATH:~/go/bin

    Option 1 : Archive officielle

    Téléchargez l’archive Linux depuis go.dev/dl, puis :

    bash
    sudo rm -rf /usr/local/go
sudo tar -C /usr/local -xzf go1.25.linux-amd64.tar.gz

    Option 2 : Gestionnaire de paquets

    bash
    # Ubuntu/Debian
sudo apt install golang-go

# Fedora
sudo dnf install golang

# Arch
sudo pacman -S go

    Ajouter au PATH (ajoutez à ~/.bashrc ou ~/.zshrc) :

    bash
    export PATH=$PATH:/usr/local/go/bin:~/go/bin
source ~/.bashrc  # Recharger

    Vérifier :

    bash
    go version
echo $PATH | grep go/bin
    2

    Installer les dépendances de la plateforme

    WebView2 Runtime (généralement préinstallé)

    Windows 10/11 inclut WebView2 par défaut. Si manquant :

    • Téléchargez-le depuis Microsoft
    • Ou exécutez wails3 doctor plus tard — il vous guidera

    C’est tout ! Aucune autre dépendance n’est nécessaire.

    Astuce de performance pour Windows 11

    Envisagez d’utiliser Dev Drive pour stocker vos projets. Les Dev Drives sont optimisés pour les charges de travail des développeurs et peuvent améliorer considérablement les temps de build et les vitesses d’accès au disque jusqu’à 30 %.

    Outils en ligne de commande Xcode (requis)

    bash
    xcode-select --install

    Cliquez sur “Installer” dans la boîte de dialogue qui apparaît.

    Vérifier :

    bash
    xcode-select -p  # Doit afficher /Library/Developer/CommandLineTools

    C’est tout ! macOS inclut WebKit par défaut.

    Outils de compilation et WebKit

    Versions minimales des distributions

    Wails v3 nécessite WebKitGTK 4.1 (utilise libsoup3). Les versions antérieures qui ne livrent que la 4.0 — Ubuntu 20.04, Debian 11, RHEL 8/9 et leurs dérivés — ne sont pas prises en charge.

    Nécessite Ubuntu 22.04+ ou Debian 12+.

    bash
    sudo apt update
sudo apt install build-essential pkg-config libgtk-3-dev libwebkit2gtk-4.1-dev
    bash
    sudo dnf install gcc pkg-config gtk3-devel webkit2gtk4.1-devel
    bash
    sudo pacman -S base-devel gtk3 webkit2gtk-4.1
    bash
    sudo zypper install gcc pkg-config gtk3-devel webkit2gtk3-devel
    bash
    sudo emerge --ask net-libs/webkit-gtk:4.1

    Ajoutez à votre shell.nix ou devShell :

    nix
    buildInputs = with pkgs; [ webkitgtk_4_1 gtk3 pkg-config gcc ];

    Exécutez wails3 doctor après avoir installé Wails — il affichera les paquets exacts nécessaires pour votre distribution.

    Optionnel : Prise en charge de GTK4

    Wails prend également en charge expérimentalement GTK4 / WebKitGTK 6.0. Si vous souhaitez construire avec GTK4, installez les dépendances supplémentaires pour votre distribution et construisez avec wails3 build -tags gtk4. Voir Packaging Linux - GTK4 pour plus de détails.
    3

    Installer l'interface de ligne de commande Wails

    bash
    go install github.com/wailsapp/wails/v3/cmd/wails3@latest

    Cela installe la commande wails3 dans ~/go/bin (ou %USERPROFILE%\go\bin sur Windows).

    4

    bash
    wails3 doctor

    Si la commande `wails3` est introuvable

    Votre ~/go/bin n’est pas dans le PATH. Voir l’étape 1 ci-dessus pour corriger cela, puis redémarrez votre terminal.

    5

    Installer npm (Optionnel mais recommandé)

    La plupart des modèles Wails utilisent npm pour les outils frontend.

    Téléchargez depuis nodejs.org et exécutez l’installateur.

    Vérifier :

    PowerShell
    npm --version

    Option 1 : Installateur officiel
    Téléchargez depuis nodejs.org

    Option 2 : Homebrew

    bash
    brew install node

    Vérifier :

    bash
    npm --version

    Option 1 : NodeSource

    bash
    curl -fsSL https://deb.nodesource.com/setup_lts.x | sudo -E bash -
sudo apt-get install -y nodejs  # Ubuntu/Debian

    Option 2 : Gestionnaire de paquets

    bash
    sudo dnf install nodejs  # Fedora
sudo pacman -S nodejs npm  # Arch

    Vérifier :

    bash
    npm --version

    Gestionnaires de paquets alternatifs

    Vous préférez pnpm, yarn ou bun ? Pas de problème ! Mettez simplement à jour le Taskfile.yml de votre projet pour utiliser votre outil préféré.

    Dépannage

    Commande wails3 introuvable

    Cause : ~/go/bin (ou %USERPROFILE%\go\bin) n’est pas dans votre PATH.

    Solution :

    1. Ouvrez “Variables d’environnement” (recherchez dans le menu Démarrer)
    2. Sous “Variables utilisateur”, trouvez Path
    3. Cliquez sur “Modifier” → “Nouveau”
    4. Ajoutez : C:\Users\VotreNom\go\bin (remplacez VotreNom)
    5. Cliquez sur “OK” sur toutes les boîtes de dialogue
    6. Redémarrez votre terminal

    Vérifier :

    PowerShell
    $env:PATH -split ';' | Where-Object { $_ -like '*\go\bin' }

    Ajoutez à ~/.zshrc (macOS) ou ~/.bashrc (Linux) :

    bash
    export PATH=$PATH:~/go/bin

    Rechargez :

    bash
    source ~/.zshrc  # ou ~/.bashrc

    Vérifier :

    bash
    echo $PATH | grep go/bin
wails3 version

    wails3 doctor signale des dépendances manquantes

    Linux : La sortie vous indique exactement quels paquets installer. Exemple :

    text
    ❌ webkit2gtk introuvable
   Installez avec : sudo apt install libwebkit2gtk-4.1-dev

    Windows : Si WebView2 est manquant :

    • Téléchargez depuis Microsoft
    • Ou il sera installé automatiquement lors de l’exécution de votre première application

    macOS : Si les outils Xcode sont manquants :

    bash
    xcode-select --install

    Version de Go trop ancienne

    Wails v3 nécessite Go 1.25+. Si vous avez une version plus ancienne :

    Téléchargez la dernière version depuis go.dev/dl et réinstallez-la.

    Téléchargez la dernière archive tarball depuis go.dev/dl, puis :

    bash
    sudo rm -rf /usr/local/go
sudo tar -C /usr/local -xzf go1.25.linux-amd64.tar.gz

    Version de développement (Bleeding Edge)

    Vous souhaitez utiliser le code le plus récent issu de la branche de développement principale ? Cela vous donne accès aux nouvelles fonctionnalités et aux correctifs avant leur publication, mais comporte le risque de bogues et de modifications incompatibles. Seulement recommandé pour les contributeurs ou ceux qui doivent tester les fonctionnalités à venir.

    bash
    git clone https://github.com/wailsapp/wails.git
cd wails
git checkout v3
cd v3/cmd/wails3
go install

    Version de développement

    • Peut contenir des bogues ou des modifications incompatibles
    • Les projets créés utiliseront la directive replace pour pointer vers Wails local
    • Seulement recommandé pour les contributeurs ou pour tester de nouvelles fonctionnalités
