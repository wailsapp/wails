    Vorlagen

    Achtung

    Diese Seite könnte für Wails v3 veraltet sein.

    Diese Seite dient als Liste von von der Community unterstützten Vorlagen. Um Ihre eigene Vorlage zu erstellen, sehen Sie bitte im Leitfaden Vorlagen nach.

    Wie man eine Vorlage einreicht

    Sie können unten auf Edit this page klicken, um Ihre Vorlagen einzufügen.

    Um diese Vorlagen zu verwenden, führen Sie wails init -n "Ihr Projektname" -t [der Link unten[@version]] aus.

    Wenn kein Versions-Suffix vorhanden ist, wird standardmäßig die Vorlage des main-Branches verwendet. Wenn ein Versions-Suffix vorhanden ist, wird die Vorlage verwendet, die dem Tag dieser Version entspricht.

    Beispiel: wails init -n "Ihr Projektname" -t https://github.com/misitebao/wails-template-vue

    Achtung

    Das Wails-Projekt pflegt keine, ist nicht verantwortlich und haftet nicht für Vorlagen von Drittanbietern!

    Wenn Sie sich bei einer Vorlage unsicher sind, prüfen Sie package.json und wails.json, welche Skripte ausgeführt werden und welche Pakete installiert sind.

    Vue

    • wails-template-vue - Wails Vorlage basierend auf der Vue-Ökologie (Integriertes TypeScript, Dunkles Thema, Internationalisierung, Single-Page-Routing, TailwindCSS)
    • wails-template-quasar-js - Eine Vorlage, die JavaScript + Quasar V2 verwendet (Vue 3, Vite, Sass, Pinia, ESLint, Prettier)
    • wails-template-quasar-ts - Eine Vorlage, die TypeScript + Quasar V2 verwendet (Vue 3, Vite, Sass, Pinia, ESLint, Prettier, Composition API mit <script setup>)
    • wails-template-naive - Wails Vorlage basierend auf Naive UI (eine Vue 3 Komponentenbibliothek)
    • wails-template-nuxt - Wails Vorlage, die sauberes Nuxt3 und TypeScript mit Auto-Imports für die Wails JS Laufzeit verwendet
    • Wails-Tool-Template - Wails Vorlage, die Vue+TypeScript+Vite+Element-plus (im Stil von NetEase Cloud) verwendet

    Angular

    • wails-angular-template - Angular mit TypeScript, Sass, Hot-Reload, Code-Splitting und i18n

    • wails-template-nextjs-app-router - Eine Vorlage, die Next.js und TypeScript mit App-Router verwendet
    • wails-template-nextjs-app-router-src - Eine Vorlage, die Next.js und TypeScript mit App-Router src + Beispiel verwendet
    • wails-vite-react-ts-tailwind-template - Eine Vorlage für React + TypeScript + Vite + TailwindCSS
    • wails-vite-react-ts-tailwind-shadcnui-template - Eine Vorlage mit Vite, React, TypeScript, TailwindCSS und shadcn/ui
